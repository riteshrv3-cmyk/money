# Chapter 1.4 [DEPTH]: रूपांतरांची साखळी आणि खोली

थेंबूचा प्रश्न: अनेक matrices एकामागून एक: याला एकत्रित अर्थ
आहे का? उत्तर सुंदर आहे, आणि ते AI च्या "खोली" (depth: शेकडो
थर) चं रहस्य उघडतं. [DEPTH]: थोडं खोलात, पण थेंबूसोबत सोपं.

**साखळी म्हणजे काय.** थेंबूची हवा (0.8, 0.6) पहिल्या matrix
A मधून जाते -> नवा बाण; तो दुसऱ्या matrix B मधून -> आणखी
नवा बाण. दोन रूपांतरं, एकामागून एक. गंमत: A नंतर B लावणं
= एकच नवा matrix C लावण्यासारखं (C म्हणजे "आधी A मग B").
म्हणजे **अनेक रूपांतरांची साखळी = एकच (गुंतागुंतीचं) रूपांतर.**
स्वयंपाकाची उपमा: भाजी चिरा -> तळा -> मसाला घाला: तीन
कृती, पण मिळून "एक पदार्थ बनवणं" ही एकच मोठी कृती.

**मग शेकडो थर कशाला, एकच मोठा matrix का नाही?** इथे खरी
गोम आहे, आणि ती समजली की deep learning मधलं "deep" कळतं.
जर मध्ये **काहीच** घडलं नाही (नुसते matrices), तर खरंच शेकडो
थर = एकच matrix (वाया). पण AI मध्ये **प्रत्येक matrix नंतर
एक छोटी वाकडी कृती** घडते: याला "activation" म्हणतात, आणि
ती साखळीला **सरळ रेषेपेक्षा जास्त** बनवते.

**वाकडी कृती का लागते (सर्वात महत्त्वाचा मुद्दा).** matrix फक्त
**सरळ** रूपांतरं करतो: ताणणं, फिरवणं (म्हणून त्याला "linear"
म्हणतात: रेषीय). पण जग सरळ नाही: "आर्द्रता 0.9 च्या **पुढे**
गेली तरच पाऊस" असले **उंबरठे**, **वळणं** matrix ला जमत
नाहीत. म्हणून प्रत्येक थरानंतर एक साधी वाकडी कृती: उदा
"उणे आकडे शून्य कर, धन तसेच ठेव" (याला ReLU म्हणतात:
सर्वात सामान्य). ही छोटी वाकडी कृती नसेल तर शंभर थर = एक
थर (नुसती सरळ साखळी); ती असेल तर शंभर थर **खरोखर**
शंभर पट गुंतागुंतीचं वळणदार रूपांतर शिकू शकतात. **खोली =
सरळ रूपांतरं + वाकड्या कृती, आलटून-पालटून, शंभर वेळा:
म्हणून यंत्र गुंतागुंतीचे नमुने पकडतं.**

**थेंबूवर:** थेंबूचा एक matrix "आर्द्रता + 2xढग" इतकंच सरळ
काढू शकतो. पण "ढग भरपूर **आणि** आर्द्रता उंबरठ्यापुढे तरच
जोरदार पाऊस" हा वाकडा नियम एका matrix ला जमत नाही: दोन
थर + मधली वाकडी कृती लागते. म्हणून खरं यंत्र = अनेक थेंबू-
matrices + वाकड्या कृती: आणि तेच ChatGPT, फक्त अब्जावधी पट.

## इथे लोक काय चुकीचं समजतात

"जास्त थर = आपोआप जास्त हुशार." अर्धसत्य: थर जास्त **आणि**
मधल्या वाकड्या कृती **आणि** नीट शिकवणी (Part 3) असेल तरच.
नुसते matrices रचले (वाकड्या कृतीशिवाय) तर शंभर थर = एक
थर: वाया. आणि उलट: वाकडी कृती हे "यंत्राची जादू" नाही; ती
"उणे शून्य कर" इतकी साधी असू शकते: जादू **खोली आणि
शिकवणीत** आहे, कुठल्या एका कृतीत नाही.

## नकाशावर

```
1.1-1.3  vector | dot | matrix
1.4  साखळी: अनेक रूपांतरं = एक मोठं रूपांतर; पण मधली
     वाकडी कृती (activation) नसेल तर शंभर थर = एक थर;
     खोली = सरळ+वाकडं आलटून-पालटून
```

**सूत्रावर:** हा चष्मा "deep learning मधलं deep का महत्त्वाचं"
हे दाखवतो: खोली म्हणजे रूपांतरं + वाकडी वळणं, वारंवार. न
दिसणारं (यंत्राची गुंतागुंत पकडायची क्षमता) आकड्यांच्या साखळीत
दिसलं.

## स्वतः बघा (5 मिनिटं)

एक वाकडी कृती हाताने: ReLU = "उणे असेल तर 0, धन असेल
तर तसंच." आकडे (3, -2, 5, -1) वर लावा: (3, 0, 5, 0). बघा:
वाईट (उणे) बातम्या गाळल्या, चांगल्या ठेवल्या. आता कल्पना
करा हे प्रत्येक थरानंतर: यंत्र हळूहळू "काय ठेवायचं, काय
गाळायचं" शिकतं. इतक्या साध्या कृतीतून गुंतागुंत जन्मते: हेच
आश्चर्य.
