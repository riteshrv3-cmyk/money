# Chapter 1.2 [SPINE]: Dot Product: जवळिकीचं माप

थेंबूला दोन बाणांची जवळीक एका आकड्यात हवीय. गणिताचं उत्तर
एका साध्या कृतीत आहे, आणि ती कृती AI मध्ये **सर्वात जास्त
वेळा** घडते: म्हणून ती हातानेच करून बघू.

**कृती: जोडीजोडीने गुणा, मग बेरीज.** दोन बाण:
आज = (0.8, 0.6), आदर्श-पावसाळी = (0.9, 0.7). Dot product:

```
पहिले आकडे गुणा:   0.8 x 0.9 = 0.72
दुसरे आकडे गुणा:   0.6 x 0.7 = 0.42
बेरीज:            0.72 + 0.42 = 1.14
```

झालं. दोन बाणांचा dot product = **1.14.** एका आकड्यात दोन
बाणांची "जुळणी." मनातल्या मनात झालं ना? यंत्रात हेच अब्जावधी
वेळा घडतं: फक्त 2 ऐवजी शेकडो आकडे, पण कृती तीच: जोडीने
गुणा, बेरीज.

**हा आकडा काय सांगतो: तीन प्रसंग बघा.** थेंबूची आजची हवा
(0.8, 0.6) तीन वेगळ्या "आदर्शां"शी ताडू:

```
पावसाळी आदर्श (0.9, 0.7): 0.8x0.9 + 0.6x0.7 = 0.72+0.42 = 1.14  (मोठा!)
कोरडा आदर्श   (0.1, 0.2): 0.8x0.1 + 0.6x0.2 = 0.08+0.12 = 0.20  (छोटा)
उलटा         (-0.9,-0.7): 0.8x-0.9+0.6x-0.7 = -0.72-0.42 = -1.14 (उणे!)
```

नियम स्पष्ट दिसतो: **बाण एकाच दिशेला (सारखे) -> dot मोठा
सकारात्मक; लंब (असंबंधित) -> शून्याजवळ; उलट्या दिशेला
(विरुद्ध) -> उणे.** म्हणजे dot product हे **जवळिकीचं थर्मामीटर**
आहे: एका आकड्यात "हे दोन बाण किती एकमेकांसारखे." थेंबूला
आता कळलं: आजची हवा पावसाळी-आदर्शाशी खूप जुळते (1.14),
कोरड्याशी नाही (0.20): म्हणजे आज पाऊस शक्य.

**आणि इथे AI ची दुसरी गुरुकिल्ली:** Book 2 मध्ये attention
म्हणजे "मागणी-पाटी जुळणी" (query-key match) होतं. ते नक्की
काय? **प्रत्येक शब्दाचा query-बाण दुसऱ्या शब्दांच्या key-बाणांशी
dot product.** मोठा dot = "हे दोन शब्द एकमेकांशी संबंधित,
लक्ष दे"; छोटा = "दुर्लक्ष कर." Attention चं हृदय म्हणजे लाखो
dot products: जवळिकीची लाखो मापं. आणि embedding-शोध
(RAG, Book 4): "या प्रश्नाशी जवळचे कागद" म्हणजे सर्वात मोठा
dot product असलेले. **एक साधी कृती: जोडीने गुणा, बेरीज: AI
च्या अर्ध्या कामाचा पाया.**

## इथे लोक काय चुकीचं समजतात

"Dot product म्हणजे किचकट गणित." आत्ता तुम्ही ते मनातल्या
मनात केलंत: दोन गुणाकार, एक बेरीज. किचकट काहीच नाही;
फक्त AI मध्ये आकडे शेकडो आणि कृती अब्जावधी वेळा, म्हणून
GPU लागतो (Book 2 चा कारखाना: तो हेच अब्जावधी गुणा-बेरीज
करतो!). दुसरा गैरसमज: "जवळीक म्हणजे नेहमी चांगलं." नाही:
dot फक्त **मोजतो**; तो जवळ हवा की दूर हे कामावर ठरतं
(query ला उत्तर जवळचं हवं, पण दोन वेगळ्या गोष्टी वेगळ्याच
हव्यात). Dot हे थर्मामीटर आहे, ताप चांगला की वाईट हे तुम्ही
ठरवता.

## नकाशावर

```
1.1  vector = यादी = दिशा (बाण)
1.2  dot product = जोडीने गुणा+बेरीज = जवळिकीचं माप;
     सारखे->मोठा, लंब->शून्य, उलटे->उणे; attention चं हृदय
```

**सूत्रावर:** dot product हा चष्मा "यंत्राला दोन शब्द संबंधित
आहेत हे कसं कळतं" हे गूढ फोडतो: एका गुणा-बेरजेने. Attention
ची जादू आता अंकगणित आहे: न दिसणारं (संबंध) आकड्यात दिसलं.

## स्वतः बघा (5 मिनिटं)

तीन जोड्या हाताने करा: (1,0)·(0,1) = 1x0+0x1 = 0 (लंब,
असंबंधित); (1,1)·(1,1) = 1+1 = 2 (तंतोतंत सारखे, मोठा);
(1,1)·(1,-1) = 1-1 = 0 (लंब!). शेवटचा गंमतीचा: (1,1) आणि
(1,-1) उलटे वाटतात पण dot शून्य = लंब = असंबंधित. आकडा
तुमच्या डोळ्याच्या अंदाजापेक्षा नेमका असतो: हीच गणिताची ताकद.

## विचार करा

थेंबूचं यंत्र आता आर्द्रता आणि ढग यांना **वेगवेगळं महत्त्व**
द्यायला शिकलंय: "पावसासाठी ढग आर्द्रतेपेक्षा जास्त महत्त्वाचे."
म्हणजे त्याला दोन आकडे नुसते जुळवायचे नाहीत, तर **एका
आकड्याचं दुसऱ्यात, महत्त्वानुसार, रूपांतर** करायचंय: (आर्द्रता,
ढग) -> (पाऊस-गुण). "एका दिशेचं दुसऱ्या दिशेत, ठरलेल्या
नियमाने रूपांतर: हे कसं मांडायचं?"
