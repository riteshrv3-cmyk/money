# Chapter 1.3 [SPINE]: Matrix: रूपांतराचं यंत्र

थेंबूला (आर्द्रता, ढग) चं (पाऊस-गुण) मध्ये, महत्त्वानुसार, रूपांतर
करायचंय. गणिताचं हत्यार म्हणजे **matrix**: आणि matrix हे
"आकड्यांचा चौकोन" नसून एक **रूपांतर-यंत्र** आहे: बाण आत
टाका, फिरवलेला-ताणलेला बाण बाहेर.

**आधी सोपं: एका आकड्याचं रूपांतर.** थेंबूला वाटतं ढग
आर्द्रतेपेक्षा दुप्पट महत्त्वाचे. तो एक "वजन-यादी" बनवतो:
आर्द्रतेला 1, ढगांना 2. आजची हवा (0.8, 0.6). पाऊस-गुण =

```
0.8 x 1  +  0.6 x 2  =  0.8 + 1.2  =  2.0
```

हे ओळखीचं आहे: हा dot product च आहे (1.2)! वजन-यादी
(1, 2) आणि हवा (0.8, 0.6) यांचा dot = पाऊस-गुण 2.0. म्हणजे
**एका बाणाचं एका आकड्यात रूपांतर = एक dot product.**

**आता matrix: अनेक रूपांतरं एकत्र.** समजा थेंबूला दोन गुण
हवेत: "पाऊस-गुण" आणि "गारवा-गुण." प्रत्येकाची वेगळी वजन-
यादी:

```
पाऊस-गुण  = वजनं (1, 2):   0.8x1 + 0.6x2 = 2.0
गारवा-गुण = वजनं (3, -1):  0.8x3 + 0.6x-1 = 2.4 - 0.6 = 1.8
```

या **दोन वजन-याद्या एकत्र रचल्या** की matrix होतो:

```
        आर्द्रता  ढग
पाऊस  [   1      2  ]
गारवा [   3     -1  ]
```

आणि "हवा-बाण matrix मधून घालवणं" म्हणजे: **प्रत्येक ओळीचा
हवेशी dot product.** आत (0.8, 0.6) टाकलं, बाहेर (2.0, 1.8)
आलं. एक 2-आकड्यांचा बाण दुसऱ्या 2-आकड्यांच्या बाणात
**रूपांतरित.** Matrix = अनेक dot products एका खोक्यात =
एक रूपांतर-यंत्र.

**हीच AI च्या प्रत्येक थराची कृती.** Book 2 चा transformer-मजला
(3.8) आठवा: प्रत्येक थर म्हणजे एक (किंवा अनेक) matrix, जो
येणारा बाण (शब्दाचा अर्थ) घेऊन त्याला नव्या बाणात रूपांतरित
करतो. "यंत्र विचार करतं" म्हणजे प्रत्यक्षात: **बाण -> matrix ->
नवा बाण -> पुढचा matrix -> नवा बाण...** शेकडो वेळा. GPT
मध्ये हे matrices अवाढव्य (शेकडो x शेकडो आकडे) आणि शेकडो
थर, पण **कृती तीच जी थेंबूची**: ओळीचा dot, नवा आकडा. यंत्राचं
"वजन" (Book 2, 2.4: weights) म्हणजे नक्की हेच: या matrices
मधले आकडे. अब्जावधी weights = अब्जावधी matrix-आकडे. **शिकणं
म्हणजे हे matrix-आकडे बरोबर जुळवणं** (Part 3 चा विषय).

## इथे लोक काय चुकीचं समजतात

"Matrix म्हणजे आकड्यांचा नुसता चौकोन/table." घातक अर्धसत्य.
Matrix हे **क्रियापद** आहे, नाम नाही: तो एक **कृती** आहे: "हा
बाण घे आणि असा फिरव-ताण." Excel-सारखा स्थिर table बघितलात
तर matrix कधीच "जाणवणार" नाही; "रूपांतर-यंत्र" म्हणून बघितलात
की AI ची अख्खी रचना उलगडते. दुसरा गैरसमज: "matrix गुणाकार
म्हणजे भयंकर किचकट नियम." नियम एकच, तुम्ही आत्ता केलात:
**ओळीचा येणाऱ्या बाणाशी dot product.** बाकी सगळं याचीच
पुनरावृत्ती.

## नकाशावर

```
1.1  vector = यादी = दिशा     1.2  dot = जवळिकीचं माप
1.3  matrix = रूपांतर-यंत्र (अनेक dot एकत्र); बाण आत ->
     फिरवलेला बाण बाहेर; AI चे weights = matrix-आकडे
```

**सूत्रावर:** matrix हा चष्मा "यंत्राचा थर म्हणजे नक्की काय"
हे दाखवतो: एक रूपांतर, बाणाचं बाणात. "यंत्र विचार करतं" ही
कविता; "बाण matrix मधून जातो" हे गणित. न दिसणारं (विचार)
आकड्यांच्या फिरवणुकीत दिसलं.

## स्वतः बघा (5 मिनिटं)

हा matrix हाताने चालवा: वजनं ओळ-1 (2, 0), ओळ-2 (0, 2),
बाण (3, 5). प्रत्येक ओळीचा dot: 2x3+0x5 = 6; 0x3+2x5 =
10. बाहेर (6, 10): मूळ बाण **दुप्पट** झाला! हा matrix "सगळं
दुप्पट कर" हे रूपांतर करतो. आता ओळी (0,1),(1,0) घ्या, बाण
(3,5): बाहेर (5,3): आकडे **उलटे**! Matrix आकडे बदलून वेगवेगळी
रूपांतरं: फिरवणं, ताणणं, अदलाबदल. खेळून बघा.

## विचार करा

थेंबूचं यंत्र आता एक matrix आहे: हवा आत, गुण बाहेर. पण
खरं यंत्र एका matrix चं नसतं; ते **अनेक matrices एकामागून
एक** असतं (Book 2 चे शेकडो थर). थेंबूला प्रश्न पडला: "मी
हवा पहिल्या matrix मधून घातली, नवा बाण आला; तो दुसऱ्या
matrix मधून घातला... हे अनेक रूपांतरं एकामागून एक: याला
काही एकत्रित अर्थ आहे का? की नुसती साखळी?"

> रूपांतर** होतं, आणि तेच AI च्या खोलीचं (depth) रहस्य आहे.
