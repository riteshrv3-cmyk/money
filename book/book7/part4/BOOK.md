# Chapter 4.1 [SPINE]: Attention आकड्यांनी: पायरी-पायरी

हा chapter म्हणजे पूर्ण पुस्तकाचा कळस: **attention, आकड्यांनी,
हाताने.** Book 2 ने उपमा दिली (query = मागणी, key = पाटी,
value = माल); आता ती उपमा **आकड्यांत** बघू. कागद-पेन घ्या.

**रचना: तीन शब्द, प्रत्येकाला तीन बाण.** एक छोटं वाक्य: "पाऊस
आज पडेल." attention चं काम: प्रत्येक शब्दाने इतर शब्दांकडे
**किती लक्ष द्यायचं** ठरवून, त्यानुसार माहिती मिसळणं. प्रत्येक
शब्दाला तीन बाण (हे matrices ने बनतात, Part 1; इथे तयार
धरू):

```
शब्द    query (q)    key (k)      value (v)
पाऊस    -            (1, 0)       (2, 0)
आज      -            (0, 1)       (0, 2)
पडेल    (1, 0)       (0.5, 0.5)   (1, 1)
```

query = "मला काय शोधायचंय"; key = "माझ्याकडे काय आहे";
value = "मी काय माहिती देईन." आपण **"पडेल" या शब्दाचं
attention** काढू: तो इतर शब्दांकडे किती लक्ष देतो?

**पायरी 1: जुळणी-गुण (query · प्रत्येक key): dot product (1.2).**
```
पडेल·पाऊस = (1,0)·(1,0)   = 1x1 + 0x0   = 1.0   (जुळतं!)
पडेल·आज   = (1,0)·(0,1)   = 1x0 + 0x1   = 0.0   (जुळत नाही)
पडेल·पडेल = (1,0)·(0.5,0.5)= 1x0.5+0x0.5 = 0.5   (थोडं)
```
"पडेल" ची मागणी (1,0) "पाऊस" च्या पाटीशी (1,0) सर्वात जुळते.
गुण: 1.0, 0.0, 0.5.

**पायरी 2: गुणांचं लक्ष-वाटप (softmax, 2.6).** हे गुण probability
मध्ये (बेरीज 1):
```
स्फोट: e^1=2.72,  e^0=1.0,  e^0.5=1.65
बेरीज: 2.72+1.0+1.65 = 5.37
लक्ष: पाऊस 2.72/5.37=0.51,  आज 1.0/5.37=0.19,  पडेल 1.65/5.37=0.31
```
म्हणजे "पडेल" आपलं **51% लक्ष "पाऊस" कडे**, 19% "आज" कडे,
31% स्वतःकडे देतो. हेच "attention weights": कुणाकडे किती
बघायचं.

**पायरी 3: माहिती मिसळा (लक्ष x value यांची बेरीज).** आता
प्रत्येक शब्दाचा value-बाण त्याच्या लक्ष-वाट्याने घ्या, बेरीज करा:
```
output = 0.51 x (2,0) + 0.19 x (0,2) + 0.31 x (1,1)
       = (1.02, 0)   + (0, 0.38)   + (0.31, 0.31)
       = (1.33, 0.69)
```
झालं. "पडेल" चा नवा बाण = **(1.33, 0.69):** मुख्यतः "पाऊस"
च्या माहितीने (2,0) रंगलेला, कारण तिकडे सर्वात जास्त लक्ष.
**हेच attention:** प्रत्येक शब्दाने इतरांकडे लक्ष-वाटून, त्यांची
माहिती स्वतःत मिसळणं. "पडेल" ला आता "पाऊस" चा संदर्भ
कळला: वाक्याचा अर्थ त्याच्या बाणात उतरला.

**हेच ChatGPT करतं, फक्त:** 3 शब्द ऐवजी हजारो, 2-आकड्यांचे
बाण ऐवजी शेकडो-आकड्यांचे, आणि एका "लक्ष-नजरे" ऐवजी अनेक
समांतर (multi-head: प्रत्येक नजर वेगळं नातं बघते: कोण-कुणाशी
व्याकरण, कोण-कुणाशी अर्थ). पण **कृती तीच जी तुम्ही आत्ता
केलीत:** dot (जुळणी) -> softmax (लक्ष) -> weighted sum
(मिसळण). Book 2 चा "मागणी-पाटी-माल बाजार" आता तीन ओळींचं
अंकगणित आहे. Attention चं गूढ संपलं.

## इथे लोक काय चुकीचं समजतात

"Attention म्हणजे यंत्र 'लक्ष देतं', म्हणजे त्याला जाणीव/समज
आहे." नाही: "लक्ष" हा फक्त softmax-चा वाटप-आकडा आहे
(0.51, 0.19, 0.31). यंत्र "बघत" नाही, "जाणत" नाही; ते dot
products चे गुण softmax मधून probability करतं आणि values
ची भारित बेरीज घेतं. "attention" हे काव्यात्मक नाव आहे,
यांत्रिक कृतीला. जाणीव तिथे नाही, फक्त जुळणी-वाटप-मिसळण
आहे. (हा भेद Book 2 च्या "यंत्राला समज आहे का" वादाचा गाभा.)

## नकाशावर

(दर chapter ला एक ओळ.)

```
4.1  attention आकड्यांनी: dot (जुळणी-गुण) -> softmax (लक्ष-
     वाटप) -> weighted sum (value मिसळण); "पडेल" 51% "पाऊस"
     कडे; हेच ChatGPT, अब्जावधी पट
```

**सूत्रावर:** attention हा सर्वात मोठा चष्मा-क्षण: Book 2 चं
सर्वात गूढ यंत्र आता तीन ओळींचं अंकगणित. न दिसणारं (यंत्र
शब्दांचा संदर्भ कसा जोडतं) पूर्ण आकड्यांत दिसलं. जादू कायमची
संपली; समज उरली.

## स्वतः बघा (5 मिनिटं)

वरचं attention स्वतः, हाताने करा: पण "पाऊस" या शब्दाचं
(त्याचा query असेल समजा (0,1)). कुठल्या शब्दाकडे तो सर्वात
जास्त लक्ष देईल? (key (0,1) असलेल्या "आज" कडे.) एकदा हाताने
केलंत की attention चा "बाजार" तुमच्या बोटांत उतरेल: आणि
कुठलाही transformer-paper वाचताना हे चित्र डोळ्यांसमोर येईल.

## विचार करा

थेंबूने attention काढलं, पण एक बारकावा दिसला: "मी गुण (1.0,
0.0, 0.5) थेट softmax मध्ये टाकले. पण Book 2 आणि papers

product). का भागायचं? गुण जसेच्या तसे का चालत नाहीत?"

> सूक्ष्म पण महत्त्वाचा प्रश्न: बाण मोठे (शेकडो आकडे) झाले
> की dot-गुणही मोठे होतात, आणि मोठे गुण softmax ला
> **अति-तीव्र** करतात (एकावर सगळं लक्ष, बाकी शून्य: शिकणं
> बिघडतं). तो का आणि उपाय: पुढचा chapter.

# Chapter 4.2 [DEPTH]: Softmax-Scaling का लागतं

थेंबूचा प्रश्न: attention मध्ये गुण आधी का भागतात? हा छोटा
पण सुंदर मुद्दा आहे, आणि तो "papers मधले विचित्र भागाकार"
समजायला किल्ली आहे. [DEPTH]: बारीक, पण एका खऱ्या नमुन्याचं
स्पष्टीकरण.

**समस्या: मोठे बाण = मोठे गुण = अति-तीव्र softmax.** 4.1 मध्ये
बाण छोटे (2 आकडे) होते, गुण छोटे (1.0, 0.5). पण खऱ्या यंत्रात
बाण शेकडो आकड्यांचे. dot product म्हणजे शेकडो गुणाकारांची
बेरीज (1.2): जितके जास्त आकडे, तितकी बेरीज **मोठी** होते.
गुण 1-2 ऐवजी 20-50 होतात. आणि मोठे गुण softmax मध्ये
घातले तर?

```
छोटे गुण (1, 0, 0.5): softmax -> (0.51, 0.19, 0.31): मऊ वाटप
मोठे गुण (10, 0, 5):  softmax -> (0.99, 0.00, 0.01): अति-तीव्र!
```

मोठे गुण softmax ला **टोकाला** नेतात: जवळजवळ सगळं लक्ष
एकावर, बाकीला शून्य (distribution अति-तीव्र, entropy जवळजवळ
शून्य: 2.4). हे वाईट का? दोन कारणं: (1) यंत्र फक्त एकाच
शब्दाकडे बघतं, बाकीचा संदर्भ गमावतं (मऊ मिसळण हवं). (2)
आणि गंभीर: शिकवणीत **gradient जवळजवळ शून्य** होतो
(vanishing: 3.3): कारण अति-तीव्र softmax चा उतार सपाट,
म्हणून weights हलतच नाहीत, यंत्र शिकत नाही.

**उपाय: गुणांना बाणाच्या-आकाराच्या मुळाने भागा.** transformer
चा नियम: dot-गुणांना **root(d)** ने भागा (d = बाणातल्या
आकड्यांची संख्या). बाण 64 आकड्यांचा तर root(64) = 8 ने भागा;
100 आकड्यांचा तर 10 ने. का हे नेमकं? गणिती कारण: बाण
मोठे झाले की dot-गुण साधारण root(d) पटीने वाढतात; म्हणून
root(d) ने भागलं की गुण पुन्हा "वाजवी" आकारात येतात (1-2
च्या आसपास), softmax मऊ राहतो, शिकणं सुरळीत. एका ओळीत:
**scaling म्हणजे बाण कितीही मोठे असोत, attention चे गुण
वाजवी ठेवणं, म्हणजे softmax मऊ आणि शिकणं जिवंत.**

**हे शिकण्याचा खरा फायदा (papers-वाचन):** transformer च्या
मूळ paper चं नावच "scaled dot-product attention" आहे. आता
तुम्हाला "scaled" का ते नेमकं कळलं: तो root(d) चा भागाकार,
आणि तो का लागतो. papers मध्ये असे शेकडो "छोटे तांत्रिक
तपशील" असतात जे भीतीदायक दिसतात पण **प्रत्येकामागे असंच
एक साधं व्यावहारिक कारण** असतं ("हे न केलं तर हे बिघडतं").
गणिताचा चष्मा तुम्हाला ते कारण शोधायला शिकवतो: आणि मग
paper भीतीदायक न राहता "समस्या-उपाय" ची यादी होतं.

## इथे लोक काय चुकीचं समजतात

"Paper मधली प्रत्येक सूत्र-सजावट म्हणजे खोल, दुर्बोध गणित."
बहुतेकदा उलट: प्रत्येक तपशीलामागे एक साधं, व्यावहारिक "नाहीतर
हे बिघडतं" असतं (इथे: नाहीतर softmax तीव्र, शिकणं मरतं).
papers अवघड **दिसतात** कारण संक्षिप्त भाषा आणि प्रतीकं; पण
आत बहुधा तुम्हाला समजणारी अभियांत्रिकी-कारणं. "हे प्रतीक
का आहे" विचारत गेलं की paper उलगडतं. भीती प्रतीकांची असते,
कल्पनांची नाही.

## नकाशावर

```
4.1  attention आकड्यांनी: dot -> softmax -> weighted sum
4.2  scaling: मोठे बाण -> मोठे गुण -> अति-तीव्र softmax (शिकणं
     मरतं); उपाय root(d) ने भागा -> गुण वाजवी, softmax मऊ;
     papers चे तपशील = "नाहीतर हे बिघडतं"
```

**सूत्रावर:** scaling हा छोटा चष्मा मोठा धडा देतो: AI मधला
प्रत्येक तांत्रिक तपशील एका मोजता-येणाऱ्या समस्येचा उपाय
आहे. जे बिघडतं ते मोजता आलं (तीव्र softmax, मेलेला gradient),
म्हणून उपाय (भागाकार) सापडला: सूत्र papers च्या तळाशीही.

## स्वतः बघा (5 मिनिटं)

दोन softmax हाताने: गुण (2, 1, 0) आणि तेच 10-पट (20, 10, 0).
पहिल्याचा softmax मऊ (तिन्हींना थोडं); दुसऱ्याचा जवळजवळ
(1, 0, 0). बघा: गुण मोठे केले की softmax टोकाला जातो. हेच
scaling टाळतं. आकड्यांचा "आकार" softmax च्या मऊपणावर किती
परिणाम करतो, ते डोळ्यांनी दिसेल.

## विचार करा

थेंबूला attention चा एक "मजला" कळला. पण Book 2 म्हणालं
transformer-मजल्यात attention **आणि** आणखी काही (एकांत-
खोली, वाकडी कृती) असतं, आणि असे शेकडो मजले. "एक पूर्ण
मजला नक्की काय-काय करतो, आणि तो एका बाणावर पायरी-पायरी
कसा चालतो? मला अख्खा मजला, आकड्यांनी, बघायचाय."

> हाच पुढचा chapter, आणि थेंबूचा ChatGPT होण्याचा क्षण:
> एक पूर्ण transformer-मजला, सगळे तुकडे जोडून, एका बाणावर
> पायरी-पायरी. Part 1-4 चं सगळं एका चित्रात.

# Chapter 4.3 [SPINE]: एक Transformer-मजला, पूर्ण

थेंबूचा ChatGPT होण्याचा क्षण. एक पूर्ण transformer-मजला, सगळे
तुकडे जोडून, एका बाणावर पायरी-पायरी. Book 2 चा "बाजार +
एकांत-खोली" आता आकड्यांच्या प्रवाहात.

**मजल्याचे चार अवयव (एका शब्द-बाणावर):** एक शब्द-बाण आत
येतो; मजला त्याला चार पायऱ्यांतून नेतो, नवा (जास्त-समजलेला)
बाण बाहेर.

```
पायरी 1: ATTENTION (बाजार): शब्द इतर शब्दांकडे लक्ष-वाटून
   त्यांची माहिती मिसळतो (4.1). "पडेल" -> (1.33, 0.69),
   "पाऊस" चा संदर्भ आत आला. आउटपुट: संदर्भ-रंगलेला बाण.

पायरी 2: जोडणी (residual): मूळ बाण + attention-आउटपुट (बेरीज).
   का? म्हणजे मूळ माहिती हरवत नाही (attention ने फक्त
   "भर" घातली, मूळ पुसलं नाही); आणि हेच खोल यंत्रात gradient
   जिवंत ठेवतं (3.3 चा vanishing टाळतो). "जुनं ठेवून नवं जोडा."

पायरी 3: एकांत-खोली (feed-forward): आता प्रत्येक शब्द एकटा,
   एका छोट्या 2-थरी यंत्रातून (matrix -> वाकडी कृती ReLU ->
   matrix: Part 1, 1.3-1.4). इथे शब्द बाजारात मिळालेली
   माहिती "पचवतो", स्वतःपुरता विचार करतो. + पुन्हा जोडणी.

पायरी 4: ताळमेळ (normalization): बाणातले आकडे खूप मोठे/
   लहान होऊ नयेत म्हणून त्यांना "वाजवी" पट्ट्यात आणणं
   (scaling चा भाऊ, 4.2): पुढच्या मजल्याला स्वच्छ बाण मिळो.
```

आत बाण, बाहेर बाण: **पण बाहेरचा बाण "जास्त समजलेला"**
(संदर्भ मिसळलेला + पचवलेला + नीटनेटका). आणि मग तोच बाण
**पुढच्या मजल्यात**, तिथे पुन्हा चार पायऱ्या, आणि पुढच्या...
GPT मध्ये असे **शेकडो मजले.** प्रत्येक मजला बाणाला थोडं जास्त
अर्थ देतो: पहिले मजले व्याकरण-सारखं उथळ, वरचे मजले खोल
अर्थ-तर्क. शेवटी शेवटच्या बाणातून पुढच्या token ची probability
(softmax, 2.6). **हेच ChatGPT चं एक पाऊल, पूर्ण.**

**थेंबू ते ChatGPT (पूर्ण प्रवास एका दृष्टिक्षेपात):**
```
थेंबू:    2 आकडे -> 3 weights -> 1 अंदाज (एक ओळ)
मजला:    बाण -> attention + जोडणी + एकांत + ताळमेळ -> बाण
ChatGPT: शब्द -> बाण (embedding) -> शेकडो मजले ->
         शेवटचा बाण -> softmax -> पुढचा token -> पुन्हा
```

तुकडे तेच जे थेंबूचे: बाण (Part 1), dot-matrix (Part 1),
softmax-probability (Part 2), आणि हे सगळं शिकलं gradient
descent-backprop ने (Part 3). **कुठेही नवीन जादू नाही; फक्त
थेंबूचे तुकडे, अब्जावधी पट, शेकडो मजले उंच.** जो थेंबू समजला
तो ChatGPT समजला: फरक आकाराचा, तत्त्वाचा नाही. हीच पूर्ण
पुस्तकाची सर्वात मोठी कमाई: **AI ही थेंबूची मोठी आवृत्ती आहे,
वेगळं जग नाही.**

## इथे लोक काय चुकीचं समजतात

"शेकडो मजले म्हणजे यंत्र शेकडो पट 'जास्त हुशार/जागरूक'."
मजले जास्त = जास्त **टप्प्याटप्प्याने अर्थ-शुद्धीकरण**, जागरूकता
नाही. प्रत्येक मजला तेच चार यांत्रिक अवयव चालवतो; "समज"
कुठल्याही एका मजल्यात नाही, ती अनेक साध्या रूपांतरांच्या
साखळीतून **उगवते** (emergence: Book 2, 3.9). "मजला विचार
करतो" ही उपमा; "मजला बाणावर चार गणिती कृती करतो" हे
सत्य. आणि हेच का इतकं चांगलं चालतं: पूर्ण कुणालाच माहीत
नाही (3.6): नम्रता कायम.

## नकाशावर

```
4.1-4.2  attention आकड्यांनी | scaling
4.3  transformer-मजला: attention (बाजार) + जोडणी (residual) +
     एकांत (feed-forward) + ताळमेळ (norm); शेकडो मजले;
     थेंबू ते ChatGPT: तेच तुकडे, अब्जावधी पट
```

**सूत्रावर:** हा chapter पूर्ण चष्मा-प्रवासाचा कळस: ChatGPT चं
हृदय आता थेंबूच्या तुकड्यांचं बनलेलं दिसतं. सर्वात गुंतागुंतीचं
यंत्र सर्वात साध्या कृतींची उंच रचना आहे: आणि ती रचना तुम्ही
आता वाचू शकता.

## स्वतः बघा (5 मिनिटं)

Book 2 चा transformer-chapter (3.8) परत उघडा आणि आता
प्रत्येक उपमेखाली गणित बघा: "बाजार" = attention (dot+softmax+
मिसळण), "एकांत-खोली" = feed-forward (matrix+ReLU), "मजले

आणि तेच खरं समजणं: दोन्ही डोळ्यांनी एकच गोष्ट बघणं.

## विचार करा

थेंबू ChatGPT झाला. पण एक मोठा प्रश्न उरला: "मजले, आकडे,
सगळं कळलं. पण Book 4 म्हणालं 'मोठं यंत्र = जास्त हुशार'

मोठं केलं की हुशारी अंदाजपत्रे वाढते: हे कसं? आणि 'सरळ रेषा'
म्हणजे नक्की कशाची रेषा?"

> Scaling laws हे AI मधलं सर्वात आश्चर्यकारक गणित आहे:
> आकार वाढवला की चूक **अंदाजपत्रे** घटते, आणि ती एका
> विशिष्ट आलेखावर सरळ रेषा येते. ते गणित, आणि त्याचा
> अर्थ: पुढचा chapter.

# Chapter 4.4 [SPINE]: Scaling Laws: सरळ रेषेचं गणित

थेंबूचा प्रश्न: यंत्र मोठं केलं की हुशारी अंदाजपत्रे वाढते: हे
कसं, आणि "सरळ रेषा" कशाची? Scaling laws हे AI मधलं सर्वात
आश्चर्यकारक, आणि व्यावहारिकदृष्ट्या सर्वात महत्त्वाचं गणित आहे
(Book 4 चा अख्खा उद्योग यावर उभा).

**निरीक्षण: आकार वाढवा, चूक अंदाजपत्रे घटते.** संशोधकांना
आढळलं: यंत्र मोठं करा (जास्त weights), data वाढवा, compute
वाढवा: आणि loss (चूक, 2.5) **गुळगुळीत, अंदाजपत्रे** घटते.
इतकी अंदाजपत्रे की छोट्या यंत्रांवरून **मोठ्या यंत्राची चूक आधीच
भाकीत** करता येते (म्हणून labs अब्जावधी खर्चण्याआधी छोट्या
प्रयोगांतून "हे मोठं यंत्र किती चांगलं होईल" ठरवतात). हे विलक्षण:
गुंतागुंतीचं वर्तन, पण त्याची चूक एका साध्या नियमाने पडते.

**"सरळ रेषा" कशाची: log-log आलेख.** साध्या आलेखावर (आकार
विरुद्ध चूक) रेषा वाकडी येते. पण **दोन्ही अक्ष "log" मध्ये**
घेतले (म्हणजे 1, 10, 100, 1000 समान अंतरावर: गुणाकाराचे
टप्पे, बेरजेचे नाही) तर ती वाकडी रेषा **सरळ** होते. याचा अर्थ:
**आकार 10 पट केला की चूक ठराविक टक्क्याने घटते; पुन्हा 10
पट, पुन्हा तेवढीच टक्केवारी.** हा "power law" (घात-नियम):
निसर्गात सर्वत्र (भूकंपांचे आकार, शहरांची लोकसंख्या, संपत्तीचं
वाटप). AI ची चूकही याच कुळात: गुणाकाराच्या टप्प्यांत गुळगुळीत
घट.

**पण इथे कठोर सत्य (आणि आशा):** रेषा सरळ, पण **खाली झुकती**:
प्रत्येक 10-पट सुधारणा **आधीच्याइतकीच टक्केवारी** देते, म्हणजे
**निरपेक्ष सुधारणा घटत जाते** (returns diminish). 100 वरून
1000 (10x) ने जेवढी सुधारणा, 1000 वरून 10000 (पुन्हा 10x,
पण 9000 चा प्रचंड खर्च!) ने तेवढीच टक्केवारी: म्हणजे पुढची
प्रत्येक सुधारणा **प्रचंड महाग.** म्हणूनच Book 4 (2.7) चा
"scaling वळलं": नुसतं मोठं करत राहणं परवडेनासं झालं, म्हणून
खर्च नव्या जागी (post-training, विचार-वेळ) वळला. Scaling
मेलं नाही; **घात-नियमाची किंमत असह्य झाली, म्हणून वाट
बदलली.**

**हे तुमच्यासाठी का महत्त्वाचं:** (1) scaling laws समजले की
"पुढचं यंत्र किती चांगलं" या चर्चा तुम्ही आकड्यांनी वाचता,
hype ने नाही. (2) "AI अनंत वाढेल" (घात-नियम विसरून) आणि
"AI थांबलं" (एका सपाटीकडे बघून) दोन्ही अतिरेक ओळखता:
खरं मधे, घातनियमाच्या झुकत्या रेषेवर. (3) आणि सर्वात खोल:
**एका साध्या रेषेने अब्जावधींचे निर्णय ठरतात** (labs किती
खर्चायचं ठरवतात): गणिताचा चष्मा किती शक्तिशाली, याचं हे
टोक.

## इथे लोक काय चुकीचं समजतात

"Scaling laws म्हणजे यंत्र मोठं केलं की अनंत हुशार होईल."
घात-नियमाची झुकती रेषा हेच नाकारते: सुधारणा **घटत** जाते,
आणि खर्च **स्फोटक** वाढतो. आणि उलट गैरसमज: "एका सुधारणेचा
वेग मंदावला = scaling मेलं." नाही: रेषा अजून सरळ (सुधारणा
सुरू), फक्त निरपेक्ष घट लहान आणि खर्च मोठा. दोन्ही टोकं
(अनंत-आशा, संपूर्ण-निराशा) घातनियम न समजल्याने येतात.
रेषा वाचता आली की दोन्ही भ्रम विरतात.

## नकाशावर

```
4.1-4.3  attention | scaling(softmax) | transformer-मजला
4.4  scaling laws: आकार 10x -> चूक ठराविक % घट (घात-नियम);
     log-log आलेखावर सरळ-झुकती रेषा; सुधारणा घटती, खर्च
     स्फोटक -> "scaling वळलं"; रेषा वाचा, hype नको
```

**सूत्रावर:** scaling laws हा सर्वात भव्य चष्मा: AI च्या भवितव्याचा
अंदाज एका सरळ रेषेत मोजता येतो. जे मोजता येतं (चूकीचा कल)
त्यावर अब्जावधींचे निर्णय ठरतात: गणित इथे भविष्यवाणीचं साधन
होतं.

## स्वतः बघा (5 मिनिटं)

एक घात-नियम रोजचा: तुमच्या अभ्यासात/कौशल्यात पहिले 10
तास मोठी झेप देतात; पुढचे 10 कमी; पुढचे 10 अजून कमी
(diminishing returns). पण थांबत नाही: प्रत्येक "दुप्पट मेहनत"
ठराविक सुधारणा देतच राहते, फक्त लहान. AI ची चूकही असंच
वागते. तुमच्या 90-दिवस-प्रवासालाही (The Climb) हेच लागू:
सुरुवात झपाट्याने, नंतर संथ-पण-सतत.

# Chapter 4.5 [SPINE]: Paper वाचण्याची कला

पूर्ण पुस्तकाची खरी परीक्षा: एक खरा AI-paper उघडून वाचणं.
कारण top 0.00001 ची सीमारेषा नेमकी हीच: papers स्वतः वाचता
येणं. आणि हे chapter सांगतं की ती भीती **रचनेची** आहे, बुद्धीची
नाही: आणि रचना शिकता येते.

**आधी दिलासा: papers तुमच्यासाठीच लिहिलेली नाहीत.** AI-papers
तज्ज्ञांनी तज्ज्ञांसाठी, संक्षिप्त, प्रतीकांनी भरून लिहिलेली असतात:
वाचकाला घाबरवायला नाही, पण **तसाच परिणाम** होतो. म्हणून
पहिला नियम: **paper "समजलं नाही" म्हणजे तुम्ही कमी नाही;
paper दुर्बोध भाषेत आहे.** आणि दुसरा: **पहिल्यांदा 100% समजायचं
नसतंच**; अनुभवी संशोधकही paper 3-4 वेळा, वाढत्या खोलीने
वाचतात.

**वाचनाचा क्रम (छापून ठेवा): बाहेरून आत.** paper पहिल्या
ओळीपासून शेवटपर्यंत वाचू नका (तिथेच लोक बुडतात). ऐवजी
थरांनी:

```
थर 1 (5 मिनिटं): फक्त शीर्षक + सारांश (abstract) + निष्कर्ष
   (conclusion) + आकृत्यांचे कॅप्शन. प्रश्न: "हे कुठलं दुखणं
   सोडवतात, आणि निकाल काय?" (Book 1-4 चं जुनं सूत्र!)
थर 2 (15 मिनिटं): प्रस्तावना (intro) + प्रत्येक विभागाचं
   पहिलं वाक्य. प्रश्न: "त्यांची मुख्य कल्पना काय, आधीच्यापेक्षा
   वेगळं काय?"
थर 3 (खोल, गरज असेल तर): पद्धत (method) + आकडे नीट.
   इथे गणित येतं: आणि आता तुमच्याकडे चष्मा आहे: dot,
   softmax, gradient, attention: बहुतेक प्रतीकं ओळखीची.
```

बहुतेक papers साठी थर 1-2 पुरतात ("हे काय, का, किती चांगलं").
थर 3 फक्त जे तुम्ही खरंच वापरणार/खोदणार त्यासाठी. **90%
मूल्य पहिल्या 20 मिनिटांत**; उरलेलं 10% साठी तास.

**प्रतीकांना घाबरू नका (सर्वात मोठा अडथळा).** paper मधली
भीतीदायक सूत्रं बहुधा तुम्हाला **आता माहीत असलेल्या** गोष्टीच:
"softmax(QK^T / root(d)) V" हे भयंकर दिसतं, पण तुम्ही ते
आत्ता वाचू शकता: Q,K,V = query-key-value बाण (4.1); QK^T =
query-key चे dot products (जुळणी-गुण); /root(d) = scaling
(4.2); softmax = लक्ष-वाटप (2.6); V = values ची भारित बेरीज.
**अख्खं attention एका ओळीत, आणि प्रत्येक तुकडा तुम्हाला माहीत.**
हीच पूर्ण पुस्तकाची कमाई: प्रतीक बघून घाबरण्याऐवजी "हा कुठला
ओळखीचा तुकडा" विचारणं. एक अनोळखी प्रतीक आलं तर थांबा,
शोधा, तो एक तुकडा समजून घ्या: paper तुकड्यांचं बनलेलं आहे,
अभेद्य भिंत नाही.

**आणि सर्वात मोठा गुपित (Book 4 शी पूल): AI आता paper
वाचायला मदत करतं.** अडलेलं प्रतीक/परिच्छेद AI ला विचारा
"हे सोप्या भाषेत समजाव": पण **आंधळेपणाने नाही**: तुमच्या
चष्म्याने त्याचं उत्तर **तपासा** (Book 4 चं evals-भान). AI +
तुमचा गणिती पाया = papers ची भीती कायमची संपते. जो हे
जोडतो (पाया + AI-मदत + तपासणी) तो कुठलंही नवं संशोधन,
आठवड्याच्या आत, वाचू-समजू शकतो: आणि तेच top 0.00001 चं
खरं रहस्य: **नवं ज्ञान स्वतः पचवण्याची यंत्रणा.**

## इथे लोक काय चुकीचं समजतात

"Papers फक्त PhD-वाल्यांसाठी; मी वाचूच शकत नाही." खोटं,
आणि आत्म-पराभवी. papers दुर्बोध **भाषेत** आहेत, दुर्बोध
**कल्पनांचं** नाहीत (बहुतेकदा): आणि भाषेचा अडथळा थर-वाचन +
चष्मा + AI-मदत ने ओलांडता येतो. आणि उलट: "मी एक paper
वाचलं, सगळं समजलं, आता मी तज्ज्ञ." एक paper = एक तुकडा;
खरी समज अनेक papers, प्रयोग, वेळ यांतून. नम्रता दोन्ही
बाजूंनी: "वाचू शकतो" (आत्मविश्वास) आणि "सगळं कळलं नाही"
(प्रामाणिकपणा): दोन्ही एकत्र.

कुणाच्या "सांगण्यावर" विसंबावं लागत नाही: तीच खरी बौद्धिक

पूर्ण पुस्तक संपत आलंय. थेंबू ChatGPT झाला, आणि थेंबूचा
मालक (तुम्ही) papers वाचू शकतो. शेवटचा प्रश्न, जो सगळं
एका परीक्षेत बांधेल: "मी हे सगळं शिकलो: दिशा, शक्यता, उतार,

जास्त?"

> तेच अंतिम परीक्षा ठरवेल: आणि उत्तर तुम्हाला माहीत आहे,
> फक्त शब्दांत यायचंय. गणिताचा चष्मा तुम्हाला "समजणाऱ्यां"
> कडून "तपासणाऱ्यां" कडे, आणि "ऐकणाऱ्यां" कडून "वाचणाऱ्यां"
> कडे नेतो: आणि तिथेच खरं leverage आहे. अंतिम परीक्षा,
> पुढे.

# Chapter 4.6 [SPINE]: अंतिम परीक्षा

नियम आधीसारखेच: पुस्तक न उघडता, **बोलून** उत्तर द्या; गाभा
खाली. हेतू गुण नाही: **गणिताचा चष्मा मुरला का** हे बघणं.

**भाग अ: गणित मुरलं का (5 प्रश्न)**

**1.** "यंत्राला शब्दाचा अर्थ कसा कळतो" चं पूर्ण गणिती उत्तर?

> अर्थ = दिशा; शब्दाला आकड्यांचा बाण (embedding); जवळच्या
> दिशा = जवळचे अर्थ; जवळीक = dot product ने मोजतात. (1.1,
> 1.2, 1.5)

**2.** "यंत्र शिकतं" पाच पायऱ्यांत, आणि "चूक" नक्की काय?

> forward (अंदाज) -> loss (cross-entropy: खऱ्याला दिलेली
> probability) -> backward (chain rule ने प्रत्येक weight चा
> उतार) -> update (उलट उतार, learning rate) -> पुन्हा. (2.5,
> 3.3, 3.4)

**3.** Attention तीन कृतींत?

> dot (query-key जुळणी-गुण) -> softmax (लक्ष-वाटप) ->
> weighted sum (values ची भारित मिसळण). (4.1)

**4.** "AI मोठं केलं की हुशार" चं गणित, आणि दोन्ही टोकांचे भ्रम?

> scaling laws: आकार 10x -> चूक ठराविक % घट (घात-नियम,
> log-log सरळ-झुकती रेषा); सुधारणा घटती + खर्च स्फोटक. भ्रम:
> "अनंत वाढ" आणि "पूर्ण थांबलं" दोन्ही रेषा न वाचल्याने. (4.4)

**5.** "AI का चालतं" चं प्रामाणिक उत्तर?

> पूर्ण कुणालाच माहीत नाही (किमया > विज्ञान); सीमेवर सगळे
> नवखे; समजून नाही, मोजून प्रगती. (3.6)

**भाग ब: थेंबू ते ChatGPT, आणि leverage (5 प्रश्न)**

**6.** softmax मध्ये गुण आधी का भागतात (scaling)?

> मोठे बाण -> मोठे dot-गुण -> अति-तीव्र softmax -> gradient
> मरतो, शिकणं थांबतं; root(d) ने भागून गुण वाजवी, softmax मऊ. (4.2)

**7.** transformer-मजल्याचे चार अवयव?

> attention (बाजार: संदर्भ मिसळणं) + जोडणी (residual: जुनं
> ठेवून नवं) + एकांत (feed-forward: पचवणं) + ताळमेळ (norm).
> शेकडो मजले. (4.3)

**8.** थेंबू आणि ChatGPT यांत तत्त्वाचा फरक आहे का?

> नाही: तेच तुकडे (बाण, dot, matrix, softmax, gradient), फक्त
> 3 weights ऐवजी अब्जावधी, शेकडो मजले उंच. फरक आकाराचा,
> तत्त्वाचा नाही. (4.3)

**9.** भीतीदायक सूत्र (उदा softmax(QK^T/root(d))V) समोर आलं तर?

> तुकड्यांत फोडा: Q,K,V=बाण, QK^T=dot-जुळणी, /root(d)=scaling,
> softmax=लक्ष, V=भारित बेरीज = attention. प्रत्येक तुकडा
> ओळखीचा; प्रतीकाला घाबरू नका, तुकडा शोधा. (4.5)

**10.** गणित शिकण्याचा **खरा** उपयोग काय (नुसतं "समजलं" पलीकडे)?

> papers/दावे **स्वतः वाचता-तपासता येणं**: कुणाच्या सांगण्यावर
> विसंबावं लागत नाही. "समजणाऱ्या" कडून "तपासणाऱ्या" कडे,
> "ऐकणाऱ्या" कडून "वाचणाऱ्या" कडे: तेच leverage (Book 4, 9.2).
> (4.5, 1.6)

---

आणि आता **खरी** अंतिम परीक्षा: वरचे दहा नाही, **खालचा एक**,
ज्याचं उत्तर पुस्तकात नाही, फक्त तुमच्याकडे आहे.

पुस्तकाच्या सुरुवातीला (front matter) एक भीती होती: "गणित
म्हणजे सूत्रं-घोकंपट्टी, माझ्या आवाक्याबाहेर." आता, थेंबूला हाताने
शिकवल्यावर, attention आकड्यांनी काढल्यावर, तो कागद पुन्हा
बघा. भीती कुठे गेली? बहुधा तिची जागा एका शांत आत्मविश्वासाने
घेतली:

> "AI मध्ये कुठेही जादू नाही. फक्त आकडे: बाण, गुणाकार,
> बेरीज, उतार. आणि आकडे मला समजतात. म्हणून AI मला
> समजतं: उपमेने नाही, **गणिताने.** आणि जे मला गणिताने
> समजतं, त्यावर मी कुणाच्या 'सांगण्यावर' विसंबत नाही: मी
> स्वतः तपासतो. हीच माझी उरलेली, न-नकलता-येणारी ताकद."

थेंबूपासून ChatGPT पर्यंतचा प्रवास हेच शिकवतो: **सर्वात
गुंतागुंतीचं यंत्रही सर्वात साध्या कृतींची उंच रचना आहे**, आणि
त्या साध्या कृती तुम्हाला येतात. जादू संपली; चष्मा उरला.

## शेवटचं "स्वतः बघा" (आयुष्यभराचं)

आजपासून, कुठलंही AI-सूत्र, कुठलाही "यंत्र हे करतं" चा दावा,
कुठलाही paper: तीन प्रश्न विचारा: **"याखालचं गणित कुठलं,
आणि ते मला माहीत असलेल्या तुकड्यांचं बनलंय का?"** (Part 1-3),
**"हा दावा किती वेळा, किती स्वच्छ चालतो: मोजलंय का?"** (1.6),
आणि **"हे मी स्वतः वाचून-तपासू शकतो, की फक्त ऐकतोय?"**
(4.5). हे तीन प्रश्न तुम्हाला AI-गर्दीतल्या कवितेतून आणि विक्रीतून
कायमचे वेगळे काढतील: कारण तुमच्याकडे चष्मा आहे, आणि
चष्मा असलेला माणूस भुलत नाही: तो बघतो.

# सूत्र-पत्र: सगळं गणित एका पानावर (भिंतीवर लावा)

(थेंबूचा ChatGPT होण्याचा पूर्ण नकाशा, एका पानात.)

**दिशांचं जग (Part 1):**

```
vector       आकड्यांची यादी = दिशा (बाण); अर्थ = दिशा
dot product  जोडीने गुणा + बेरीज = जवळिकीचं माप
             सारखे->मोठा, लंब->शून्य, उलटे->उणे
matrix       रूपांतर-यंत्र (अनेक dot); बाण आत, फिरवलेला बाण बाहेर
             weights = matrix-आकडे
साखळी+खोली   रूपांतर + वाकडी कृती (ReLU), वारंवार = खोली
उच्च मिती    जागा स्फोटक (अर्थ मावतात); डोळे फसतात, गणित खरं
```

**शक्यतांचं जग (Part 2):**

```
probability  विश्वासाचं माप (0-1); बेरीज=1; खात्री-बरोबर वेगळे
distribution शक्यतांचा आकार; तीव्र=खात्री, सपाट=गोंधळ
Bayes        नवं मत = जुनं मत + पुरावा; दुर्मिळतेचा विसर = चूक
entropy      आश्चर्याचं माप; शिकणं = आश्चर्य कमी करणं
cross-entropy loss = खऱ्याला दिलेल्या खात्रीची शिक्षा
softmax+temp गुण -> probability (स्फोट+भागा); temp = धीटपणा-कळ
```

**उताराचं जग (Part 3):**

```
derivative   बदलाचा दर; पायाखालचा उतार
gradient     सगळ्या weights चे उतार (बाण); उलट जा = शिकणं
chain rule   दर गुणत loss मागे वाटणं (backprop)
थेंबू-पाऊल   forward(अंदाज) -> loss -> backward(उतार) ->
             update(उलट, learning rate) -> पुन्हा
का चालतं     पूर्ण कुणालाच माहीत नाही; मोजून प्रगती
```

**परत AI कडे (Part 4):**

```
attention    dot(जुळणी) -> softmax(लक्ष) -> weighted sum(मिसळण)
scaling      root(d) ने भागा: softmax मऊ, शिकणं जिवंत
transformer  attention + जोडणी + एकांत + ताळमेळ; शेकडो मजले
scaling laws आकार 10x -> चूक % घट (घात-नियम, log-log रेषा)
paper-वाचन   बाहेरून-आत; प्रतीक = ओळखीचे तुकडे; AI-मदत+तपास
```

**थेंबू ते ChatGPT (एका ओळीत):**

```
शब्द -> बाण(embedding) -> [attention+एकांत] x शेकडो मजले
     -> शेवटचा बाण -> softmax -> पुढचा token -> पुन्हा
शिकलं: gradient descent + backprop, ट्रिलियन पावलं.
तेच थेंबूचे तुकडे, अब्जावधी पट. जादू नाही, आकडे.
```

**तीन आयुष्यभराचे प्रश्न:**

```
1. याखालचं गणित कुठलं, माझ्या तुकड्यांचं बनलंय का? (Part 1-3)
2. हा दावा किती वेळा, किती स्वच्छ चालतो: मोजलंय का? (1.6)
3. हे मी स्वतः वाचून-तपासू शकतो, की फक्त ऐकतोय? (4.5)

सूत्र: गणित म्हणजे न दिसणारं दाखवणारा चष्मा.
जे मोजता येतं ते सुधारता येतं; ते तपासताही येतं.
```
