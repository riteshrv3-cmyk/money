# सूत्र-पत्र: सगळं गणित एका पानावर (भिंतीवर लावा)

(थेंबूचा ChatGPT होण्याचा पूर्ण नकाशा, एका पानात.)

**दिशांचं जग (Part 1):**

```
vector       आकड्यांची यादी = दिशा (बाण); अर्थ = दिशा
dot product  जोडीने गुणा + बेरीज = जवळिकीचं माप
             सारखे->मोठा, लंब->शून्य, उलटे->उणे
matrix       रूपांतर-यंत्र (अनेक dot); बाण आत, फिरवलेला बाण बाहेर
             weights = matrix-आकडे
साखळी+खोली   रूपांतर + वाकडी कृती (ReLU), वारंवार = खोली
उच्च मिती    जागा स्फोटक (अर्थ मावतात); डोळे फसतात, गणित खरं
```

**शक्यतांचं जग (Part 2):**

```
probability  विश्वासाचं माप (0-1); बेरीज=1; खात्री-बरोबर वेगळे
distribution शक्यतांचा आकार; तीव्र=खात्री, सपाट=गोंधळ
Bayes        नवं मत = जुनं मत + पुरावा; दुर्मिळतेचा विसर = चूक
entropy      आश्चर्याचं माप; शिकणं = आश्चर्य कमी करणं
cross-entropy loss = खऱ्याला दिलेल्या खात्रीची शिक्षा
softmax+temp गुण -> probability (स्फोट+भागा); temp = धीटपणा-कळ
```

**उताराचं जग (Part 3):**

```
derivative   बदलाचा दर; पायाखालचा उतार
gradient     सगळ्या weights चे उतार (बाण); उलट जा = शिकणं
chain rule   दर गुणत loss मागे वाटणं (backprop)
थेंबू-पाऊल   forward(अंदाज) -> loss -> backward(उतार) ->
             update(उलट, learning rate) -> पुन्हा
का चालतं     पूर्ण कुणालाच माहीत नाही; मोजून प्रगती
```

**परत AI कडे (Part 4):**

```
attention    dot(जुळणी) -> softmax(लक्ष) -> weighted sum(मिसळण)
scaling      root(d) ने भागा: softmax मऊ, शिकणं जिवंत
transformer  attention + जोडणी + एकांत + ताळमेळ; शेकडो मजले
scaling laws आकार 10x -> चूक % घट (घात-नियम, log-log रेषा)
paper-वाचन   बाहेरून-आत; प्रतीक = ओळखीचे तुकडे; AI-मदत+तपास
```

**थेंबू ते ChatGPT (एका ओळीत):**

```
शब्द -> बाण(embedding) -> [attention+एकांत] x शेकडो मजले
     -> शेवटचा बाण -> softmax -> पुढचा token -> पुन्हा
शिकलं: gradient descent + backprop, ट्रिलियन पावलं.
तेच थेंबूचे तुकडे, अब्जावधी पट. जादू नाही, आकडे.
```

**तीन आयुष्यभराचे प्रश्न:**

```
1. याखालचं गणित कुठलं, माझ्या तुकड्यांचं बनलंय का? (Part 1-3)
2. हा दावा किती वेळा, किती स्वच्छ चालतो: मोजलंय का? (1.6)
3. हे मी स्वतः वाचून-तपासू शकतो, की फक्त ऐकतोय? (4.5)

सूत्र: गणित म्हणजे न दिसणारं दाखवणारा चष्मा.
जे मोजता येतं ते सुधारता येतं; ते तपासताही येतं.
```
