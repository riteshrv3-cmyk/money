# Chapter 4.1 [SPINE]: Attention आकड्यांनी: पायरी-पायरी

हा chapter म्हणजे पूर्ण पुस्तकाचा कळस: **attention, आकड्यांनी,
हाताने.** Book 2 ने उपमा दिली (query = मागणी, key = पाटी,
value = माल); आता ती उपमा **आकड्यांत** बघू. कागद-पेन घ्या.

**रचना: तीन शब्द, प्रत्येकाला तीन बाण.** एक छोटं वाक्य: "पाऊस
आज पडेल." attention चं काम: प्रत्येक शब्दाने इतर शब्दांकडे
**किती लक्ष द्यायचं** ठरवून, त्यानुसार माहिती मिसळणं. प्रत्येक
शब्दाला तीन बाण (हे matrices ने बनतात, Part 1; इथे तयार
धरू):

```
शब्द    query (q)    key (k)      value (v)
पाऊस    -            (1, 0)       (2, 0)
आज      -            (0, 1)       (0, 2)
पडेल    (1, 0)       (0.5, 0.5)   (1, 1)
```

query = "मला काय शोधायचंय"; key = "माझ्याकडे काय आहे";
value = "मी काय माहिती देईन." आपण **"पडेल" या शब्दाचं
attention** काढू: तो इतर शब्दांकडे किती लक्ष देतो?

**पायरी 1: जुळणी-गुण (query · प्रत्येक key): dot product (1.2).**
```
पडेल·पाऊस = (1,0)·(1,0)   = 1x1 + 0x0   = 1.0   (जुळतं!)
पडेल·आज   = (1,0)·(0,1)   = 1x0 + 0x1   = 0.0   (जुळत नाही)
पडेल·पडेल = (1,0)·(0.5,0.5)= 1x0.5+0x0.5 = 0.5   (थोडं)
```
"पडेल" ची मागणी (1,0) "पाऊस" च्या पाटीशी (1,0) सर्वात जुळते.
गुण: 1.0, 0.0, 0.5.

**पायरी 2: गुणांचं लक्ष-वाटप (softmax, 2.6).** हे गुण probability
मध्ये (बेरीज 1):
```
स्फोट: e^1=2.72,  e^0=1.0,  e^0.5=1.65
बेरीज: 2.72+1.0+1.65 = 5.37
लक्ष: पाऊस 2.72/5.37=0.51,  आज 1.0/5.37=0.19,  पडेल 1.65/5.37=0.31
```
म्हणजे "पडेल" आपलं **51% लक्ष "पाऊस" कडे**, 19% "आज" कडे,
31% स्वतःकडे देतो. हेच "attention weights": कुणाकडे किती
बघायचं.

**पायरी 3: माहिती मिसळा (लक्ष x value यांची बेरीज).** आता
प्रत्येक शब्दाचा value-बाण त्याच्या लक्ष-वाट्याने घ्या, बेरीज करा:
```
output = 0.51 x (2,0) + 0.19 x (0,2) + 0.31 x (1,1)
       = (1.02, 0)   + (0, 0.38)   + (0.31, 0.31)
       = (1.33, 0.69)
```
झालं. "पडेल" चा नवा बाण = **(1.33, 0.69):** मुख्यतः "पाऊस"
च्या माहितीने (2,0) रंगलेला, कारण तिकडे सर्वात जास्त लक्ष.
**हेच attention:** प्रत्येक शब्दाने इतरांकडे लक्ष-वाटून, त्यांची
माहिती स्वतःत मिसळणं. "पडेल" ला आता "पाऊस" चा संदर्भ
कळला: वाक्याचा अर्थ त्याच्या बाणात उतरला.

**हेच ChatGPT करतं, फक्त:** 3 शब्द ऐवजी हजारो, 2-आकड्यांचे
बाण ऐवजी शेकडो-आकड्यांचे, आणि एका "लक्ष-नजरे" ऐवजी अनेक
समांतर (multi-head: प्रत्येक नजर वेगळं नातं बघते: कोण-कुणाशी
व्याकरण, कोण-कुणाशी अर्थ). पण **कृती तीच जी तुम्ही आत्ता
केलीत:** dot (जुळणी) -> softmax (लक्ष) -> weighted sum
(मिसळण). Book 2 चा "मागणी-पाटी-माल बाजार" आता तीन ओळींचं
अंकगणित आहे. Attention चं गूढ संपलं.

## इथे लोक काय चुकीचं समजतात

"Attention म्हणजे यंत्र 'लक्ष देतं', म्हणजे त्याला जाणीव/समज
आहे." नाही: "लक्ष" हा फक्त softmax-चा वाटप-आकडा आहे
(0.51, 0.19, 0.31). यंत्र "बघत" नाही, "जाणत" नाही; ते dot
products चे गुण softmax मधून probability करतं आणि values
ची भारित बेरीज घेतं. "attention" हे काव्यात्मक नाव आहे,
यांत्रिक कृतीला. जाणीव तिथे नाही, फक्त जुळणी-वाटप-मिसळण
आहे. (हा भेद Book 2 च्या "यंत्राला समज आहे का" वादाचा गाभा.)

शब्दांचा संदर्भ कसा जोडतं) पूर्ण आकड्यांत दिसलं. जादू कायमची
संपली; समज उरली.

## स्वतः बघा (5 मिनिटं)

वरचं attention स्वतः, हाताने करा: पण "पाऊस" या शब्दाचं
(त्याचा query असेल समजा (0,1)). कुठल्या शब्दाकडे तो सर्वात
जास्त लक्ष देईल? (key (0,1) असलेल्या "आज" कडे.) एकदा हाताने
केलंत की attention चा "बाजार" तुमच्या बोटांत उतरेल: आणि
कुठलाही transformer-paper वाचताना हे चित्र डोळ्यांसमोर येईल.
