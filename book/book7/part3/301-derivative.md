# Chapter 3.1 [SPINE]: Derivative: बदलाचा दर

उतार समजायला आधी एक साधी कल्पना: **derivative** (बदलाचा
दर). आणि ती इतकी रोजची आहे की तुम्ही ती वापरता, फक्त नाव
माहीत नाही.

**Derivative म्हणजे काय.** एका आकड्याला थोडं ढकललं, तर
दुसरा आकडा **किती** बदलतो? गाडीचा वेग म्हणजे derivative:
"वेळ थोडा पुढे गेला, तर अंतर किती वाढलं." थेंबूवर: "weight
थोडं वाढवलं, तर loss किती बदलली?" हाच प्रश्न, आणि त्याचं
उत्तर = derivative. एका ओळीत: **derivative = परिणामाचा दर =
"इथे थोडं हललं तर तिथे किती हलतं."**

**आकड्यांनी बघू (थेंबूचं सोपं रूप).** समजा थेंबूचा loss हा एका
weight w वर असा अवलंबून आहे: loss = (w - 3)². म्हणजे w =
3 ला loss शून्य (सर्वोत्तम), आणि w जसजसा 3 पासून दूर, तसतशी
loss वाढते (एक खोरं, तळाशी w=3). आता derivative विचारतो:
"w = 5 ला उभं राहून थोडं हललं तर loss कुठे जाईल?"

```
w = 5:   loss = (5-3)² = 4
w = 5.1: loss = (5.1-3)² = 2.1² = 4.41   (वाढली!)
w = 4.9: loss = (4.9-3)² = 1.9² = 3.61   (घटली!)
```

म्हणजे w = 5 ला: w **वाढवलं** तर loss वाढते; w **घटवलं**
तर loss घटते. Derivative हा दर आणि दिशा दोन्ही सांगतो:
इथे तो **धन** (positive) आहे ("w वाढला की loss वाढते"),
आणि आकार सांगतो किती वेगात. आणि इथे शिकण्याची गुरुकिल्ली:
**loss कमी करायची तर derivative च्या उलट दिशेला जा.**
derivative धन (w वाढला की loss वाढते) -> म्हणून w **कमी**
करा (उताराच्या खाली, w=3 कडे). हेच "उतार उतरणं."

**डोंगराची उपमा (Book 2 चा धुका).** loss = एक डोंगराळ भूभाग,
उंची = चूक. तुम्ही एका जागी (w = 5) उभे, तळ (कमीत कमी
loss) शोधायचाय, पण धुक्यामुळे पूर्ण नकाशा दिसत नाही. Derivative
म्हणजे: **तुमच्या पायाखालचा उतार**: "इथे जमीन कुठल्या दिशेला
झुकलीये, किती तीव्र." उतार कळला की एक पाऊल **खाली** टाका
(loss कमी होईल त्या दिशेला). पुन्हा उतार बघा, पुन्हा पाऊल.
हळूहळू तळाकडे. Derivative = पायाखालच्या उताराचं मोजमाप:
पूर्ण नकाशा नाही, पण पुढचं एक पाऊल पुरेसं.

## इथे लोक काय चुकीचं समजतात

"Derivative म्हणजे किचकट calculus, सूत्रं." मूळ कल्पना साधी:
"इथे थोडं हललं तर तिथे किती हलतं." तुम्ही ती रोज वापरता
(वेग = अंतराचा derivative, प्रवेग = वेगाचा). AI मध्ये लागणारं
derivative फक्त काही मूठभर नियमांचं (कोणतं फार महत्त्वाचं
नाही; कल्पना महत्त्वाची). आणि दुसरा गैरसमज: "derivative
म्हणजे उत्तर." नाही: derivative म्हणजे **दिशा** (पुढचं पाऊल
कुठे), उत्तर नाही: उत्तर मिळतं अनेक पावलं टाकून (3.4).

## नकाशावर

(दर chapter ला एक ओळ.)

```
3.1  derivative = बदलाचा दर ("इथे हललं तर तिथे किती");
     पायाखालचा उतार; loss कमी करायला उलट दिशेला जा
```

**सूत्रावर:** derivative हा चष्मा "सुधारायचं तर कुठे सरकावं"
हे **मोजून** दाखवतो: अंदाजाने नाही, दराने. जे मोजता येतं
(उतार) त्या दिशेने सुधारता येतं (खाली पाऊल): हेच शिकण्याचं
यांत्रिक हृदय.

## स्वतः बघा (5 मिनिटं)

डोंगरउतारावर चेंडू सोडला तर तो **सर्वात तीव्र उताराच्या** दिशेने
घरंगळतो, तळाकडे. का? कारण गुरुत्व त्याला "derivative च्या
उलट" ढकलतं. यंत्राचं शिकणं तेच: loss-डोंगरावर weight-चेंडू
उताराने खाली. निसर्ग हेच गणित वापरतो; आपण फक्त त्याला
आकड्यांत मांडलं.

## विचार करा

थेंबूला एकच weight असेल तर उतार सोपा (एका दिशेला खाली).
पण थेंबूला **दोन** weights आहेत (आर्द्रता आणि ढगांचे), आणि
खऱ्या यंत्राला अब्जावधी. "एका weight चा उतार कळला; पण
लाखो weights एकाच वेळी, प्रत्येकाचा loss वर वेगळा परिणाम:
सगळ्यांचे उतार एकत्र कसे काढायचे, आणि कुठल्या दिशेला
सगळ्यांनी मिळून जायचं?"

> सगळ्या weights चे उतार एकत्र म्हणजे एक "उतार-बाण" (Part 1
> चा vector!): तो सगळ्यात तीव्र-उताराची दिशा दाखवतो. त्याचं
> नाव gradient. पुढचा chapter.
