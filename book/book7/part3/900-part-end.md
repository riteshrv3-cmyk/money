## जे तुमच्याकडे आता आहे

```
derivative    बदलाचा दर ("इथे हललं तर तिथे किती"); पायाखालचा
              उतार; loss कमी करायला उलट दिशेला जा
gradient      सगळ्या weights चे उतार एकत्र (बाण); सर्वात तीव्र
              चढ -> उलट जा (gradient descent); धुक्यात पावलापावलाने
chain rule    प्रत्येक थराचा दर गुणत loss मागे वाटणं (backprop);
              forward (अंदाज) + backward (दोष-वाटप) = शिकणं
थेंबू हाताने   forward 1.4 -> loss 0.16 -> उतार गुणा -> weights
              कमी -> नवी loss 0.0576; हेच ChatGPT, अब्जावधी पट
learning rate पावलाचा आकार (छोटं=कासव, मोठं=भरकटणं); अडकणं ->
              थोडा गोंधळ + गती सोडवतात
का चालतं      पूर्ण सिद्धांत नाही (किमया); सीमेवर सगळे नवखे;
              समजून नाही, मोजून प्रगती; नम्रता = वृत्ती
```

## स्वतःची परीक्षा (4 प्रश्न, बोलून; उत्तरं खाली)

**1.** "यंत्र शिकतं" चं पूर्ण गणित पाच पायऱ्यांत?

> forward (अंदाज) -> loss (चूक मोजा) -> backward (chain rule
> ने प्रत्येक weight चा उतार) -> update (उताराच्या उलट, learning
> rate ने) -> पुन्हा. loss घसरते. (3.4)

**2.** Gradient बाण काय दाखवतो, आणि आपण काय करतो?

> सर्वात तीव्र **चढाची** दिशा; loss कमी करायला त्याच्या **उलट**
> पाऊल (gradient descent). (3.2)

**3.** Backpropagation म्हणजे "यंत्र मागे विचार करतं" का?

> नाही: शुद्ध गुणाकार: प्रत्येक थराचा दर गुणत loss मागे, प्रत्येक
> weight ला त्याचा दोष-वाटा. बुद्धी नाही, अंकगणित. (3.3)

**4.** "AI का चालतं" चं प्रामाणिक उत्तर, आणि त्याचा धडा?

> पूर्ण कुणालाच माहीत नाही (किमया > विज्ञान); म्हणून सीमेवर
> सगळे नवखे (मुक्त करणारं), आणि जिथे सिद्धांत अपुरा तिथे
> मोजमाप (evals) हेच सत्य. (3.6)

## पुढच्या भागाची चाहूल

थेंबूचं सगळं गणित (बाण, dot, matrix, probability, softmax,
gradient) आता attention मध्ये एकत्र येईल. Part 4: परत AI

हाताने, scaling laws चं गणित, आणि एक खरा paper उलगडून
