# Chapter 3.4 [SPINE]: थेंबूला हाताने शिकवू: पूर्ण एक पाऊल

हा पूर्ण पुस्तकातला सर्वात महत्त्वाचा chapter. इथे आपण थेंबूला
**प्रत्यक्ष, हाताने, एका शिकवणी-पावलातून** नेऊ: एकही पायरी न
वगळता, खऱ्या आकड्यांनी. हे एकदा डोळ्यांनी घडताना बघितलं की
"यंत्र शिकतं" हे वाक्य कायमचं उघडं होईल. कागद-पेन घ्या; सोबत
करा.

**थेंबूची रचना (सर्वात सोपी).** थेंबू एका ओळीचं यंत्र:
```
अंदाज p = w1 x आर्द्रता  +  w2 x ढग  +  b
```
w1, w2 = आर्द्रता आणि ढगांना दिलेली महत्त्वं (weights); b =
एक स्थिर सरकवण (bias). आजची माहिती: आर्द्रता = 0.8, ढग =
0.6. सुरुवातीचे (कच्चे, न-शिकलेले) weights: w1 = 1.0, w2 =
1.0, b = 0. खरं घडलं: **पूर्ण पाऊस, म्हणजे लक्ष्य y = 1.**

**पायरी 1: पुढे (forward): अंदाज काढा.**
```
p = 1.0 x 0.8  +  1.0 x 0.6  +  0
  = 0.8 + 0.6
  = 1.4
```
थेंबूचा अंदाज 1.4. पण खरं लक्ष्य 1. म्हणजे थेंबू **अति-आत्मविश्वासाने**
जास्त बोलला (1 हवं होतं, 1.4 दिलं).

**पायरी 2: चूक (loss) मोजा.** सोप्या loss = (अंदाज - खरं)²:
```
loss = (p - y)²  =  (1.4 - 1)²  =  0.4²  =  0.16
```
चूक 0.16. आता ती कमी करायची.

**पायरी 3: मागे (backward): प्रत्येक weight चा उतार (chain
rule, 3.3).** प्रश्न: प्रत्येक weight थोडा बदलला तर loss किती
बदलेल?

```
आधी loss चा अंदाजावरचा दर:
  dLoss/dp = 2 x (p - y) = 2 x (1.4 - 1) = 2 x 0.4 = 0.8

आता अंदाजाचा प्रत्येक weight वरचा दर (p = w1x0.8 + w2x0.6 + b):
  dp/dw1 = आर्द्रता = 0.8
  dp/dw2 = ढग       = 0.6
  dp/db  = 1

chain rule ने गुणा (दर मागे वाटा):
  w1 चा उतार = 0.8 x 0.8 = 0.64
  w2 चा उतार = 0.8 x 0.6 = 0.48
  b  चा उतार = 0.8 x 1   = 0.80
```

तिन्ही उतार **धन** (positive): अर्थ "हा weight वाढवला तर loss
वाढेल." म्हणून तिन्ही weights **कमी** करायचे (उलट दिशा: 3.2).
आणि लक्षात घ्या: w1 चा उतार (0.64) w2 पेक्षा (0.48) मोठा,
कारण आर्द्रता (0.8) ढगांपेक्षा (0.6) जास्त होती: **जो input
मोठा, त्याचा weight जास्त जबाबदार, म्हणून जास्त सुधारणा.**
गणित आपोआप न्याय करतं.

**पायरी 4: सुधारा (gradient descent).** प्रत्येक weight मधून
"पावलाचा-आकार (learning rate) x उतार" वजा करा. पाऊल-आकार
0.1 घेऊ:
```
w1: 1.0 - 0.1 x 0.64 = 1.0 - 0.064 = 0.936
w2: 1.0 - 0.1 x 0.48 = 1.0 - 0.048 = 0.952
b:  0   - 0.1 x 0.80 = 0   - 0.080 = -0.080
```

**पायरी 5: तपासा: चूक कमी झाली का?** नव्या weights ने पुन्हा
अंदाज:
```
p = 0.936 x 0.8 + 0.952 x 0.6 + (-0.08)
  = 0.7488 + 0.5712 - 0.08
  = 1.24
नवी loss = (1.24 - 1)² = 0.24² = 0.0576
```

**बघा: चूक 0.16 वरून 0.0576 वर घसरली!** एका पावलात.
थेंबू 1.4 वरून 1.24 कडे, म्हणजे खऱ्या 1 च्या **जवळ** आला.
हे पुन्हा-पुन्हा (पायरी 1-5) केलं तर थेंबू हळूहळू 1 वर स्थिरावेल:
**तो शिकला.** आणि हेच, नेमकं हेच, ChatGPT ट्रिलियन वेळा
करतं: फक्त 3 weights ऐवजी अब्जावधी, आणि आर्द्रता-ढग ऐवजी
शब्दांचे बाण. **तुम्ही आत्ता, हाताने, यंत्र-शिक्षण केलंत.**

## इथे लोक काय चुकीचं समजतात

"यंत्र-शिक्षण म्हणजे काहीतरी गूढ, अतिमानवी." तुम्ही ते आत्ता
कागदावर केलंत: गुणा, बेरीज, वजा. पाच पायऱ्या. गूढ काहीच
नाही: फक्त अब्जावधी weights आणि ट्रिलियन पावलं, म्हणून GPU
आणि महिने (Book 4, 1.1). "यंत्र जादूने शिकतं" ही कविता संपली;
"forward-loss-backward-update, पुन्हा" हे अंकगणित उरलं. आणि
हीच सर्वात मोठी मुक्ती: **AI मध्ये कुठेही जादू नाही, फक्त
आकडे: आणि आकडे तुम्हाला समजतात.**

## नकाशावर

```
3.1-3.3  derivative | gradient | chain rule
3.4  थेंबू हाताने: forward (अंदाज 1.4) -> loss (0.16) ->
     backward (उतार गुणा) -> update (weights कमी) -> नवी
     loss 0.0576; हेच ChatGPT, फक्त अब्जावधी पट
```

**सूत्रावर:** हा chapter पूर्ण सूत्राचं मूर्त रूप आहे: चूक **मोजली**
(0.16), उतार **मोजला**, म्हणून **सुधारता आली** (0.0576). जे
मोजता येतं ते सुधारता येतं: यंत्र-शिक्षण म्हणजे या एका वाक्याची
ट्रिलियन-पट पुनरावृत्ती.

## स्वतः बघा (5 मिनिटं)

वरचं पूर्ण उदाहरण स्वतः कागदावर, हाताने, पुन्हा करा: पण
वेगळ्या सुरुवातीच्या weights ने (उदा w1 = 0.5, w2 = 0.5,
b = 0). पाच पायऱ्या चालवा आणि बघा: loss कमी होते का?
(होईल.) एकदा हाताने केलंत की "training" हा शब्द तुमच्यासाठी
कायमचा अंकगणित होईल, जादू नाही: आणि तीच या पुस्तकाची
सर्वात मोठी कमाई.

## विचार करा

जर 0.01 (खूप छोटं) घेतलं असतं तर? किंवा 2 (खूप मोठं)? हे
'0.1' कुठून आलं, आणि ते चुकीचं निवडलं तर काय होतं? आणि
धुक्यातल्या डोंगरावर मी 'खऱ्या' तळाऐवजी एका छोट्या खड्ड्यात
