# Chapter 3.3 [SPINE]: Chain Rule: चूक मागे वाटणं

थेंबूचा प्रश्न: लांब साखळीत सुरुवातीच्या weight चा शेवटच्या
loss वरचा उतार कसा? उत्तर deep learning चा सर्वात हुशार,
सर्वात सुंदर भाग आहे: **chain rule** (साखळी-नियम), ज्याला
कृतीत **backpropagation** (चूक मागे-वाटणं) म्हणतात.

**कल्पना: परिणामांची साखळी.** एक साखळी: पाऊस कमी -> धरणात
पाणी कमी -> वीज कमी -> कारखाना बंद -> मजूर बेकार. आता
प्रश्न: "पाऊस 10% कमी झाला तर मजुरीवर किती परिणाम?"
उत्तर: **प्रत्येक दुव्याचा दर गुणा.** पाऊस->पाणी चा दर x पाणी->
वीज चा दर x वीज->कारखाना x कारखाना->मजुरी. दरांचा गुणाकार =
टोकापासून टोकाचा परिणाम. **हाच chain rule: साखळीतल्या
प्रत्येक पायरीचा दर (derivative) गुणा, म्हणजे सुरुवातीचा शेवटावरचा
परिणाम मिळतो.**

**यंत्रात: loss मागे वाटणं.** थेंबूचं यंत्र: पहिला थर -> दुसरा ->
शेवटचा -> loss. पहिल्या थरातल्या weight चा loss वरचा उतार
हवाय. Chain rule: **शेवटापासून सुरुवातीकडे, प्रत्येक थराचा दर
गुणत मागे या.** म्हणून याला "back-propagation": loss ची "जबाबदारी"
शेवटच्या थरापासून मागे, प्रत्येक थराला त्याच्या वाट्याची, वाटत
जाणं. जणू loss म्हणते "ही चूक झाली; प्रत्येक थराचा यात किती
हात?": आणि उत्तर मागे-मागे, गुणाकाराने, प्रत्येक weight पर्यंत
पोहोचतं.

**दोन पावलं (हेच पूर्ण training चं यंत्र):**

```
1. पुढे (forward): माहिती आत -> थर-थर -> अंदाज -> loss.
   (थेंबू: हवा -> गुण -> probability -> चूक)
2. मागे (backward): loss -> chain rule ने प्रत्येक थराचा
   दर गुणत मागे -> प्रत्येक weight चा उतार (gradient).
   मग gradient descent ने सगळे weights एक पाऊल सुधार (3.2).
```

पुढे-मागे, पुढे-मागे: ट्रिलियन वेळा. **हेच "यंत्र शिकतं." Forward
ने अंदाज, backward ने दोष-वाटप, मग सुधारणा.** आणि सौंदर्य:
कितीही खोल यंत्र (शंभर थर) असो, chain rule प्रत्येक weight
पर्यंत नेमका उतार पोहोचवतो: फक्त दर गुणत मागे या. Deep
learning शक्य झालं कारण हा एक साधा गुणाकार-नियम अब्जावधी
weights ना एका पावलात सुधारू देतो.

**एक सूक्ष्म धोका (कळून घ्या, नाव पुरे):** दर गुणत-गुणत मागे
जाताना, जर दर सतत **छोटे** (0.1 x 0.1 x 0.1...) असतील तर
गुणाकार जवळजवळ **शून्य** होतो: सुरुवातीच्या थरांपर्यंत उतार
पोहोचतच नाही (ते शिकतच नाहीत): याला "vanishing gradient"
म्हणतात. उलट दर मोठे तर गुणाकार **स्फोटक** (exploding).
खूप-खोल यंत्रं शिकवायला हे मोठे अडथळे होते; आणि transformer
ची काही रचना (residual connections वगैरे) नेमकी हे टाळायला:
म्हणजे Book 2 चा transformer अंशतः या गणिती अडचणीवरचा
उपाय आहे. (खोलात जायची गरज नाही; एवढं कळलं की papers
मधला हा शब्द ओळखीचा होईल.)

## इथे लोक काय चुकीचं समजतात

"Backpropagation म्हणजे यंत्र 'मागे विचार करतं' किंवा 'आठवतं'."
नाही: हे विचार-आठवण नाही, **शुद्ध गुणाकार.** loss पासून मागे,
प्रत्येक थराचा दर गुणत, प्रत्येक weight चा उतार काढणं: यांत्रिक,
भावनाशून्य अंकगणित. "यंत्र स्वतःच्या चुकांतून शिकतं" ही कविता;
"loss चा gradient chain rule ने प्रत्येक weight ला वाटला जातो
आणि weights एक पाऊल सरकतात" हे गणित. Backprop ला बुद्धी
नाही, फक्त गुणाकार आहे.

## नकाशावर

```
3.1  derivative = उतार   3.2  gradient = उतार-बाण, उलट जा
3.3  chain rule/backprop: प्रत्येक थराचा दर गुणत loss मागे
     वाटणं; forward (अंदाज) + backward (दोष-वाटप) = शिकणं;
     vanishing/exploding = खोलीचा अडथळा
```

**सूत्रावर:** chain rule हा चष्मा "खोल यंत्र कसं शिकतं" या
गूढाला एका गुणाकार-नियमात आणतो: चूक मागे वाटा, प्रत्येक
weight ला त्याचा वाटा. जे मोजता येतं (प्रत्येकाचा दोष) ते
सुधारता येतं (प्रत्येकाला एक पाऊल): deep learning चं संपूर्ण
रहस्य एका गुणाकारात.

## स्वतः बघा (5 मिनिटं)

एक साखळी-हिशेब करा: एका दुकानाचा नफा 10% वाढला, दुकानाचा
मालक कंपनीचा 20% भागधारक, कंपनीचा नफा शहराच्या करात
5% योगदान. "दुकान-नफा वाढ शहराच्या करावर किती?": दर
गुणा (0.10 x 0.20 x 0.05 = 0.001, म्हणजे किरकोळ). तुम्ही
आत्ता chain rule केलात: साखळीतले दर गुणून टोकाचा परिणाम.
यंत्र loss साठी हेच करतं, फक्त लाखो दुव्यांचं.
