# Chapter 2.5 [SPINE]: Cross-Entropy: Loss चं खरं रूप

थेंबूचा प्रश्न: "चूक (loss)" नक्की काय? Book 2 ने loss ला
"चुकीचं माप" म्हटलं (2.5); आता त्याचं खरं गणिती रूप उघडू:
आणि ते entropy चंच जुळं भावंडं आहे: **cross-entropy.** हे
समजलं की यंत्राच्या शिकवणीचं हृदय दिसतं.

**कल्पना: खऱ्याला तू किती probability दिलीस?** थेंबूने अंदाज
लावला (distribution): पाऊस 0.6, ढगाळ 0.3, कोरडं 0.1. मग
प्रत्यक्षात **पाऊस पडला.** आता चूक कशी मोजायची? सोपं तत्त्व:
**जे खरं घडलं, त्याला यंत्राने किती probability दिली होती?**
पाऊस पडला, यंत्राने पावसाला 0.6 दिलं होतं: बऱ्यापैकी, पण
पूर्ण नाही. जर यंत्राने 0.95 दिलं असतं तर उत्तम (कमी चूक);
0.1 दिलं असतं तर वाईट (मोठी चूक: खऱ्या गोष्टीला यंत्र म्हणत
होतं "अशक्य").

**Cross-entropy loss (गाभा, सूत्राशिवाय):** **खऱ्या घटनेला
यंत्राने दिलेली probability जितकी जास्त, तितकी चूक कमी.**
आणि नातं उलटं-आणि-तीव्र आहे:

```
यंत्राने खऱ्याला दिलं  ->  loss (चूक)
0.9 (छान)              ->  लहान (~0.1)
0.6 (ठीक)              ->  मध्यम (~0.5)
0.1 (वाईट)             ->  मोठा (~2.3)
0.01 (भयंकर)           ->  प्रचंड (~4.6)
```

लक्षात घ्या: probability जसजशी शून्याकडे, तसतशी loss **स्फोटक**
वाढते. का? कारण **"खऱ्या गोष्टीला अशक्य म्हणणं" ही सर्वात
मोठी चूक.** यंत्र 0.9 खात्रीने चुकीचं बोललं (आणि खरं वेगळं
निघालं) तर loss प्रचंड: शिक्षा मोठी. हेच यंत्राला "ठाम-चूक"
पासून परावृत्त करतं (किंवा करायला हवं: hallucination अजून
का उरतं हे Book 2, 5.1). Loss = खऱ्याला दिलेल्या खात्रीची
उलटी शिक्षा.

**Entropy शी नातं (सुंदर):** entropy होतं "यंत्राच्या स्वतःच्या
अंदाजातलं सरासरी आश्चर्य" (2.4). Cross-entropy आहे "खऱ्या
जगाशी ताडून यंत्राला किती आश्चर्य." जर यंत्राचा अंदाज खऱ्याशी
तंतोतंत जुळला तर cross-entropy = entropy (कमीत कमी). जितका
अंदाज खऱ्यापासून दूर, तितकी cross-entropy entropy पेक्षा जास्त:
आणि तो **जास्तीचा भाग म्हणजे यंत्राची चूक.** म्हणून training
म्हणजे: cross-entropy कमी करत नेणं = यंत्राचा अंदाज खऱ्या
जगाच्या जवळ नेणं = आश्चर्य कमी करणं (2.4 चा "शिकणं =
आश्चर्य कमी करणं" आता नेमकं).

**हेच LLM चं संपूर्ण training (Book 2 उघडलं):** अब्जावधी
वाक्यांत, प्रत्येक शब्दाला यंत्र अंदाज लावतं (पुढचा शब्द काय),
खरा शब्द बघतं, आणि **खऱ्या शब्दाला यंत्राने किती probability
दिली** यावरून cross-entropy loss. मग ती कमी करायला weights
थोडे हलवतात (Part 3). ट्रिलियन वेळा. "यंत्र इंटरनेट वाचून
शिकलं" म्हणजे: ट्रिलियन शब्दांवर cross-entropy कमी करत,
आपला अंदाज खऱ्या मजकुराच्या जवळ नेत गेलं. Book 2 चं
"अंदाज-चूक-सुधार" चक्र आता गणितात: चूक = cross-entropy.

## इथे लोक काय चुकीचं समजतात

"Loss म्हणजे यंत्राने किती उत्तरं चुकवली (टक्केवारी)." नाही:
loss हे "किती चुकवली" नाही, "**किती खात्रीने** चुकवली/बरोबर
केली" मोजतं. यंत्र बरोबर उत्तर देऊनही (जर कमी खात्रीने दिलं
तर) थोडी loss घेतं; आणि चुकीचं उत्तर ठाम खात्रीने दिलं तर
प्रचंड loss. म्हणून loss हे उत्तरांच्या **खात्रीचं** माप आहे,
नुसत्या बरोबर-चूक चं नाही. हेच यंत्राला "नुसतं बरोबर" नाही
तर "योग्य आत्मविश्वासाने बरोबर" व्हायला शिकवतं (आदर्शात;
प्रत्यक्षात calibration अपुरं: Book 2, 1.4).

## नकाशावर

```
2.1-2.4  probability | distribution | Bayes | entropy
2.5  cross-entropy = loss चं खरं रूप; खऱ्याला दिलेली
     probability जास्त -> loss कमी; अशक्य-म्हणणं = स्फोटक
     शिक्षा; training = cross-entropy कमी करणं
```

**सूत्रावर:** cross-entropy हा चष्मा "यंत्र शिकतं म्हणजे काय"
हे पूर्ण उघडतो: खऱ्या जगाशी आपला अंदाज ताडून, अंतर (loss)
मोजून, ते कमी करणं. जे मोजता येतं (loss) तेच सुधारता येतं
(कमी करत): सूत्र यंत्र-शिक्षणाच्या केंद्रस्थानी.

## स्वतः बघा (5 मिनिटं)

एक स्वतःची परीक्षा कल्पना करा जिथे तुम्ही प्रत्येक उत्तराला
"किती खात्री" (%) लिहायची. आता cross-entropy चा नियम: बरोबर
उत्तराला 90% खात्री दिली आणि बरोबर निघालं -> छान (कमी
शिक्षा); पण चुकीच्या उत्तराला 90% खात्री दिली -> मोठी शिक्षा.
हा नियम तुम्हाला "खात्री तेवढीच दाखवा जेवढी खरी आहे" शिकवतो:
अति-आत्मविश्वासाला शिक्षा. यंत्रालाही तेच शिकवायचा प्रयत्न,
cross-entropy ने.
