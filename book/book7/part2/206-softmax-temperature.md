# Chapter 2.6 [SPINE]: Softmax आणि Temperature

थेंबूचे दोन प्रश्न: कुठलेही गुण probability मध्ये कसे बदलायचे,
आणि "किती धीट" कसं ठरवायचं. दोन्हींची उत्तरं एका सुंदर
यंत्रात आणि एका कळीत आहेत: **softmax** आणि **temperature.**
हे विभाग 2 आणि Part 1 ला जोडतात.

**Softmax: गुणांचं probability मध्ये रूपांतर.** थेंबूचे गुण: पाऊस
2.0, ढगाळ 1.8, कोरडं 0.5. हे 0-1, बेरीज-1 मध्ये कसे आणायचे?
Softmax ची तीन पावलं (हाताने, ढोबळ):

```
1. प्रत्येक गुणाचा "स्फोट" (exponential: मोठा गुण जास्त
   मोठा होतो, फरक ठळक होतात):
   पाऊस 2.0 -> ~7.4;  ढगाळ 1.8 -> ~6.0;  कोरडं 0.5 -> ~1.6
2. बेरीज: 7.4 + 6.0 + 1.6 = 15.0
3. प्रत्येकाचा हिस्सा (भागा):
   पाऊस 7.4/15 = 0.49;  ढगाळ 6.0/15 = 0.40;  कोरडं 1.6/15 = 0.11
```

झालं: गुण (2.0, 1.8, 0.5) -> probability (0.49, 0.40, 0.11),
बेरीज 1. **Softmax = कुठलेही आकडे घेऊन probability-वाटणी
बनवणारं यंत्र.** आणि पायरी-1 चा "स्फोट" महत्त्वाचा: तो मोठ्या
गुणाला **अप्रमाणात** जास्त probability देतो (फरक ठळक करतो):
म्हणून "soft-max": सर्वात मोठ्याला झुकतं, पण बाकीलाही थोडं
(पूर्ण max नाही, soft). हेच LLM च्या शेवटच्या पायरीत: शब्दकोशाच्या
गुणांचं (logits) probability मध्ये रूपांतर, प्रत्येक token ला.

**Temperature: "किती धीट" ची कळ (Book 2 ची तीच).** आता
जादूची कळ. softmax च्या आधी सगळे गुण एका आकड्याने **भागा**:
त्याचं नाव temperature (T).

```
T कमी (उदा 0.5): गुण मोठे होतात -> स्फोट तीव्र -> सर्वात
  मोठ्याला अजून जास्त वजन -> distribution तीव्र (2.2) ->
  यंत्र "ठाम", नेहमी सर्वात शक्य निवडतं. (कंटाळवाणं पण सुरक्षित.)
T जास्त (उदा 1.5): गुण लहान होतात -> स्फोट मंद -> सगळे
  जवळ येतात -> distribution सपाट -> यंत्र "धीट/जुगारी",
  कमी-शक्य पर्यायही निवडतं. (सर्जनशील पण जोखमीचं.)
T = 1: मूळ, जसंच्या तसं.
```

म्हणजे temperature ही **entropy ची कळ** (2.4): कमी T = कमी
entropy (ठाम); जास्त T = जास्त entropy (गोंधळ/सर्जनशीलता).
Book 2 मध्ये "temperature = निवडीच्या फाशांची मात्रा" म्हटलं
होतं; आता नेमकं दिसतं: ती softmax च्या तीव्रतेची कळ, म्हणजे
distribution च्या आकाराची कळ.

**सगळं जोडून (विभाग 2 चा कळस): एका token चा पूर्ण प्रवास.**

```
1. matrix-थर (Part 1): शब्दाचा बाण -> गुण-यादी (logits),
   शब्दकोशातल्या प्रत्येक शब्दाला एक गुण.
2. temperature ने भागा: "किती धीट" ठरवा.
3. softmax: गुण -> probability-distribution (बेरीज 1).
4. त्या distribution मधून एक शब्द निवडा (फासे: 2.1).
5. training असेल तर: खऱ्या शब्दाशी ताडून cross-entropy
   loss (2.5) -> weights हलवा (Part 3).
```

Part 1 (बाण, matrix) + Part 2 (probability, softmax, loss):
एकत्र म्हणजे LLM च्या एका पावलाचं **पूर्ण** गणित. थेंबूचं यंत्र
आणि ChatGPT: हाच प्रवास, फक्त आकार वेगळा.

## इथे लोक काय चुकीचं समजतात

"Temperature वाढवली की यंत्र हुशार/सर्जनशील होतं." अर्धसत्य,
धोकादायक. Temperature फक्त "किती कमी-शक्य पर्याय निवडायचे"
ठरवते: जास्त T = जास्त विविधता, **पण जास्त चुका/बरळणंही**
(कमी-शक्य म्हणजे अनेकदा चुकीचं). "सर्जनशीलता" आणि "बरळणं"
दोन्ही जास्त-T चीच फळं: फरक फक्त तुम्हाला कोणतं हवं. तथ्यांच्या
कामाला कमी T (ठाम, अचूक), कल्पक लेखनाला जास्त T (विविध).
कळ हुशारीची नाही, **जोखमीची** आहे.

## नकाशावर

```
2.1-2.5  probability | distribution | Bayes | entropy | cross-entropy
2.6  softmax = गुण -> probability (स्फोट+भागा); temperature =
     धीटपणाची/entropy ची कळ (कमी=ठाम, जास्त=जुगारी);
     पूर्ण token-प्रवास: बाण->गुण->softmax->निवड->loss
```

**सूत्रावर:** softmax+temperature हा चष्मा "यंत्र किती धीट/ठाम"
ही कळ **तुमच्या हातात** देतो: entropy ची कळ फिरवता येते.
आणि पूर्ण Part 1-2 मिळून यंत्राचं एक पाऊल आता संपूर्ण गणित
आहे: कुठेही जादू उरली नाही.

## स्वतः बघा (5 मिनिटं)

अनेक AI-साधनांत "temperature" किंवा "creativity" ची कळ असते.
असेल तर: तोच प्रश्न दोन T ला विचारा (कमी आणि जास्त). कमी
T: उत्तर दर वेळी जवळपास तेच, सुरक्षित. जास्त T: दर वेळी
वेगळं, कधी छान कधी विचित्र. तुम्ही entropy ची कळ प्रत्यक्ष
फिरवताय: distribution तीव्र-सपाट करताय.
