# Chapter 6.1  [SPINE]
## Bolne aur karne ke beech ka gap

### Samvaad

**Madhav:** Aap model se kehte ho "mera email bhej do." Kya hota hai?

**Kabir:** Woh keh dega ki bhej diya.

**Madhav:** Kya woh bheja gaya?

**Kabir:** Nahi. Woh sirf text hai.

**Madhav:** Toh usne jhooth bola?

**Kabir:** Nahi. Aise sawal ke baad "bhej diya" ek sambhavit jawab hai.

**Madhav:** Bas. Ab ek line mein batao ki uske paas kya nahi hai.

**Kabir:** Uske paas haath nahi hain. Woh sirf likh sakta hai.

**Madhav:** Aur ek program ke paas kya hota hai?

**Kabir:** Woh sach mein kuch kar sakta hai. Email bhej sakta hai, file khol sakta hai.

**Madhav:** Toh dono ko jodna hai. Kaise jodoge?

**Kabir:** Model kuch likhe, aur ek program use padh kar kaam kare.

**Madhav:** Model ko kaise pata chalega ki kya likhna hai?

**Kabir:** Use batana padega. "Agar email bhejna ho toh aise likhna."

**Madhav:** Aur woh nirdesh kahan jaayega?

**Kabir:** Sawal ke saath. Context mein.

**Madhav:** Ab ek problem. Model text likhta hai. Program ko kaise pata chalega ki yeh baat hai ya hukum?

**Kabir:** Shakal alag honi chahiye. Koi tay shakal, jise program pehchan sake.

**Madhav:** Bas. Ab poora chakkar bolo.

**Kabir:** Program model ko batata hai ki kya kya kaam mumkin hain. Model ek tay shakal mein likhta hai ki kaunsa kaam karna hai. Program use padh kar sach mein karta hai.

**Madhav:** Aur uske baad?

**Kabir:** Nateeja model ko wapas dena padega. Warna use pata hi nahi chalega ki kya hua.

**Madhav:** Kis shakal mein?

**Kabir:** Text mein. Aur kis shakal mein ho sakta hai.

**Madhav:** Toh nateeja bhi context mein aa gaya. Ab dhyaan do ki humne kya kiya. Kya model badla?

**Kabir:** Bilkul nahi. Woh abhi bhi sirf agla token chun raha hai.

**Madhav:** Toh naya kya hai?

**Kabir:** Uske aas-paas ek program hai jo uske likhe ko padh kar kaam karta hai, aur nateeja wapas likh deta hai.

**Madhav:** Aur woh program kiska hai?

**Kabir:** Kisi aur ka. Model ke bahar.

**Madhav:** Yaad rakhna. Poore Part 6 mein yeh baat baar baar kaam aayegi.

### Naam

Model ke paas koi taakat nahi hai. Woh sirf text banata hai.

Toh use "haath" dene ka matlab hai: ek program uske likhe ko padhta hai aur us hisaab se kaam karta hai.

```
1.  program model ko batata hai: yeh kaam mumkin hain
2.  model ek tay shakal mein likhta hai: yeh kaam karo
3.  program use padhta hai aur SACH MEIN karta hai
4.  nateeja text bankar wapas model ke saamne aata hai
5.  model us nateeje ko dekh kar aage likhta hai
```

Do baatein jo iss chapter ki jaan hain.

**Ek: model ke andar kuch nahi badla.**

Woh abhi bhi wahi kaam kar raha hai: sabse sambhavit agla token. Sirf ab uske likhe ka ek asar hota hai duniya mein.

Yeh Book 1 Chapter 6.3 ki baat hai, ek parat upar: **jo cheez taakat rakhti hai woh alag hai, aur jo cheez maangti hai woh alag.**

**Do: model ke paas apna koi haath nahi hota, aur wahi ek bachaav hai.**

Har kaam kisi program ke through jaata hai. Aur woh program tay karta hai ki kya karne diya jaaye.

Book 1 Chapter 3.4 wali baat: OS app ko taakat nahi deta, use maangne deta hai. Yahan bilkul wahi shakal hai, aur woh iss poore Part ka sabse zaroori bachaav hai.

Ab ek chetavni jo aage baar baar dohrayi jaayegi:

> **Model yeh nahi jaanta ki uske likhe ka asar hua ya nahi. Use sirf woh dikhta hai jo wapas likh kar bataya gaya.**

Agar aap use jhoota nateeja de do, toh woh use maan lega. Woh jaanch nahi sakta, kyunki uske paas dekhne ka koi rasta hai hi nahi.

### Asli duniya se

Ek aam galti jo shuru mein sabse zyada hoti thi: log model se kehte the "mera calendar dekh kar batao," aur woh ek poora calendar bana kar dikha deta tha.

Woh jhooth nahi bol raha tha. Uske paas calendar tha hi nahi, aur "calendar dikhao" ke baad ek calendar likha jaana sambhavit tha.

Aaj ke products mein yeh kam hai, aur uski wajah model nahi hai. Wajah yeh hai ki ab unke paas sach mein calendar tak jaane ka ek raasta hai, aur agar woh raasta na ho toh unhe saaf mana karne ke liye kaha jaata hai.

**Farak model ki imaandaari mein nahi hai. Farak uske aas-paas ke dhaanche mein hai.**

### Yahan log kya galat samajhte hain

Sabse aam galti: **yeh maan lena ki agar usne kaha ki kaam ho gaya toh ho gaya.**

Jab tak uske paas us kaam ka koi asli raasta na ho, "ho gaya" sirf ek sambhavit vaakya hai.

Iska seedha, kaam ka roop: **poochho ki usne kya kiya, aur uska saboot maango.** Agar usne file badli, toh file dekho. Agar usne email bheja, toh sent folder dekho.

Doosri galti: **yeh sochna ki tools milne se model ki samajh badh gayi.**

Uske andar kuch nahi badla. Woh ab bhi wahi hai. Bas uski aankh ki seemayein hat gayi hain (Chapter 5.2), aur uske likhe ka asar hone laga hai.

Yeh farak zaroori hai, kyunki uski **andar ki** seemayein wahi hain. Woh ab bhi nahi jaanta ki use kya nahi pata. Woh ab bhi apni galti khud nahi pehchan sakta.

**Aur ab uski galtiyon ka asar hota hai.** Yeh Part 6 ka poora tanaav hai.

### Sochne ke liye

**1. (samajh check)** Aap model se kehte ho "meri website check karo ki chal rahi hai ya nahi." Uske paas koi tool nahi hai. Kya hoga?

> **Jawab:** Woh ek jawab likh dega jo sambhavit hai. Aksar "haan, chal rahi hai" ya ek aam sa saaransh.
>
> Woh check kar hi nahi sakta. Uske paas internet tak jaane ka koi raasta nahi hai.
>
> Aur woh yeh nahi kahega ki "main check nahi kar sakta," jab tak use saaf taur pe aisa kehne ke liye na dhaala gaya ho.
>
> **Uske paas jo nahi hai, uska use pata nahi hota.**

**2. (samajh check)** Model kehta hai "maine file padh li aur usmein yeh likha hai." Aapne use file bheji hi nahi thi. Kya hua?

> **Jawab:** Usne file nahi padhi. Usne likha ki ek file mein kya hota, aisi jagah pe.
>
> Yeh Chapter 5.4 ki baat hai: jaanch karna aur jaanch jaisa lagna alag hain.
>
> **Jab tak aapne kuch bheja nahi, tab tak usne kuch dekha nahi.** Iska koi apwaad nahi hai.

**3. (jodne wala)** Book 1 Ch 3.4 mein OS app ko taakat nahi deta tha, maangne deta tha. Yahan wahi shakal kaise hai?

> **Jawab:** Bilkul wahi hai, ek parat upar.
>
> ```
> Book 1   app ke paas taakat nahi, woh OS se maangta hai
> yahan    model ke paas taakat nahi, woh program se maangta hai
> ```
>
> Aur dono jagah faayda ek hi hai: **beech wala mana kar sakta hai.**
>
> Isliye ek AI agent ko jo kar sakta hai, woh us list se tay hota hai jo kisi insaan ne likhi. Aur agar us list mein "sab kuch" likh diya jaaye, toh bachaav khatam ho jaata hai.
>
> Yeh Chapter 6.7 mein sabse zaroori baat banegi.
