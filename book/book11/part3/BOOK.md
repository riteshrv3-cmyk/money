# विभाग 3: गणित: आकड्यांनी

गोष्टी प्रेरणा देतात; **आकडे निर्णय देतात.** या विभागात पाच
हिशेब, सगळे हाताच्या आकड्यांनी (Book 7 ची शैली: प्रत्येक
आकडा कुठून आला ते दिसेल): **ताळेबंद** (ओमच्या धंद्याचा
महिना रुपया-रुपयाने), **माणशी-कमाईची स्फोट-पट्टी** (TCS ते
Anthropic: आणि तिच्यावर तुमची जागा), **किंमत-LTV-CAC**
(विक्रीचं त्रिकोणी गणित), **जिना** (₹0 ते unicorn: सहा पायऱ्या,
प्रत्येकीची यंत्रणा), आणि **फाटा** (माणसं कधी: आकड्याने ठरतं,
भावनेने नाही).

एक वचन: विभाग संपेल तेव्हा 'unicorn' हा शब्द तुमच्यासाठी
स्वप्न नसेल: **गुणाकार** असेल: ARR x multiple: आणि गुणाकार
मोजता येतो, म्हणून चढताही येतो.

# Chapter 3.1 [SPINE]: ताळेबंद: ओमच्या धंद्याचा एक महिना, रुपया-रुपयाने

ओमचं (नमुना-) SaaS: महिना $19 वर्गणी, **500 गिऱ्हाईकं**
(जिन्याची चौथी पायरी: 3.4). त्याचा खरा महिना:

```
उत्पन्न:  500 x $19                        = $9,500
वजावट 1: Stripe (कार्ड-कात्री ~2.9%+30c)   = -$330
वजावट 2: AI-tokens (COGS चा राजा)
   प्रत्येक गिऱ्हाईक महिन्याला ~400 AI-कामं;
   काम सरासरी 3K input + 1K output tokens, Sonnet-दराने
   ($3/M in, $15/M out): काम ~$0.024; cache-batch शिस्तीने
   (Book 9, 3.2) ~40% खाली: ~$0.014
   500 x 400 x $0.014/400... = गिऱ्हाईकामागे ~$5.8/महिना
                                              = -$2,900
वजावट 3: infra (servers, DB, domain, साधनं)  = -$700
वजावट 4: त्याची स्वतःची AI-वर्गणी + याद्या    = -$300
------------------------------------------------
ढोबळ नफा (gross):                            = $5,270
   म्हणजे gross margin ~55%
```

**या ताळेबंदातले चार धडे:**

**धडा 1: AI-SaaS चं margin जुन्या SaaS हून कमी: आणि हे
सर्वत्र खरं आहे.** जुनं software: प्रत जवळजवळ फुकट: margins
70-90%. AI-product: **प्रत्येक वापराला token-मीटर फिरतो**:
उद्योग-पाहण्या (2026) AI-native margins ~50-60% दाखवतात;
inference-खर्च उत्पन्नाच्या ~20-25% पर्यंत जातो [पक्कं-जवळ:
गुंतवणूकदार-अहवाल]. ओमचे 55% हे **सामान्य** आहेत, आजार
नाही. पण म्हणूनच:

**धडा 2: token-शिस्त = margin-शिस्त.** वजावट-2 आत Book 9
(3.1-3.2) ची सगळी हत्यारं राबतात: model-निवड (सगळं Opus
ला दिलं तर COGS x3 = margin मेला!), cache-batch, context-
शिस्त. ओमने ती शिस्त सोडली तर तोच ताळेबंद: gross $2,300
(24%!): **एकाच धंद्याचे दोन भाव: फरक फक्त बटणांचा.** solo-AI-
धंद्यात 'engineer' आणि 'CFO' एकच माणूस असतो: बरं आहे:
भांडण होत नाही.

**धडा 3: ढोबळ-नफ्याखाली एकट्याचं सोनं आहे.** मोठ्या कंपनीत
gross खाली अजून कात्र्या: पगार, office, sales-टीम, HR... ओमकडे:
**जवळजवळ काहीच नाही** (तो स्वतः = अजून-न-काढलेला पगार).
म्हणजे त्याचा operating-नफा जवळजवळ = gross: $5,270/महिना:
आणि इथे विभाग 1 चं सूत्र आकड्यात: **यंत्र-विभागांचा 'पगार'
वजावट-2-3-4 त आधीच धरलाय: $3,900**: चार-माणसांच्या
जुन्या टीमच्या दहाव्या हिश्शात.

**धडा 4: वाढीचं गणित रेषीय नाही.** गिऱ्हाईकं 500 -> 2,000
झाली तर: उत्पन्न x4 ($38K); tokens-Stripe x4 (प्रमाणात);
infra जरा वर; त्याचा वेळ? **support-प्रश्न x4**: हीच 1.7 ची
भिंत आकड्यात दिसू लागते (आणि 3.5 चा फाटा तिथून). margin
टिकतं; **माणूस ताणतो**: वाढीआधी agent-support आणि नियम-पत्रं
(1.4) पक्की करायची ती यासाठी.

**ओमवर:** ओम हा ताळेबंद **धंदा सुरू करण्याआधी** मांडतो
(नमुना-आकड्यांनी: pre-mortem चा हिशेबी भाऊ!): त्याला आधीच
दिसतं: $19 भाव ठेवला तर 500 गिऱ्हाईकांवर तो जगू शकतो
(भारतीय राहणीत आरामात); token-शिस्त 30% वाचवते; आणि
2,000 च्या आधी support-यंत्रणा लागेल. **धंदा अजून जन्मलाही
नाही आणि त्याचं अर्थशास्त्र त्याला पाठ आहे**: हीच power-user
ची खरी व्याख्या.

## महाग चूक

"उत्पन्न आलं की हिशेब बघू." Indie-जगातली सर्वात महाग टाळाटाळ:
कारण **रचना-निर्णय (भाव, model, features) हे हिशेब-निर्णय
आहेत** आणि ते पहिल्या दिवशी होतात: $9 भाव ठेवला असता
तर हाच धंदा tokens खाऊन उपाशी; 'unlimited AI' feature
दिलं असतं तर एक जड-वापरकर्ता margin खातो (म्हणून usage-
मर्यादा हे design असतं: Book 9, 2.6 चा limits-राग आता
दुसऱ्या बाजूने दिसला?). ताळेबंद आधी: उत्पन्न मग: क्रम हाच.

## नकाशावर

```
3.1  ताळेबंद: $9,500 उत्पन्न -> Stripe -> tokens ($2,900:
     COGS-राजा) -> infra -> gross ~55% (AI-native सामान्य);
     token-शिस्त = margin-शिस्त (55% वि 24%!); एकट्याचं
     सोनं gross खाली; वाढ = support-ताण
```

**सूत्रावर:** ताळेबंद सूत्राचा आरसा: 'कामांचा गठ्ठा' वजावट-2-3-4
मध्ये ($3,900 चा यंत्र-पगार), 'निवड-वाटप' gross-खालच्या
मोकळ्या जागेत: एकट्याची कमाई तिथेच राहते.

# Chapter 3.2 [SPINE]: स्फोट-पट्टी आणि unicorn-गणित

**पट्टी 1: माणशी-कमाई (revenue per employee): युगांची शिडी.**

```
युग          उदाहरण (वार्षिक, ~2025-26)      माणशी
सेवा-युग     TCS ~$50K, Infosys ~$60K       हात विकणं:
             [पक्कं: जाहीर ताळेबंद]           माणसं = उत्पन्न
software-    Apple ~$2.4M, Meta ~$2.6M,     प्रत फुकट:
युग          Nvidia ~$3.6M [पक्कं]           माणशी 50 पट
AI-युग       OpenAI ~$5.5M, Anthropic ~$9M   यंत्रं राबतात:
             [अंदाज-संस्था: MED]; Midjourney  माणशी 100+
             $200M+/~40 जण = ~$5M [स्व];     पट
             Lovable ~$2.2M/माणूस [पक्कं-जवळ]
विक्री-क्षण   WhatsApp: $19B/55 = माणशी      पट्टीबाहेरचा
             ~$345M! [पक्कं]                 तारा
```

पट्टीचं वाचन: **सेवा-युगात उत्पन्न माणसांबरोबर वाढतं (रेषा);
software-युगात प्रत-फुकटपणाने माणशी उडी; AI-युगात निर्मितीही
यंत्राकडे: आणखी उडी.** आणि पट्टीच्या टोकाला 'एक माणूस':
Levels $3M/1, Medvi चा दावा $401M/1-2 [स्व]: **पट्टी 'एकट्याच्या
unicorn' कडेच झुकतेय: प्रश्न 'का' नाही, 'कधी-कोण' आहे**
(Altman ची पैज हीच: 1.3).

**पट्टी 2: unicorn-गणित (शब्द ते गुणाकार).** 'Unicorn' हा
शब्द: Aileen Lee (गुंतवणूकदार), Nov 2013 चा लेख: **$1B+
किंमतीची startup**: तेव्हा त्या दुर्मिळतेला 'unicorn' (एकशिंगी)
नाव: तेव्हा जगात ~39 होत्या! [पक्कं]. किंमत ठरते कशी: गुंतवणूक-
फेरीत/विक्रीत कुणीतरी **मोजते** (2.2 ची Medvi-शस्त्रक्रिया आठवा:
व्यवहार नाही = किंमत नाही). आणि मोजणारा हिशेब कुठला?
मुख्य दांडा: **ARR x multiple:**

```
किंमत = वार्षिक-recurring-उत्पन्न (ARR) x बाजार-गुणक
गुणक (2025-26 चे ढोबळ पट्टे [MED: सल्लागार-अहवाल]):
   साधं-संथ SaaS:            4-6x
   जोमदार SaaS (वेगवान वाढ): 7-9x
   AI-native तारे:           15-30x
उदाहरण [पक्कं-जवळ]: Lovable: ~$100M ARR x ~18 = $1.8B
unicorn-उलट-गणित: $1B किंमतीला हवं:
   30x गुणकाने ARR ~$33M | 15x ने ~$67M | 10x ने $100M
```

म्हणजे 'one-person unicorn' चं तांत्रिक भाषांतर: **एकट्याने
~$35-100M ARR चा, वेगात वाढणारा, recurring धंदा**: आणि
कुणीतरी (गुंतवणूकदार/खरेदीदार) तो गुणक **मोजायला तयार**
असणं. अशक्य नाही (पट्टी-1 तिथेच झुकतेय); पण झालेला नाही
(2.2): फरक स्पष्ट ठेवणं = प्रौढता.

**आणि तिसरा, सर्वात व्यावहारिक स्तंभ: कागद विरुद्ध रोख.**
Lovable च्या $1.8B तले संस्थापक 'श्रीमंत' आहेत **कागदावर**
(हिस्सा विकेपर्यंत आकडा); Frind चे $575M आणि Shlomo चे
$80M **बँकेत** गेले. दोन्ही खरे: पण जातीने वेगळे: कागदी किंमत
वाढवायला गुंतवणूक-शिडी लागते (हिस्सा विकत जाणं: मालकी
आकसते); रोख-वाट मालकी राखते (नमुना-2!) पण खरेदीदार/नफा
लागतो. **एकट्याच्या जगात रोख-वाट नैसर्गिक आहे**: म्हणून
या पुस्तकाची पट्टी 'valuation' पेक्षा **'बँकेत-जाणाऱ्या नफ्या'ला**
वर मानते: ओमचं ध्येयही तेच ठेवलंय (3.4).

**ओमवर:** ओम पट्टीवर स्वतःची जागा शोधतो: आज ₹0 (पट्टीबाहेर);
3.1 च्या ताळेबंदाने तो 'माणशी $60K+' ला (एकटा, $5K+/महिना
नफा) पोहोचला की **तो एकटाच TCS-माणशी-पट्टीच्या वर**:
हे त्याला हसवतं आणि पेटवतं: पट्टी अमूर्त 'unicorn' पेक्षा
जवळची, चढण्याजोगी झाली.

## महाग चूक

"Valuation = यश; मोठा आकडा = मोठा माणूस." तीन घोटाळे:
(1) कागदी आकडा बदलतो (Jasper: $1.5B -> कपाती: 2.6);
(2) गुणक **बाजार-मूड** आहे: तोच धंदा 2021 त 30x, 2023 त
6x: तुमच्या हातात ARR आहे, गुणक नाही: **नियंत्रणातल्या
आकड्यावर खेळा** (Book 8, 3.6 ची शिस्त); (3) मालकी-टक्का
गुणिल्याशिवाय आकडा अर्थहीन: 10% मालकीचं $1B < 100%
मालकीचं $150M. म्हणून एकट्याची खरी पट्टी: **ARR x margin x
मालकी-टक्का**: तिन्ही तुमच्या हातात: हेच स्वातंत्र्य.

## नकाशावर

```
3.1  ताळेबंद: gross ~55%, token-शिस्त
3.2  पट्ट्या: माणशी-कमाई $50K (सेवा) -> $2-4M (software) ->
     $5-9M (AI) -> एकट्याकडे झुकती; unicorn = ARR x गुणक
     (4-30x: बाजार-मूड); $1B = $33-100M ARR; कागद वि रोख;
     खरी पट्टी: ARR x margin x मालकी
```

**सूत्रावर:** माणशी-कमाईची चढण म्हणजे सूत्राचा इतिहास-आलेख:
'कामांचा गठ्ठा' माणसांकडून यंत्रांकडे सरकतोय तशी माणशी-रेषा
उडतेय: एकटा-unicorn हे त्या रेषेचं गणिती टोक आहे: चमत्कार
नाही, extrapolation.

## स्वतः बघा (5 मिनिटं)

तुमची आजची माणशी-कमाई काढा (वार्षिक उत्पन्न ÷ 1!). पट्टीवर
ठेवा. मग तीन लक्ष्यं लिहा: 1-वर्ष (उदा. सेवा-पट्टी ओलांडणं:
$50K+), 3-वर्षं, 5-वर्षं: प्रत्येकाला 'कुठल्या यंत्रणेने' ची एक
ओळ. Unicorn-स्वप्नापेक्षा ही तीन-पायरी शिडी हजारपट उपयोगी.

## विचार करा

ओम: "ARR वाढवायचा म्हणजे शेवटी **विकायचं**: आणि विकताना
तीन आकडे भेटतात: भाव किती ठेवू (pricing), गिऱ्हाईक आणायला
किती खर्च (CAC), आणि गिऱ्हाईक एकूण किती देऊन जातो (LTV).
हे त्रिकोणी गणित नीट मांडून द्या: चुकलं तर काय होतं तेही."

> पुढचा chapter: विक्रीचा त्रिकोण: भाव-मानसशास्त्र (का $19,
> $20 का नाही: आणि का $190 ही बरोबर असू शकतं!),
> LTV = भाव x महिने (churn चा राक्षस), CAC चे तीन रंग
> (फुकट-वेळ-पैसा), आणि LTV:CAC चा 3:1 अंगठा-नियम:
> सगळं ओमच्या आकड्यांनी.

# Chapter 3.3 [SPINE]: विक्रीचा त्रिकोण: भाव, LTV, CAC

तीन आकडे, एक त्रिकोण: चुकला की धंदा गळतो, जमला की
compounding. ओमच्या आकड्यांनी:

**कोपरा 1: भाव (pricing).** ओमचा $19 आला कुठून? तीन
तपास: (अ) **किंमत-अँकर:** गिऱ्हाईकाचा पर्याय काय: हे काम
माणसाकडून = महिन्याला $200+ (1.2 चा तक्ता!); त्याच्या 1/10
वर ओम स्वस्त 'वाटतो' पण token-खर्चाच्या 3 पट वर राहतो
(3.1); (ब) **मूल्य-भाषा:** भाव 'खर्चावर' नाही, **'वाचणाऱ्या
वेळेवर'** बांधायचा: 'महिन्याला 10 तास वाचतात' = $19 हास्यास्पद
स्वस्त: म्हणूनच वरचा-थरही ($49 'Pro') ठेवायचा: **काही गिऱ्हाईकं
नेहमी जास्त द्यायला तयार असतात: त्यांना दार हवं** (Book 9,
2.4 ची शिडी!); (क) **धाडस-नियम:** indie-जगाची सिद्ध चूक:
**भाव फार कमी ठेवणं** (आत्मविश्वासाचा प्रश्न, गणिताचा नाही):
भाव दुप्पट केला आणि 30% गिऱ्हाईकं गेली तरी उत्पन्न +40%:
आकडा मांडून बघा: 100 x $19 = $1,900 विरुद्ध 70 x $38 =
$2,660. **भाव हा product-निर्णयांतला सर्वात स्वस्त प्रयोग आहे**
(दुतर्फा दार! Book 8, 1.3).

**कोपरा 2: LTV (गिऱ्हाईक-आयुष्य-किंमत).** LTV = भाव x
सरासरी-महिने. महिने ठरवतो **churn** (गळती-दर): महिन्याला
5% गळती = सरासरी आयुष्य 1/0.05 = **20 महिने**: LTV =
$19 x 20 = **$380.** आता churn चा राक्षस बघा: गळती 5% ->
10% झाली: आयुष्य 10 महिने: LTV अर्धा ($190)! **churn हा
LTV चा silent killer**: आणि उलटं: 5% -> 2.5% = LTV दुप्पट
($760): **product-सुधारणा आणि गिऱ्हाईक-नातं (न-कोसळलेलं!)
हीच सर्वात मोठी 'विक्री'.** (पट्टे [MED]: B2C त महिन्याला
5-7% सामान्य; B2B त 2-4%; 2% खाली = उत्तम.)

**कोपरा 3: CAC (गिऱ्हाईक-मिळवणी-खर्च).** तीन रंग: **फुकट-रंग**
(1.6 ची साठणारी यंत्रं: build-in-public, SEO, product-आत
पसरणं: CAC ~ $0 पण **वेळ** जातो: तो मोजायचा!); **पैसा-रंग**
(जाहिराती, retainers: Cal AI चं यंत्र: CAC स्पष्ट मोजता येतो);
**मिश्र.** ओमचा हिशेब: retainer-प्रयोग: $500/महिना एका छोट्या
creator ला -> महिन्याला ~35 नवी गिऱ्हाईकं -> **CAC = $14.**

**त्रिकोण जोडा: अंगठा-नियम LTV:CAC >= 3:1.** ओम: $380:$14 =
**27:1** (उत्कृष्ट: म्हणजे तो **कमी** खर्चतोय: वाढ-पेडल दाबायला
जागा आहे: हे 'बचत छान' नाही; 'संधी सुटतेय' आहे!). नियम
उलटाही: LTV:CAC < 3 = प्रत्येक गिऱ्हाईक आणणं आतबट्ट्याचं:
वाढ = वेगाने बुडणं (Lensa-जातीच्या लाटांत नेमकं हेच घडतं:
लाट-CAC शून्य वाटतो, लाट संपली की खरा CAC उगवतो आणि
LTV लाट-गिऱ्हाईकांचा ठिसूळ). आणि तिसरी अट: **payback-काळ**:
CAC किती महिन्यांत वसूल? ($14 ÷ $19 = पहिल्याच महिन्यात:
एकट्याला हेच हवं: रोख-प्रवाह हाच त्याचा प्राणवायू: गुंतवणूकदाराची
उशी नाही.)

**ओमवर (त्रिकोणाचा वापर):** ओमची तिमाही-फेरी (1.5 च्या
आरसा-सवयीची मोठी बहीण): तीन आकडे फळ्यावर: भाव-थरांचं
मिश्रण, churn, CAC-रंगांचं मिश्रण. या तिमाहीचा निर्णय: churn
5.5% आहे: **वाढ-खर्चाआधी गळती-दुरुस्ती** (निघणाऱ्या 10
गिऱ्हाईकांना स्वतः फोन: न-कोसळलेलं नातं-काम: कारणांची यादी
-> product-दुरुस्ती). त्रिकोण त्याला **क्रम** देतो: काय आधी,
काय नंतर: भावना नाही, आकडा ठरवतो.

## महाग चूक

"वाढ म्हणजे नवी गिऱ्हाईकं." त्रिकोण उलटं शिकवतो: उत्पन्न-वाढीचे
**तीन** नळ आहेत: नवी गिऱ्हाईकं (CAC-नळ), कमी गळती (churn-
नळ), जास्त भाव/थर (pricing-नळ): आणि एकट्यासाठी क्रम बहुधा
**उलटा** सर्वोत्तम: आधी भाव-धाडस (एका दुपारचा प्रयोग, +40%),
मग गळती-दुरुस्ती (LTV दुप्पट), **मग** नवी गिऱ्हाईकं (आता
प्रत्येक नवं गिऱ्हाईक दुप्पट किमतीचं!). नव्या-गिऱ्हाईक-नळावरच
पडून राहणं म्हणजे फुटक्या बादलीत जोरात पाणी: indie-जगातली
रोजची शोकांतिका.

# Chapter 3.5 [SPINE]: फाटा: माणसं कधी: आकड्याचं उत्तर

'एकटा' हा धर्म नाही, रचना-साधन आहे (1.7): मग साधन बदलायची
वेळ **आकड्याने** ओळखू.

**भरतीची खरी किंमत (पगाराच्या पलीकडे).** पहिल्या माणसाची
किंमत = पगार + **जोडणी-खर्च** (1.1 चा O(n²) पहिल्यांदा
तुमच्या दारात: समजावणं, तपासणं, meetings) + **तुमचा शिकवण्याचा
वेळ** (पहिले 2-3 महिने: तुमच्या सर्वात महाग स्रोताची गुंतवणूक)
+ **यंत्रणा-कर्ज** (आजवर डोक्यात असलेलं सगळं लिहावं लागतं:
हे खरं तर फायदाच: पण वेळ आत्ता जातो). अंगठा-हिशेब: **पहिला
माणूस पहिल्या 6 महिन्यांत त्याच्या पगाराच्या दुप्पट 'खातो'**:
म्हणून भरती-निर्णय पगार-परवडण्याचा नाही; **वेळ-गणिताचा**
आहे:

```
फाटा-सूत्र: तुमचा-तास-भाव x त्या-कामाचे-महिन्याचे-तास
   विरुद्ध (माणूस/पर्यायाची किंमत x 1.5 ते 2)
तुमचा तास-भाव = (महिन्याचा नफा ÷ तुमचे कामाचे तास):
   पायरी-3 चा ओम: $5,270 ÷ 160 = ~$33/तास
उदाहरण: support ओमचे महिन्याला 40 तास खातो = $1,320
   चं 'तुमचा-वेळ-मोल'; part-time support-माणूस/contractor
   $600 त मिळतो: x2 धरूनही $1,200 < $1,320: फाटा
   ओलांडायची वेळ जवळ: आणि ते 40 तास निवड-वाटपात
   गेले तर किंमत $1,320 हून कैक पट (तिथे leverage आहे!)
```

**क्रम-यादी (काय आधी सोपवायचं):** नियम: **यंत्र-सोपवणी आधी,
माणूस-सोपवणी मग; आणि माणूस-सोपवणीत 'न-कोसळलेल्यांपासून
दूरचं' आधी:** (1) support-उत्तरं (escalation-सकट: 80% agent
आधीच घेतोय: उरलेल्याला माणूस: Klarna-धडा: इभ्रत-क्षण
माणसाकडे); (2) कारभार-ops (हिशेब-नोंदी, कागदं); (3) content-
अंमल (मसुदे यंत्राचे: **आवाज-मंजुरी तुमचीच**); (4) **शेवटी**
engineering (कारण तिथे यंत्र-leverage सर्वात जास्त आहे: Claude
Code + तुम्ही हीच जोडी सर्वात स्वस्त-जलद राहते सर्वात लांब);
आणि (5) **कधीच पूर्ण नाही: निवड-चव-नातं** (सोपवली की तुम्ही
'मालक-संपादक' न राहता नुसते 'मालक': चव गळते, brand पातळ
होतो: 1.7 चा खंदक-3 विकल्यासारखा).

**भरती-ऐवजीची तीन उत्तरं (फाटा लांबवणारी):** (1) **यंत्र-खोली
वाढवा:** भिंत बहुधा 'यंत्र अपुरं' नसते; 'नियम-पत्रं कच्ची' असते
(1.4): support-भार वाढला तर आधी agent-चौकट घासा (Book 9,
3.3 ची आरसा-सवय); (2) **contractors/तुकडा-काम:** पूर्ण-वेळ
जोडणी-खर्चाशिवाय हात: ठरावीक कामाला ठरावीक मोल (Cal AI
ची retainer-रीत माणसांनाही!); (3) **भागीदार-देवाण:** तुमचं
यंत्र-बळ x दुसऱ्याचं वाटप-बळ अशा अदलाबदली. तिन्ही संपली
आणि फाटा-सूत्र तरीही 'घे' म्हणतं: **तेव्हा घ्या: आणि उत्तम
घ्या** (पहिला माणूस संस्कृती ठरवतो: Book 8, 3.3).

**आणि प्रामाणिक चौथी वाट: न वाढणं.** पायरी-3-4 वर थांबून
**खोल** होणं (Levels-वाट): जाणीवपूर्वक निवडलेली छोटी-श्रीमंत-
स्वतंत्र कंपनी हे अपयश नाही; **एक शिखर आहे** (3.4 ची वाट-ब).
जिना चढत राहण्याची सक्ती फक्त गुंतवणूकदारांच्या जगात असते:
तुमच्या 100% मालकीच्या जगात **थांबा हाही नफ्याचा निर्णय
असू शकतो.**

**ओमवर:** ओम फाटा-सूत्र वहीत नोंदवतो आणि एक ओळ जोडतो:
"माझा पहिला 'कर्मचारी' आधीच कामावर आहे: **रोज रात्री राबणारी
यंत्र-पाळी** (1.5). माणूस-फाटा आला की मी तयार असेन: क्रम-
यादीसकट. तोवर: नियम-पत्रं घासणं हीच माझी HR."

## महाग चूक

दोन विरुद्ध टोकं, दोन्ही महाग: **टोक 1: 'भरती = यश-चिन्ह':**
जुन्या जगाची प्रतिष्ठा-मोजपट्टी (1.1 ची!): गरजेआधी माणसं =
margin-नाश + जोडणी-खर्च + वेग-मृत्यू. **टोक 2: 'एकटा = अहंकार':**
फाटा-सूत्र 'घे' म्हणत असताना न घेणं = तुमचा वेळ (कंपनीचा
सर्वात महाग स्रोत) स्वस्त कामांत जाळणं + burnout-वाट (Notch-
धडा). दोन्हींवर एकच औषध: **निर्णय आकड्याने** (फाटा-सूत्र) **+
क्रमाने** (यादी): भावना दोन्ही टोकांना ओढते; हिशेब मधून चालवतो.

## छोटा शब्दकोश (विभाग 3)

```
COGS             विक्री-मालाची थेट किंमत (इथे: tokens+infra)
gross margin     (उत्पन्न - COGS) ÷ उत्पन्न
revenue/employee माणशी-कमाई: युग-बदलाची पट्टी
ARR multiple     किंमत = ARR च्या किती पट: बाजार-मूड
LTV              गिऱ्हाईक आयुष्यभरात एकूण किती देतो
CAC              एक गिऱ्हाईक मिळवायचा खर्च
churn            मासिक गळती-दर: LTV चा silent killer
payback          CAC वसूल व्हायला लागणारे महिने
MRR              मासिक recurring उत्पन्न: जिन्याची पायरी-पट्टी
फाटा-सूत्र        तुमचा-तास-भाव x तास वि. पर्याय x 1.5-2
```
