# Chapter 3.4 [SPINE]: जिना: ₹0 ते unicorn-दिशा: सहा पायऱ्या

पुस्तकाचा कणा. प्रत्येक पायरीला तीन ओळी: **तिकीट** (इथून
पुढे जायला काय सिद्ध करावं लागतं), **यंत्रणा-बदल** (काय
नवं बांधावं लागतं), **मरण-जागा** (इथले बहुतेक कुठे मरतात).

```
पायरी 0: ₹0: शिकाऊ
   तिकीट: एक निवडलेला कोपरा + चालणारं product-बीज
   यंत्रणा: साधन-पट्टा (4.1) + रोजचं चक्र (1.5) + वाटप-
   यंत्र-1 चालू (product आधीही!)
   मरण-जागा: कधीच न-प्रकाशित करणं (perfection-लकवा);
   किंवा 10 कल्पनांत उड्या (Book 8, 1.6 ची नाही-कला)
पायरी 1: पहिला डॉलर: सिद्धता
   तिकीट: अनोळखी माणसाने पैसे दिले (मित्र नव्हे!)
   यंत्रणा: भाव-पान + Stripe-जोड + पहिल्या 10 गिऱ्हाईकांशी
   थेट बोलणं (प्रत्येकाशी!)
   मरण-जागा: फुकट-वापरकर्ते जमवत राहणं ('नंतर पैसे लावू':
   सिद्धता लांबवणं); पहिला डॉलर हे product-सिद्धतेचं एकमेव
   खरं प्रमाणपत्र आहे
पायरी 2: $1K MRR: चिन्ह
   तिकीट: ~50-60 गिऱ्हाईकं टिकून; churn दिसू लागतो
   यंत्रणा: support-agent + नियम-पत्रं (1.4); त्रिकोण-मोजणी
   सुरू (3.3); वाटप-यंत्रांत दुसरं चालू
   मरण-जागा: 'features वाढवू' चा मोह विरुद्ध गळती-दुरुस्ती;
   आणि इथेच बहुतेकांचा burnout-पहिला-झटका (चक्र-शिस्त!)
पायरी 3: $10K MRR: उपजीविका-मुक्ती
   तिकीट: ~500 गिऱ्हाईकं; धंदा पगारापेक्षा जास्त देतो
   यंत्रणा: 3.1 चा पूर्ण ताळेबंद जिवंत; token-शिस्त निर्णायक;
   escalation-रेषा पक्क्या; तिमाही-त्रिकोण-फेरी
   मरण-जागा: आराम ('पुरे झालं' vs 'पुढची पायरी'): दोन्ही
   योग्य असू शकतात: पण निवड जाणीवपूर्वक हवी (Levels-वाट
   इथून वळते: आणि ती हरणं नाही!)
पायरी 4: $100K MRR (~$1.2M ARR): संस्था-प्रश्न
   तिकीट: ~5,000 गिऱ्हाईकं किंवा वरचे-थर जड
   यंत्रणा: 1.7 च्या भिंती इथे खऱ्या: support-महापूर, on-call,
   कदाचित enterprise-दार: फाटा-निर्णय (3.5): माणसं/विका/
   आत-खोल
   मरण-जागा: भिंतींकडे दुर्लक्ष (गुणवत्ता घसरते -> churn ->
   उतरण); किंवा घाई-भरती (जोडणी-खर्च परत: 1.1!)
पायरी 5: विक्री किंवा साम्राज्य: दोन शिखर-वाटा
   वाट अ (विक्री): Base44/Frind: खरेदीदार + timing + मालकी-
   टक्का = बँकेतली रोकड; वाट ब (स्थिर साम्राज्य): Levels/
   Craigslist: कायमची मालकी, वार्षिक नफा, स्वातंत्र्य
   मरण-जागा: कागदी-किंमतीच्या मोहात रोख-वाट सोडणं;
   किंवा विक्री-क्षण हुकवणं (लाट ओसरल्यावर खरेदीदारही जातो)
```

**जिन्याची तीन सार्वत्रिक सत्यं:** (1) **पायऱ्या गाळता येत
नाहीत:** $1K आधी $100K ची यंत्रणा बांधणं = वजन-नसलेल्या
इमारतीला lift लावणं (उलटंही: $10K वर पायरी-1 ची यंत्रणा =
कोसळ); (2) **प्रत्येक पायरीवर 'धंदा' या शब्दाचा अर्थ बदलतो:**
0-1 त धंदा = product; 2-3 त = यंत्रणा; 4-5 त = संस्था/निर्णय:
**तुम्हीही पायरीगणिक बदलावं लागतं**: हीच खरी किंमत; (3)
**वेळ-अंदाज कुणालाच देता येत नाही:** Base44 ने जिना 6 महिन्यांत
घेतला, Frind ने 12 वर्षांत: दोघेही जिंकले: **पायरी-क्रम नक्की
आहे, वेळापत्रक नाही**: वेळापत्रकाची तुलना हीच indie-जगातली
सर्वात मोठी विष-सवय (2.5 ची वेग-अपेक्षा चूक).

**ओमवर:** ओम आज पायरी-0 वर उभा: आणि आता त्याला **पुढचं
एकच तिकीट** दिसतं: पहिला अनोळखी डॉलर. जिन्याचं देणं हेच:
'unicorn' चं धुकं जाऊन **पुढच्या पायरीची स्पष्टता**: बाकीच्या
पायऱ्या त्या-त्या वेळी.

## महाग चूक

"जिना = योजना: सहा पायऱ्यांचा 5-वर्षांचा plan बनवतो." जिना
नकाशा आहे, वेळापत्रक नाही (सत्य-3!): पुढच्या पायरीपलीकडचं
planning म्हणजे धुक्यात architecture (Book 8, 1.5: लांब क्षितिज
दिशेसाठी; पावलं आजची). योग्य वापर: **आजची पायरी ओळखा,
तिचं तिकीट लिहा, तिची मरण-जागा टाळा**: बास. आणि उलट
चूक: जिनाच नाकारणं ('मी वेगळा, मी थेट...'): पायऱ्या गाळणाऱ्यांची
यादी शवागारात आधीच बघितलीये.

## नकाशावर

```
3.1  ताळेबंद   3.2  पट्ट्या   3.3  त्रिकोण
3.4  जिना 6: ₹0 (कोपरा+बीज) -> $1 (सिद्धता!) -> $1K (चिन्ह)
     -> $10K (मुक्ती) -> $100K (संस्था-प्रश्न) -> विक्री/साम्राज्य;
     पायऱ्या गाळू नका; अर्थ पायरीगणिक बदलतो; वेळापत्रक-तुलना
     = विष
```

**सूत्रावर:** जिन्याच्या प्रत्येक पायरीवर सूत्राचं प्रमाण बदलतं:
खाली निवड-जड (काय बांधू), मध्ये वाटप-जड (कसं पोहोचू),
वर संस्था-जड (सीमेचं काय): पण तिन्ही जागी यंत्रं गठ्ठा उचलतात
आणि माणूस **त्या पायरीचा** प्रश्न सोडवतो.
