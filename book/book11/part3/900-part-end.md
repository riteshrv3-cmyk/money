# विभाग 3 चा हिशेब: गणित

## पाच हिशेब एका नजरेत

```
3.1  ताळेबंद   $9,500 -> gross ~55% (AI-native सामान्य);
               tokens = COGS-राजा; token-शिस्त = margin
3.2  पट्ट्या    माणशी-कमाई: $50K (सेवा) -> $2-4M (software)
               -> $5-9M (AI); unicorn = ARR x गुणक (4-30x);
               खरी पट्टी: ARR x margin x मालकी
3.3  त्रिकोण   भाव-धाडस | LTV = भाव x (1/churn) | CAC;
               LTV:CAC >= 3; वाढीचे 3 नळ, क्रम उलटा
3.4  जिना      ₹0 -> $1 -> $1K -> $10K -> $100K -> विक्री/
               साम्राज्य; पायऱ्या गाळू नका; वेळापत्रक-तुलना = विष
3.5  फाटा      भरती = पगार x2; फाटा-सूत्र तास-भावाने; क्रम:
               support->ops->content->eng; निवड-चव-नातं कधीच नाही
```

## स्वतःची परीक्षा (आधी उत्तरं, मग खाली)

1. AI-SaaS चं gross margin जुन्या SaaS हून कमी का: आणि
   ते परत वर आणायची तीन बटणं कुठली?
2. "one-person unicorn" चं तांत्रिक भाषांतर आकड्यांत करा.
3. churn 5% वरून 2.5% झाला तर LTV चं काय होतं आणि का?
4. जिन्याच्या पायरी-1 चं तिकीट काय: आणि ते इतकं महत्त्वाचं का?
5. फाटा-सूत्रात भरतीची किंमत 'पगार x 1.5-2' का धरतात?

> **उत्तरं:** (1) प्रत्येक वापराला token-मीटर (जुन्या software त
> प्रत फुकट); बटणं: model-निवड, cache-batch, context/वापर-
> मर्यादा (3.1). (2) ~$33-100M ARR चा वेगवान recurring
> धंदा x 10-30 गुणक = $1B; + तो गुणक मोजणारा व्यवहार
> (3.2). (3) आयुष्य 20 -> 40 महिने: LTV दुप्पट: churn हा
> silent killer/booster (3.3). (4) पहिला अनोळखी डॉलर:
> product-सिद्धतेचं एकमेव खरं प्रमाणपत्र: फुकट-वापरकर्ते
> सिद्धता लांबवतात (3.4). (5) पगारावर जोडणी-खर्च + तुमचा
> शिकवण्याचा वेळ + यंत्रणा-कर्ज चढतं (3.5).

## चाहूल: विभाग 4

शेवटचा विभाग = रस्ता: **साधन-पट्टा** (code/लेखन/चित्र-video/
voice/automation: कुठल्या कामाला कुठलं: power-user ची पूर्ण
सज्जता), **निवड-चाळणी** (काय बांधायचं: कपाटाचे सगळे चष्मे
एका चाळणीत), **90-दिवसांची मोहीम** (आठवडा-आठवडा: पहिल्या
डॉलरपर्यंत), **वाढ-यंत्र** ($0 -> $10K MRR ची यंत्रणा), आणि
**अंतिम परीक्षा + हात-पट्टी.**

## छोटा शब्दकोश (विभाग 3)

```
COGS             विक्री-मालाची थेट किंमत (इथे: tokens+infra)
gross margin     (उत्पन्न - COGS) ÷ उत्पन्न
revenue/employee माणशी-कमाई: युग-बदलाची पट्टी
ARR multiple     किंमत = ARR च्या किती पट: बाजार-मूड
LTV              गिऱ्हाईक आयुष्यभरात एकूण किती देतो
CAC              एक गिऱ्हाईक मिळवायचा खर्च
churn            मासिक गळती-दर: LTV चा silent killer
payback          CAC वसूल व्हायला लागणारे महिने
MRR              मासिक recurring उत्पन्न: जिन्याची पायरी-पट्टी
फाटा-सूत्र        तुमचा-तास-भाव x तास वि. पर्याय x 1.5-2
```
