# Chapter 1.4 [SPINE]: एकट्याची org-रचना: मालक-संपादक आणि यंत्र-विभाग

50-जणांच्या कंपनीची org-chart आठवा: वर CEO, खाली विभाग-प्रमुख
(product, engineering, marketing, support, हिशेब), खाली करणारे
हात. एकट्याची कंपनी ही chart **मोडत नाही; भूमिका तशाच ठेवून
हात बदलते:**

```
भूमिका            जुनं वाहन          नवं वाहन
ठरवणं (CEO)       माणूस              माणूसच (न-कोसळलेलं!)
बांधणं (eng)      4-6 engineers      Claude Code + तुमची
                                     देखरेख (Book 9, 3.3)
design            designer           चित्र-यंत्रं + चव तुमची
marketing-मजकूर   2-3 माणसं          लेखन-यंत्रं + आवाज तुमचा
support           2-4 माणसं          agent + escalation
                                     तुमच्याकडे
हिशेब-कागदं       accountant-ops     automation + महिन्याची
                                     तुमची नजर
QA-तपास          testers            चाचणी-agents + शेवटची
                                     मंजुरी तुमची
```

**नमुना बघा:** प्रत्येक ओळीत यंत्र 'करतं' आणि माणूस **ठरवतो-
तपासतो-चव लावतो**: 1.2 चे न-कोसळलेले पाच प्रत्येक विभागात
शिंपडलेले. म्हणून एकट्याच्या भूमिकेचं खरं नाव **मालक-संपादक**
(owner-editor): संपादक जसा: लिहीत नाही सगळं, पण **काय
छापायचं** तो ठरवतो, दर्जाची रेषा तो आखतो, आवाज त्याचा असतो.
(खरं उदाहरण: Medvi चा Gallagher: 12+ AI-साधनांचा मेळ:
code-यंत्रं, जाहिरात-चित्रं, आवाज-यंत्र: प्रत्येक विभागाला यंत्र,
संपादन स्वतः: पूर्ण विच्छेदन 2.2 त.)

**रचनेचे तीन नियम (नुसती chart नाही):**

**नियम 1: प्रत्येक विभागाला लिखित नियम-पत्र.** माणूस-विभागाला
जसं 'हे आमचं धोरण' असतं, तसं प्रत्येक यंत्र-विभागाला लिखित
सूचना-पत्र (Book 9, 3.3 ची CLAUDE.md + skills: इथे कंपनी-
पातळीवर): support-agent चं 'काय कबूल करायचं नाही', लेखन-
यंत्राचा 'आवाज', code-यंत्राचे 'कधीच-करू-नको'. **नियम-पत्रं
हीच तुमची खरी कंपनी**: ती जितकी पक्की, तितका तुमचा दिवस
मोकळा. (आणि Vend-धडा आठवा: Book 9, 2.3: चौकट नसलेला
agent = भोळा कर्मचारी: Medvi च्या chatbot ने खोटे भाव सांगितल्याची
खरी गोष्ट 2.2 त: चौकटीची किंमत तिथे रुपयांत दिसेल.)

**नियम 2: escalation-रेषा आधी आखा.** कुठलं यंत्र कुठला निर्णय
**स्वतः घेऊ शकतं** आणि कुठे तुमच्याकडे आणलंच पाहिजे: पैसे
परत देणं? सवलत? नवं feature कबूल करणं? कायद्याचा प्रश्न?
Book 4 (4.6) च्या brakes कंपनी-रूपात: रेषा जितक्या स्पष्ट,
तितके अपघात कमी: आणि **रेषा म्हणजे अविश्वास नाही; रचना
आहे** (50-जणांच्या कंपनीतही approval-रेषा असतातच!).

**नियम 3: तुमचा वेळ हा कंपनीचा एकमेव दुर्मिळ स्रोत: तसा
वाटा.** यंत्र-विभाग रात्रंदिवस चालतात; तुमचे 8-10 तासच आहेत.
ते फक्त तीन कामांना: **निवड** (आज काय, काय नाही: Book 8,
1.6), **तपास-संपादन** (यंत्रांच्या कामाची चव-मंजुरी), **नातं-वाटप**
(गिऱ्हाईकांशी, जगाशी: 1.6 त पूर्ण). या तिन्हींबाहेरचं काम हातात
दिसलं की प्रश्न: "हे कुठल्या यंत्र-विभागाकडे का नाही: नियम-पत्र
लिहायचं राहिलंय का?"

**ओमवर:** ओम त्याची पहिली org-chart लिहितो: 7 यंत्र-विभाग,
प्रत्येकाला एक-पानी नियम-पत्र (पहिल्या आवृत्त्या कच्च्या: चालतंय),
escalation-रेषा (पैसे/वचन/कायदा = फक्त मी), आणि स्वतःच्या
वेळाचं बजेट: 3 तास बांधकाम-संपादन, 2 तास गिऱ्हाईक-नातं,
2 तास वाटप, 1 तास निवड-नियोजन. कागदावर तो आता 'एकटा'
नाही: **8-विभागांची कंपनी आहे जिचा पगार-खर्च एका वर्गणीएवढा
आहे.**

## महाग चूक

"एकटा म्हणजे रचना-मुक्त: मूड लागेल ते करीन." हीच एकट्यांची
सर्वात मोठी मृत्यू-वाट: रचना नसेल तर तुम्ही कंपनी नाही, **छंद**
चालवता: यंत्रं सैरावैरा, दर्जा हेलकावे, गिऱ्हाईकाला दर आठवड्याला
वेगळा अनुभव. उलट टोकही खोटं: 'corporate सारखी' जड यंत्रणा
(50 नियम-पत्रं पहिल्या दिवशी). मध्य: **विभाग जन्मतो तेव्हा
त्याचं एक-पानी नियम-पत्र जन्मतं**: वाढ होईल तशी पानं. रचना
ही एकट्याची बेडी नाही; **एकट्याला अनेक होऊ देणारी** गोष्ट
आहे: सूत्राचा गाभा हाच.

## नकाशावर

```
1.1  Coase   1.2  कोसळ + न-कोसळलेले 5   1.3  leverage-जिना
1.4  org-रचना: भूमिका तशाच, हात यंत्रांचे; माणूस = मालक-
     संपादक; 3 नियम: नियम-पत्रं | escalation-रेषा | वेळ फक्त
     निवड-तपास-नातं यांना
```

**सूत्रावर:** "कामांचा गठ्ठा" आता **रचलेला** गठ्ठा झाला: विभाग,
नियम, रेषा. सूत्रात 'निवड आणि वाटप' माणसाकडे म्हटलं: org-
chart त्याचंच चित्र आहे: बाकी सगळे रकाने यंत्रांचे.

## स्वतः बघा (5 मिनिटं)

तुमच्या कामाची (नोकरी असो वा धंदा) org-chart काढा: तुम्ही
रोज ज्या भूमिका निभावता त्या विभाग म्हणून लिहा. प्रत्येकापुढे:
या विभागाचं नियम-पत्र लिहिलंय का? escalation-रेषा आहे का?
एक विभाग निवडून त्याचं एक-पानी नियम-पत्र आजच लिहा:
तुमच्या एक-माणसी कंपनीचा पहिला अधिकृत दस्तावेज.

## विचार करा

ओमला chart आवडली, पण शंका: "chart स्थिर आहे; **दिवस**
वाहता असतो. सकाळी उठल्यावर नक्की काय: आधी support-रांग?
नवं feature? marketing? या 8 विभागांचा मेळ एका दिवसात
कसा बसतो: खरे solo-founders चा दिवस आतून कसा दिसतो?"
