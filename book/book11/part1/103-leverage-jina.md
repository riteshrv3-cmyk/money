# Chapter 1.3 [SPINE]: Leverage चा जिना: श्रम, भांडवल, code, AI

**Leverage (उचल-शक्ती) = तुमच्या एका तासाचं फळ किती पट
होतं.** पहारीने एकटा माणूस दहा जणांचा दगड हलवतो: तीच
कल्पना कमाईत. या जिन्याची सर्वात गाजलेली मांडणी Naval
Ravikant ची (AngelList चा संस्थापक; त्याचा 2018 चा "How to
Get Rich" धागा: startup-जगाची गीता):

```
पायरी 1: श्रम-leverage: दुसऱ्यांचे हात.
   जुनी, सर्वांना कळणारी: 10 मजूर = 10x काम. दुखणं:
   परवानगी लागते (माणसं यावी लागतात), व्यवस्थापन-खर्च
   O(n²) (1.1!), आणि प्रत्येक हाताला पगार.
पायरी 2: भांडवल-leverage: दुसऱ्यांचा पैसा.
   पैसा कामाला लावणं (यंत्रं, जाहिराती, व्याज). शक्तिशाली
   पण परवानगी इथेही: कुणीतरी पैसा द्यावा लागतो (बँक,
   गुंतवणूकदार): आणि तो देणारा हिस्सा-नियंत्रण घेतो.
पायरी 3: code + media: परवानगी-विरहित leverage.
   Naval चं सोनेरी वाक्य: "code आणि media ही परवानगी-
   नसलेली उचल-शक्ती: झोपेत काम करणारे robots." एकदा
   लिहिलेलं software/video/लेख कोटी लोकांपर्यंत शून्य-
   अधिक-खर्चात (marginal cost ~ 0): कुणाची परवानगी
   नाही, कुणाचा पगार नाही. internet-युगातले नव-श्रीमंत
   सगळे या पायरीचे.
```

**आता पायरी 4: AI: आणि ती आधीच्यांहून जातीने वेगळी आहे.**
पायरी-3 ची मर्यादा लक्षात घ्या: code/media **तेच-तेच** करतात:
लिहिलेला program लिहिल्याइतकंच; video तोच. **निर्मिती**
(नवा code, नवा मजकूर, नवं उत्तर) अजून माणसाकडेच होती:
म्हणून पायरी-3 वाल्यालाही 'बनवण्याचे' तास लागायचेच. AI ने
नेमकं तेच फोडलं: **पहिल्यांदाच उचल-शक्ती स्वतः निर्णय घेते,
नवं घडवते, परिस्थिती बघून वागते** (Book 2/4 चं जग). म्हणजे:
पायरी-3 ने 'वाटप' शून्य-खर्चाचं केलं होतं; **पायरी-4 ने 'निर्मिती'
जवळजवळ-शून्य-खर्चाची केली** (1.2 चा कोसळ): आणि दोन्ही
परवानगी-विरहित: वर्गणी घ्या, सुरू करा.

**जिन्याचं एकत्र गणित (इथे जादू आहे):** पायऱ्या **गुणाकाराने**
जोडतात, बेरजेने नाही. एकटा ओम: AI-निर्मिती (पायरी-4: दिवसात
product-सुधारणा जी टीमला आठवडा) x internet-वाटप (पायरी-3:
ते जगभर शून्य-खर्चात) x थोडं भांडवल (पायरी-2: वर्गणी + servers:
महिन्याला हजारो रुपये, लाखो नाही) = **एका माणसाचं फळ शेकडो
पट.** आणि श्रम-पायरी (महाग, O(n²)) पूर्ण वगळलेली: **जुन्या
जगात कंपनी म्हणजे पायरी-1 चं व्यवस्थापन होती; नव्या जगात
पायरी-1 वगळणं हीच रचना.**

**आणि याच जिन्यावरचं गाजलेलं भाकीत:** Feb 2024, Sam
Altman (OpenAI चा CEO) जाहीरपणे: "आमच्या tech-CEO मित्रांच्या
group-chat मध्ये पैज लागलीये: **एक-माणसाची billion-डॉलर
कंपनी पहिल्यांदा कुठल्या वर्षी येईल**: AI शिवाय अकल्पनीय होतं;
आता होणारच." हे पुस्तक त्या पैजेची यंत्रणा तपासतंय: भाकीत
खरं ठरलंय का (आणि 'ठरलं' चे दावे किती खरे) ते Part 2 त
आकड्यांनी.

**ओमवर:** ओम स्वतःचा जिना-हिशेब मांडतो: श्रम-leverage शून्य
(टीम नाही: आता तो हे **वैशिष्ट्य** समजतो, कमतरता नाही);
भांडवल छोटं (बचतीचे काही हजार); code-media पूर्ण खुलं;
AI पूर्ण खुलं. त्याची रणनीती आपोआप निघते: **ज्या पायऱ्या
फुकट-खुल्या आहेत (3-4) त्यांत जगातल्या-वरच्या-टक्क्यात पोहोचणं**:
कारण तिथे प्रवेश-फी नाही, फक्त विद्या-फी: आणि विद्या हे
पुस्तक-कपाट देतंय.

## महाग चूक

"Leverage म्हणजे धोका: कर्जासारखं." गफलत शब्दाची: कर्ज-
leverage (पायरी-2 चं एक रूप) खरंच दुधारी: पण **code-media-AI
leverage त 'खाली' बाजू जवळजवळ नाही**: लिहिलेला code
फसला तर गेले फक्त तुमचे तास; कर्जासारखं दुसऱ्याचं देणं नाही.
हीच Book 8 (1.4) ची असमान पैज **रचनेत**: हार = वेळ (मर्यादित,
परवडणारी); जिंक = अमर्याद पट. म्हणून या जिन्यावर 'पैज न
लावणं' हीच सर्वात महाग चूक: फुकटची असमानता वाया घालवणं.
(पण नोंद: 'वेळ' ही तरुणाला स्वस्त वाटते आणि नसते: म्हणून
पैजाही निवडून: Book 8, 1.6.)

## नकाशावर

```
1.1  जुनं गणित: Coase   1.2  नवं गणित: कोसळ + न-कोसळलेले 5
1.3  leverage-जिना: श्रम (परवानगी+O(n²)) -> भांडवल (परवानगी)
     -> code-media (परवानगी-विरहित वाटप) -> AI (परवानगी-
     विरहित निर्मिती); पायऱ्या गुणतात; Altman ची group-chat-पैज
```

**सूत्रावर:** जिना सूत्राला जोड देतो: गठ्ठा हातात मावतो (1.2)
**आणि** हाताला शेकडो पटींची उचल मिळते (1.3): आता 'एकटा =
कंपनी' हे गणित पूर्ण; उरलं 'कंपनी = मोठी कंपनी' चं: त्यासाठी
org-रचना: पुढे.

## स्वतः बघा (5 मिनिटं)

तुमच्या गेल्या आठवड्याचे कामाचे तास चार पायऱ्यांत वाटा: किती
तास शुद्ध-श्रम (जे कुणीही/यंत्र करेल), किती code-media-निर्मिती
(एकदा करून पुन्हा-पुन्हा विकता येईल असं), किती AI-चालवणं?
बहुतेकांचं 80% पायरी-1 त निघतं: **तो आकडा दर महिन्याला
खाली आणणं** हेच 'जिना चढणं' चं व्यावहारिक रूप.
