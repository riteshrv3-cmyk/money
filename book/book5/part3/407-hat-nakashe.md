# Chapter 4.7 [SPINE]: पाच हात-नकाशे (टेबलावर चिकटवा)

वाचायचं नाही, **वापरायचं.** पाच एक-पानी याद्या: रचना ठरवताना,
database निवडताना, deploy करताना, नकाशा वाचताना, आणि
agent-सोबत बांधताना समोर ठेवायच्या.

## नकाशा 1: नवं system: रचना-निर्णय (सुरुवातीला)

```
[ ] सुरुवात सोपी: एक monolith, एक database; गरजेआधी
    तुकडे/scale नको (premature टाळा) (1.1, 2.6)
[ ] डेटा: नाती+शुद्धता हवी? -> SQL (डिफॉल्ट). प्रचंड-सैल-
    वेगवान? -> NoSQL. शंका -> SQL (2.2)
[ ] नाती आधी कागदावर (one-to-many, many-to-many) (2.1)
[ ] कुठली माहिती किती जुनी चालेल? (cache/CAP निर्णय) (1.4, 1.10)
[ ] सेवा वाढवल्या तर: फक्त API ने बोलतील, थेट DB-हात नाही (2.5)
```

## नकाशा 2: Scale ची भिंत आली (क्रम पाळा)

```
[ ] आधी: index (जिथे शोध) + cache (वारंवारचं) (1.3, 1.4)
[ ] मग: replicas कडे वाचनं वळवा (ताजं-हवं मुख्याकडे) (1.5)
[ ] मग: load balancer + अनेक stateless servers (1.8)
[ ] जड कामं queue त (idempotent!) (1.7)
[ ] शेवटी, नाईलाजाने: sharding (लेखनच आवाक्याबाहेर तर) (1.6)
[ ] "मोठा server" (vertical) हा शेवटचा/तात्पुरता उपाय
```

## नकाशा 3: अपयश-सज्जता + deploy (production आधी)

```
[ ] प्रत्येक बाहेरची विनंती: timeout (वाट अनंत नाही) (1.11)
[ ] retry: थांबत (backoff) + मोजून + idempotent (1.11)
[ ] circuit breaker: आजारी दुवा वेगळा (1.11)
[ ] deploy: canary (थोड्यांना आधी) + परत-फिरण्याचा रस्ता (3.3)
[ ] छोटे-वारंवार deploys > मोठे-क्वचित (सुरक्षित) (3.3)
[ ] backup आहे + तो तपासलेला आहे (GitLab!) (1.2, 2.9)
```

## नकाशा 4: नकाशा वाचणं (कुठलीही रचना, 2 मिनिटांत)

```
[ ] एका विनंतीचा पूर्ण रस्ता काढा (कुठून कुठे) (1.15)
[ ] एकच अपयश-बिंदू कुठे? (एक पडलं तर सगळं थांबतं) (1.8)
[ ] database: पैसे SQL त? सैल NoSQL त? की सगळं कोंबलं? (2.2)
[ ] cache कुठे? "जुनं कधी फेकायचं" विचारलंय का? (1.4)
[ ] सेवा-संवाद: API ने की थेट-DB-हात (धोका)? (2.5)
[ ] गर्दी/अपयश कुठे फुटेल? (queue? LB? timeout?) (1.11)
[ ] प्रत्येक पेटी "का आहे"? उत्तर नसेल तर fashion (2.10)
```

## नकाशा 5: Agent-सोबत बांधणं (AI-युग)

```
[ ] रचना-निर्णय मी घेतो (SQL/NoSQL, mono/micro, CAP):
    agent अंमलात आणतो (4.5)
[ ] स्पष्ट करार आधी: काय + कुठले सौदे (Book 4, spec) (4.5)
[ ] agent चं code: नकाशा-वाचन (नकाशा 4) लावून तपासा
[ ] Book 4 ची शिस्त: test/evals + brakes + review + observ.
[ ] over-engineering तपासा: agent ला "सोपं ठेव" सांगा
    (WhatsApp/Zerodha धडा) (4.1, 4.3)
```
