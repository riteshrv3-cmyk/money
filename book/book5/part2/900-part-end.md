## स्वतःची परीक्षा (4 प्रश्न, बोलून; उत्तरं खाली)

**1.** नवं app: database डिफॉल्ट SQL की NoSQL, आणि का?

> SQL: नाती+शुद्धता फुकट मिळतात, नंतर सोडता येतात; NoSQL
> ची खरी गरज (प्रचंड-सैल-वेगवान) असेल तरच तिकडे. Fashion
> नको. (2.2)

**2.** दोन सेवा आमच्याच आहेत; एकीने दुसरीच्या database ला
थेट हात घातला तर?

> करार (API) तुटला, सीमा गेली: आतला कुठलाही बदल दुसरीला
> फोडेल. सेवांनी फक्त API ने बोलावं. (2.5)

**3.** Amazon Prime Video ची गोष्ट काय शिकवते?

> रचना fashion ने नाही, गरजेने: त्यांनी microservices वरून
> परत monolith कडे जाऊन 90% खर्च वाचवला. प्रवाहाविरुद्ध
> सौदा बघणं = नजर. (2.6)

**4.** चालत्या database ची रचना बदलायची: पद्धत?

> विस्तार-आकुंचन: नवं जोडा (जुनं ठेवून) -> दुहेरी-लेखन ->
> वळण -> जुनं काढा; प्रत्येक पाऊल छोटं, उलटवता-येणारं;
> backup आधी. (2.9)
