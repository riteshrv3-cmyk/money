# Chapter 1.13 [SPINE]: शव-विच्छेदन: ज्या दिवशी जग बंद पडलं

हा chapter उलटा: चार खऱ्या महाप्रलयांची शव-विच्छेदनं (तपासलेली).
हेतू भीती नाही; उलट दिलासा आणि धडा: **जगातल्या सर्वात
हुशार teams नीही हे भोगलंय, म्हणजे अपयश लाज नाही: न
शिकणं लाज आहे.**

**प्रलय 1: Amazon S3, Feb 2017: एका टंकलेखन-चुकीने.**
Amazon चा S3 (जगाचा अर्धा data जिथे राहतो ती साठवण-सेवा)
चार तास बंद पडली. कारण? एक अधिकृत engineer, ठरलेल्या
पद्धतीने billing-यंत्रणा दुरुस्त करताना, एका command मध्ये
**चुकीचा आकडा** टाकला: ठरवलेल्यापेक्षा **कितीतरी जास्त**
servers बंद झाले. आणि गंमत (कडू): Amazon चं "सगळं व्यवस्थित
आहे का" दाखवणारं dashboard **स्वतः S3 वरच** चालत होतं:
म्हणून S3 बंद पडल्यावर dashboard ही लाल दाखवू शकेना:
Amazon ला Twitter वरून सांगावं लागलं! धडा: **एका माणसाची
एक टंकचूक जग बंद करू शकते: म्हणून धोक्याच्या commands
ना रचनात्मक अडसर हवेत** (Book 4, 4.5 चे brakes; एकाच
command ने प्रचंड विध्वंस अशक्य करणं).

**प्रलय 2: Knight Capital, 2012: 45 मिनिटांत $460 million.**
ही सर्वात थरारक. एका trading-company ने नवं code आठ
servers वर टाकायचं होतं; engineer **एक server विसरला.**
त्या एका जुन्या server वर एक **मृत, विसरलेलं** जुनं code
जागं झालं आणि वेड्यासारखे चुकीचे शेअर-व्यवहार करू लागलं.
45 मिनिटांत कंपनीने **~$460 million** गमावले: आणि कंपनीच
बुडाली. सकाळी 8 वाजता 97 **इशारा-emails** आले होते ("जुनं
code जागं झालंय"): कुणीही वाचले नाहीत. धडा दुहेरी: **अर्धवट
deployment (एक server विसरणं) = मृत्यू** (म्हणून पुढे 3.7 त
canary/सुरक्षित-deploy); आणि **इशारे वाजले पण कुणी बघत
नव्हतं** = observability असून **पाहणारा** नसेल तर व्यर्थ (1.12
चा कडू पूरक).

**प्रलय 3: Facebook, Oct 2021: 6 तास, आणि दारंही उघडेनात.**
एका नेहमीच्या देखभाल-command ने चुकून Facebook च्या सगळ्या
data-centers चा जगाशी संपर्क तोडला (BGP/DNS: internet चा
पत्ता-यंत्रणा). Facebook, WhatsApp, Instagram: 6 तास गायब.
आणि सर्वात विचित्र: engineers ना दुरुस्त करायला data-center
मध्ये **शिरताच येईना**, कारण **दाराचे electronic बॅज-lock
सुद्धा त्याच network वर** होते जे बंद पडलं होतं! धडा:
**तुमची दुरुस्ती-यंत्रणा त्याच गोष्टीवर अवलंबून असेल जी बिघडली,
तर तुम्ही अडकता** (circular dependency): बचाव-यंत्रणा नेहमी
**वेगळी, स्वतंत्र** हवी.

**प्रलय 4: CrowdStrike, Jul 2024: 85 लाख यंत्रं, एका update ने.**
एका सुरक्षा-company ने एक सदोष update पाठवलं आणि जगभरची
**~85 लाख** Windows यंत्रं एकदम कोसळली: विमानतळ, रुग्णालयं,
बँका ठप्प (इतिहासातला सर्वात मोठा IT-बिघाड, यंत्र-संख्येने).
कारण: update **सगळ्यांना एकदम** गेलं, आधी थोड्यांवर तपासून
नाही. धडा: **कुठलाही बदल सगळ्यांना एकदम देऊ नका; आधी
थोड्यांवर** (हाच 3.7 चा canary; इथे त्याची गैरहजेरी अब्जांची
पडली).

**चार प्रलयांचं समान सूत्र:** प्रत्येक ठिकाणी बिघाड **लहान**
होता (एक टंकचूक, एक विसरलेला server, एक command, एक
update); तो **पसरला** म्हणून महाप्रलय. म्हणजे 1.11 चा धडा
जगाच्या पातळीवर: **अपयश टाळता येत नाही; पसरणं टाळता
येतं.** आणि दुसरा, दिलासा देणारा धडा: या सगळ्या company नी
नंतर **प्रामाणिक शव-विच्छेदनं जाहीर** केली (कुणाला दोष न देता,
"रचना कशी बदलली"): तीच प्रौढ संस्कृती (3.6 त पूर्ण).

## महाग चूक

"आमचं छोटं app; असे महाप्रलय आम्हाला नाहीत." उलट: या
company कडे जगातले सर्वोत्तम engineers, अब्जांची यंत्रणा,
तरी कोसळल्या: कारण अपयश **कौशल्याचा** प्रश्न नाही, **गुंतागुंतीचा**
अपरिहार्य साथीदार आहे. तुमचं छोटं app कोसळलं तर बातमी
होणार नाही, पण गिऱ्हाईक जाईल तोच. धडा उलट घ्या: मोठेही
कोसळतात, म्हणून **अपयश गृहीत धरून बांधणं** ही लाज नाही,
शहाणपण आहे: आणि कोसळल्यावर **दोष न देता शिकणं** ही
खरी प्रौढता.

नाही (अशक्य), **पसरू न देण्यात** आणि **शिकण्यात** आहे.

## स्वतः बघा (5 मिनिटं)

कधी असा दिवस आठवा जेव्हा WhatsApp/Instagram/UPI काही
तास बंद होतं (2021 पासून अनेकदा घडलंय). तेव्हा वाटलं होतं
"एवढी मोठी company, कशी बंद पडली?": आता उत्तर माहीत आहे:
गुंतागुंतीच्या जाळ्यात एक लहान बिघाड पसरला. मोठेपणा आणि
नाजूकपणा एकत्रच येतात: हेच या chapter चं सत्य.

## विचार करा

आरतीचं app आता स्थिरावलंय: वेगवान, टिकाऊ, दृश्य, अपयश-
सज्ज. पण महिना-अखेरीस cloud चं bill आलं आणि आरती
हादरली: अपेक्षेच्या तिप्पट! सगळं "चालतंय" पण खर्च गिळंकृत
करतोय. ती विचारते: "servers, database, CDN, हे सगळं तर
लागतंच. मग bill एवढं का, आणि नक्की कशाचं?"

> मोठ्या systems मध्ये bill हे code इतकंच रचनेचं फळ असतं:
> आणि त्यात एक लपलेला, कपटी खर्च असतो जो बहुतेकांना
> उशिरा कळतो. Cloud-bill चं शरीर: विभागाची शेवटची भिंत.
