# विभाग 3: Context ची शिस्त

Harness ची पहिली वीट यंत्राच्या "टेबलावर" आहे. Book 2 ने
context window दाखवली (1.5): एका वेळेस रांगेत मावणारे tokens.
2026 ची विद्या पुढची आहे: **त्या रांगेत काय ठेवायचं, काय
काढायचं, कधी: याचं शास्त्र**: context engineering. **हे तुमच्या
धंद्यात कुठे येईल:** agent भरकटला, अर्धवट विसरला, महाग पडला:
यांतल्या 80% तक्रारींचं मूळ याच विभागात सापडतं. Prompt छान
लिहिणं ही 2023 ची विद्या होती; टेबल नीट लावणं ही 2026 ची.
