# विभाग 4: Harness प्रत्यक्ष: हात, टेबलं, Brakes

टेबलाची शिस्त (विभाग 3) झाली; आता agent चं शरीर बांधू:
हत्यारं (हात), subagents (अनेक टेबलं), MCP (हत्यारांची जोडणी),
brakes (न घडू देण्याची रचना), आणि बांधकामाची शिस्त: नियम +
आधी-करार-मग-काम. **हे तुमच्या धंद्यात कुठे येईल:** इथून पुढचं
सगळं थेट बांधणीचं आहे: या विभागानंतर "agent बांधणं" हा शब्द
तुमच्यासाठी धुकं राहणार नाही: यादी असेल.
