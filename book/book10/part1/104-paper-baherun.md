## महाग चूक

"Abstract वाचला = पेपर कळला." Abstract हा **जाहिरात-दावा**
आहे (प्रामाणिक, पण दावाच): 'काय' सांगतो, 'कसं-का' नाही.
Abstract-वाचनावर मतं बनवणारे (आणि हल्ली शीर्षक-वाचनावर!)
गोंधळ पसरवतात: 'attention is all you need' चा शब्दशः अर्थ
घेऊन 'बाकी काही लागतच नाही' म्हणणारे विसरतात की पेपरच्या
यंत्रात FFN-सांधे-embeddings सगळं आहे (2.7 त बघू: शीर्षक
'रांग-खिडकी लागत नाही' म्हणतं, 'फक्त attention पुरतं' नाही!).
शिस्त: **abstract = नकाशाची खूण; प्रवास = आतले विभाग.**

## नकाशावर

```
1.1  रांगेचं जग   1.2  लक्षाचा जन्म   1.3  पेपरची गोष्ट
1.4  पेपर बाहेरून: abstract = दावा (साधी रचना, फक्त लक्ष;
     28.4 BLEU; 3.5 दिवस x 8 GPU); 7-विभाग नकाशा; गाभा =
     विभाग 3; शीर्षकाचा नेमका अर्थ: 'रांग-खिडकी नको'
```

**सूत्रावर:** abstract चं 'simple' हे विशेषण सूत्राचाच अभिमान
आहे: एक प्रश्न ("कोण कुणाला किती लागू?") गुंतागुंतीच्या रांगांची
जागा घेतो: साधेपण ही ताकद.
