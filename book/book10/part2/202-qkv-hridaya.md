# Chapter 2.2 [SPINE]: Q-K-V: पेपरचं हृदय, हाताच्या आकड्यांनी

**ग्रंथालयाची उपमा (एकदा पक्की करा: पुस्तकभर पुरेल).** तुम्ही
ग्रंथालयात जाता. तुमच्या हातात **प्रश्न-चिठ्ठी** (Query): "स्वयंपाकाची
पुस्तकं हवीत." प्रत्येक कप्प्यावर **पत्ता-पाटी** (Key): "इतिहास",
"स्वयंपाक", "प्रवास". आणि कप्प्याच्या आत **ऐवज** (Value):
प्रत्यक्ष पुस्तकं. रीत: तुमची चिठ्ठी प्रत्येक पाटीशी **जुळवायची**
(जुळणी जास्त = त्या कप्प्याकडे लक्ष जास्त), आणि जुळणीच्या
प्रमाणात ऐवज गोळा करायचा. Attention म्हणजे नेमकं हेच: फक्त
इथे **प्रत्येक शब्द एकाच वेळी वाचक आणि कप्पा** असतो: त्याची
स्वतःची चिठ्ठी (Q), स्वतःची पाटी (K), स्वतःचा ऐवज (V).

**तीन रूपं येतात कुठून?** प्रत्येक शब्दाच्या अर्थ-बाणाला (embedding:
Book 2, 3.2) तीन **शिकलेली रूपांतर-यंत्रं** (matrices W_Q, W_K,
W_V: Book 7, 1.3!) लावली की तीन रूपं निघतात. उदाहरणादाखल
'मांजर' चा (सोपेपणासाठी) 4-आकडी बाण आणि 4x2 चं W_Q घेऊ:
बाण [1, 0, 1, 0] x W_Q = चिठ्ठी [1.0, 0.8] (Book 7, 1.4 चा
गुणाकार). **हे गुणाकार यंत्र शिकतं**: 'चिठ्ठी कशी लिहावी' हीच
त्याची विद्या. पुढच्या गणितासाठी तिन्ही शब्दांची तयार रूपं (2-आकडी:
हाताला पेलतील अशी):

```
शब्द      चिठ्ठी Q      पाटी K        ऐवज V
मांजर     [0.9, 0.2]   [1.0, 0.8]   [2, 0]
चटईवर    [0.3, 0.5]   [0.2, 0.4]   [0, 2]
बसली     [1.0, 1.0]   [0.6, 0.6]   [1, 1]
```

**आता पेपरचं समीकरण-1, पायरी-पायरीने.** 'बसली' या शब्दाला
वाक्य समजायचंय (कर्ता कोण? कुठे?). त्याची चिठ्ठी Q=[1,1]
प्रत्येक पाटीशी जुळवू: जुळणीचं गणित = **dot product** (Book 7,
1.2: सावली-गुणाकार: दिशा जुळल्या तर मोठा):

```
पायरी 1: गुण (scores)
   बसली-मांजर:  1x1.0 + 1x0.8 = 1.8   <- सर्वात जुळलं!
   बसली-चटईवर: 1x0.2 + 1x0.4 = 0.6
   बसली-बसली:  1x0.6 + 1x0.6 = 1.2
पायरी 2: √d_k ने भागा (d_k=2, √2 = 1.41: का ते 2.3 त!)
   1.8/1.41=1.28   0.6/1.41=0.43   1.2/1.41=0.85
पायरी 3: softmax (Book 7, 2.6: गुणांची टक्केवारी)
   e^1.28=3.60  e^0.43=1.54  e^0.85=2.34  (बेरीज 7.48)
   टक्के: 0.48, 0.21, 0.31
पायरी 4: टक्क्यांनी ऐवजांची भारित बेरीज
   0.48x[2,0] + 0.21x[0,2] + 0.31x[1,1]
   = [0.96+0+0.31, 0+0.42+0.31] = [1.27, 0.73]
```

**झालं!** 'बसली' चं नवं रूप [1.27, 0.73]: त्यात 48% 'मांजर'
मुरलंय (कर्ता सापडला!), 21% जागा, 31% स्वतः. **हेच पेपरचं
हृदय-समीकरण:** Attention(Q,K,V) = softmax(QK^T/√d_k)V:
आपण आत्ता ते **हाताने चालवलं.** आणि सगळ्यात सुंदर: हेच
गणित तिन्ही शब्दांसाठी **एकाच वेळी** होतं (प्रत्येकाची स्वतःची
चिठ्ठी: तीन प्रश्न, एकदम): Q, K, V हे तक्ते (matrices) बनवून
एकच मोठा गुणाकार: GPU चं आवडतं जेवण (1.1 चं दुखणं-2
इथेच मरतं).

**हे 'समज' का आहे (नुसती बेरीज का नाही)?** कारण टक्केवारी
**शिकलेली** आहे: W_Q-W_K अशी घडतात की व्याकरणाला जे
जुळायला हवं (क्रियापद-कर्ता, सर्वनाम-नाम) त्यांच्या चिठ्ठ्या-पाट्या
जुळतात. 'ती बसली' मधल्या 'ती' ची चिठ्ठी 'मांजर' च्या पाटीशी
जुळणं: **संदर्भ-समज म्हणजे हीच जुळणी** (Book 2, 4.3 चं
'ambiguity-निवारण' आता समीकरणात दिसलं).

## महाग चूक

"Q, K, V ही तीन वेगळी क्लिष्ट यंत्रं आहेत." उलट: तिन्ही **एकाच
बाणाची तीन रूपं** आहेत: तीन साधे गुणाकार: आणि संपूर्ण
attention म्हणजे फक्त चार पायऱ्या: गुणाकार, भागाकार, टक्केवारी,
भारित-बेरीज: **शाळेचं गणित.** पेपरची दहशत वाटते ती चिन्हांमुळे
(QK^T/√d_k!); चिन्हं सोलली की आत चौथीची आकडेमोड. हा
धडा सगळ्या AI-पेपरांचा: **दहशत notation ची असते, गणिताची
नसते** (Book 7 चं पूर्ण सूत्र: चष्मा लावा, डोंगर सपाट).

पायऱ्यांभोवतीचे मजले आहेत.
