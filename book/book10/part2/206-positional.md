# Chapter 2.6 [SPINE]: जागेची मुद्रा: sin-cos ची घड्याळ-जादू

**अडचण नेमकी:** attention चं गणित क्रम-आंधळं आहे: शब्दांचा
**गठ्ठा** बघतं, **रांग** नाही. रांगेचं यंत्र (RNN) फेकलं तेव्हा
क्रमाची फुकट-सोयही गेली. आता क्रम **माहिती म्हणून** परत
घालायचा: प्रत्येक शब्दाच्या बाणात 'मी जागा क्रमांक अमुक'
ही खूण मिसळायची.

**पहिली कल्पना (आणि तिचं दुखणं):** जागा-क्रमांकच मिसळा:
1, 2, 3... दुखणं: 100-शब्दी वाक्यात '100' हा आकडा बाणांतल्या
0.5-1.2 च्या नाजूक आकड्यांना **चिरडेल**; आणि यंत्राने 40
जागांवर शिकलं तर जागा-41 त्याला परकी. लागते अशी खूण जी
(अ) मर्यादित पट्ट्यात राहते (कधीच फुगत नाही), (ब) प्रत्येक
जागेला वेगळी, (क) आणि 'दोन जागांतलं **अंतर**' गणिताला
सहज दिसेल अशी.

**पेपरचं उत्तर: घड्याळांची रांग.** भिंतीवर अनेक घड्याळं: पहिलं
**जलद** (दर शब्दाला काटा खूप फिरतो), दुसरं हळू, तिसरं आणखी
हळू... शेवटचं **अति-संथ** (हजार शब्दांत जरा हलतं). प्रत्येक
जागेची खूण = **त्या क्षणी सगळ्या घड्याळांच्या काट्यांची स्थिती.**
जलद घड्याळ शेजारच्या जागा वेगळ्या करतं (जागा 5 वि. 6:
जलद काटा खूप वेगळा); संथ घड्याळ लांबचा पत्ता देतं (वाक्याच्या
सुरुवातीला की शेवटी). आणि काटे **गोल फिरतात**: स्थिती नेहमी
-1 ते +1 च्या पट्ट्यात: कधीच फुगत नाही (अट अ पूर्ण). काट्याची
स्थिती गणितात = sin आणि cos: म्हणून सूत्र:

```
PE(जागा, 2i)   = sin(जागा / 10000^(2i/d_model))
PE(जागा, 2i+1) = cos(जागा / 10000^(2i/d_model))
   (i = घड्याळ-क्रमांक: i वाढेल तसं घड्याळ 10000-च्या
    घातांनी संथ; प्रत्येक घड्याळ बाणाचे दोन आकडे भरतं:
    sin-कोन आणि cos-कोन: काट्याची पूर्ण स्थिती)
```

**हाताने (d_model=4: दोन घड्याळं: जलद x1, संथ x1/100):**

```
जागा 0 (मांजर):  [sin 0,    cos 0,    sin 0,     cos 0   ]
                = [0,        1,        0,         1       ]
जागा 1 (चटईवर): [sin 1,    cos 1,    sin 0.01,  cos 0.01]
                = [0.84,     0.54,     0.010,     1.000   ]
जागा 2 (बसली):  [sin 2,    cos 2,    sin 0.02,  cos 0.02]
                = [0.91,    -0.42,     0.020,     1.000   ]
```

बघा: पहिले दोन आकडे (जलद घड्याळ) जागोजागी झपाट्याने
बदलतात; शेवटचे दोन (संथ) रांगत सरकतात. ही चार-आकडी
मुद्रा शब्दाच्या अर्थ-बाणात **मिसळायची** (बेरीज): 'चटईवर'
चा बाण = चटईवरचा-अर्थ + जागा-1-ची-मुद्रा. आता 'मांजर
चटईवर बसली' आणि 'बसली चटईवर मांजर' चे बाण **वेगळे**:
क्रम परतला: रांगेशिवाय.

**आणि अट (क) ची जादू:** sin-cos ची शाळेतली ओळख आठवा:
कोन k ने पुढे सरकवणं हे **फिरवण्याचं** (rotation) साधं गणित
आहे: म्हणजे 'जागा p+k ची मुद्रा' ही 'जागा p च्या मुद्रे'चं ठरावीक
वळण: **'k अंतरावरचा शब्द' ही कल्पना यंत्राला एका सोप्या
रूपांतराने शिकता येते**: पेपरने घड्याळं निवडली ती नेमकी यासाठी.
(लेखकांनी 'शिकलेल्या मुद्रा' पण तपासल्या: निकाल जवळजवळ
सारखा: Table 3: पण sin-cos ला शिकवावं लागत नाही आणि
न-बघितलेल्या लांबीलाही चालतं: म्हणून तेच ठेवलं. गंमत: पुढच्या
युगाने हीच कल्पना आणखी घासून RoPE बनवली: 3.2 त.)

## महाग चूक

"sin-cos ही 'जादूची' निवड: असंच काहीतरी गूढ." उलट प्रवास
खरा: **गरजा आधी लिहिल्या** (फुगू नये, प्रत्येक जागा वेगळी,
अंतर गणिती-सोपं, कुठल्याही लांबीला चालावं), मग त्या गरजा
पूर्ण करणारं **सर्वात साधं** गणित शोधलं: त्रिकोणमिती. पेपर-
वाचनाची खोल शिस्त इथे शिका: विचित्र-दिसणाऱ्या प्रत्येक निवडीमागे
गरजांची यादी असते: **निवड पाठ करू नका; यादी शोधा** (Book 8,
1.1: मुळं). यादी सापडली की निवड 'जादू' न राहता 'अपरिहार्य'
वाटू लागते: तीच समजेची खूण.
