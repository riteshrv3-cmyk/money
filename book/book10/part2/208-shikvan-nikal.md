# Chapter 2.8 [SPINE]: शिकवण आणि निकाल: पेपरचे तक्ते बोलतात

यंत्र उभं; आता शाळा. पेपरचे विभाग 5-6 (Training, Results)
चार गोष्टी सांगतात:

**गोष्ट 1: शब्दांचे तुकडे (BPE).** यंत्राला अख्खे शब्द दिले तर
शब्दकोश अवाढव्य आणि नवा शब्द आला की पंचाईत. पेपरची रीत:
**byte-pair encoding**: वारंवार येणाऱ्या अक्षर-जोड्या जोडत-जोडत
~37,000 तुकड्यांचा (EN-DE, दोन्ही भाषांना **एकच**) संच
(Book 2, 2.3 चे tokens: त्यांचा जन्म-विधी हा). 'बसली' कदाचित
'बस'+'ली': नवे-दुर्मिळ शब्दही जुन्या तुकड्यांतून वाचता येतात.

**गोष्ट 2: Adam ची warmup-चाल.** शिकवण Adam ने (Book 7,
3.5 चा उतार-शोधक, सुधारित). पण पेपरची खास युक्ती **शिकण्याच्या
वेगाची (learning rate) चाल**: पहिली 4,000 पावलं वेग **चढत**
(warmup), मग हळूहळू **उतरत** (1/√step). का? सुरुवातीला
वजनं यादृच्छिक: पहिल्याच क्षणी मोठ्या उड्या = गोंधळात उड्या
(Book 7, 3.5 चा दरीत-उडी-धडा): म्हणून आधी चाचपडत, आत्मविश्वास
आला की जोरात, शेवटी बारीक-घासत. (आजही प्रत्येक LLM
याच चालीचा वंशज वापरतो: 'warmup' शब्द दिसला की आता
तुम्हाला यंत्र दिसेल.)

**गोष्ट 3: label smoothing: अति-खात्रीचं औषध.** शिकवताना
'बरोबर उत्तराला 100% दे' ऐवजी **90% दे, उरलेले 10% इतरांत
वाटा** (0.1 चा डोस). विचित्र वाटतं: मुद्दाम 'चूक' शिकवायचं?
पेपरची प्रामाणिक नोंद: याने यंत्राची आकडेवारी-खात्री (perplexity)
'बिघडते' पण **भाषांतर-गुणवत्ता (BLEU) सुधारते**: कारण 100%-
खात्रीचं यंत्र दगडी होतं (2.3 चा softmax-दगड शिक्षणातही!);
जरा-नम्र यंत्र पर्याय खुले ठेवतं. (Book 8 च्या भाषेत: यंत्रालाही
'मी चुकू शकतो' ची जागा ठेवली की निर्णय सुधारतात!)

**गोष्ट 4: निकाल आणि दोन अमर तक्ते.**

```
यंत्र            EN-DE BLEU   EN-FR BLEU   शिकवण-खर्च
आधीचे विजेते     ~26 (ensembles!)  ~41      प्रचंड
base (65M)      27.3         38.1         12 तास x 8 GPU
big (213M)      28.4         41.8         3.5 दिवस x 8 GPU
```

एकट्या यंत्राने ensembles (अनेक यंत्रांच्या फौजा!) हरवल्या:
अंशात्मक खर्चात. (बारकावे: big चा dropout EN-DE ला 0.3;
लेखन-वेळी v1 त EN-FR 41.0 होतं, अंतिम आवृत्तीत 41.8;
भाकीत-वेळी beam search रुंदी 4: Book 4, 2.2 च्या sampling-
जगाचा पूर्वज.) **Ablation-तक्ता (Table 3): 'काय काढलं तर
काय बिघडतं':** 1 डोकं: -0.9 BLEU; 32 डोकी: किंचित घसरण
(2.4); d_k खूप आटवला: घसरण (जुळणी-गणिताला जागा लागते);
मोठं यंत्र: चढ; dropout काढला: घसरण; sin-cos ऐवजी शिकलेल्या
मुद्रा: **जवळजवळ सारखं** (2.6). ablation = विज्ञानाची खरी
शिस्त: दावा नुसता 'चाललं' नाही; **'कशामुळे चाललं' सुट्टं करून
सिद्ध** (Book 7, 4.5: पेपर तोलताना ablations आधी बघा!).

**आणि Table 1: complexity चा तक्ता (पेपरचा 'का' विभाग):**
प्रति-थर काम: self-attention **O(n²·d)** विरुद्ध recurrent
**O(n·d²)** (n = वाक्य-लांबी, d = बाण-रुंदी: Book 6, 1.1 ची
Big-O भाषा!). n < d असेपर्यंत (सामान्य वाक्यं: n~50, d=512)
लक्ष स्वस्तही! आणि दोन निर्णायक रकाने: क्रमिक-पावलं: **O(1)
विरुद्ध O(n)** (समांतर-स्वातंत्र्य: 1.1 चं दुखणं-2 अंकात) आणि
माहितीचा लांबचा रस्ता: **O(1) विरुद्ध O(n)** (कुठलाही शब्द
कुठल्याही शब्दाला एका उडीत: दुखणं-1 अंकात). पेपरचा पूर्ण
दावा या एका तक्त्यात मावतो. (आणि भविष्याची कुजबुज: **n²**
हेच पुढच्या युगाचं दुखणं बनणार: लांब context ला लक्ष महाग:
Book 4, 3.1 ची context-भिंत इथे जन्मली: 3.2 त परतू.)

## महाग चूक

"निकाल-तक्ता = विजयाचा पुरावा: बाकी तपशील सजावट." उलटं:
**निकाल जुने होतात (28.4 केव्हाच मागे पडलं!); पद्धत अमर राहते.**
आजचा वाचक पेपरातून काय उचलतो: BPE (आजही), warmup
(आजही), label smoothing (आजही), ablation-शिस्त (आजही),
complexity-विचार (आजही: n² ची लढाई चालूच!). Benchmark-
आकडे विरुद्ध पद्धत-विद्या हा फरक Book 9 (1.6) त कंपन्यांना
लावला; इथे पेपरांना: **पेपर वाचा तो आकड्यांसाठी नव्हे, पद्धतींसाठी**:
आकडे बातमी आहेत, पद्धती संपत्ती.

## नकाशावर

```
2.1-2.7  सांगाडा | Q-K-V | √d_k | multi-head | जागा+मुखवटा |
         मुद्रा | सांधे
2.8  शिकवण: BPE-तुकडे, Adam+warmup-4000 (चढ मग उतार),
     label smoothing 0.1 (नम्रतेचा डोस); निकाल: 28.4/41.8,
     ensembles हरले, 3.5 दिवस; Table 3 ablations; Table 1:
     O(n²d) वि O(nd²), क्रमिक O(1), रस्ता O(1); n² = उद्याचं दुखणं
```

**सूत्रावर:** complexity-तक्ता हे सूत्राचं गणिती प्रमाणपत्र: 'रांग
मोडा' चा फायदा O(n) -> O(1) या दोन रकान्यांत सिद्ध. सूत्र
घोषणा होती; तक्ता हिशेब आहे.
