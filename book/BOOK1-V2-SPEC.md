# Book 1 v2: The Machine, 5 parts

## Why v2
User wants: less mistakes per unit (small parts, checked one by one),
tighter money connection, less dialogue, more doing.

## Structure: 5 separate PDFs
```
PART 1: PAISA AUR MACHINE        16 ch   (curriculum Part 0, 1, 2)
PART 2: MACHINE SE BAAT          12 ch   (curriculum Part 3, 4)
PART 3: MACHINES KA JAAL          8 ch   (curriculum Part 5)
PART 4: DATA AUR YAADEIN          7 ch   (curriculum Part 6)
PART 5: DUNIYA KO SERVE KARNA    15 ch   (curriculum Part 7, 8) + full glossary/map
```
Curriculum (chapter list, order, SPINE/DEPTH) unchanged from CURRICULUM.md.
Content rewritten fresh.

## Format rules (v2)
1. Direct voice, "aap" ki taraf. Running examples: user's phone, UPI, Claude Code.
2. Samvaad kam: Madhav-Kabir only to break a misconception, short blocks.
3. Every chapter ends with MAP PE: one line, where this sits in Layer 1-4
   and where money is made. SHAPE VARIES (rupee flow / who earns / company case).
   India + global mix.
4. One SOCHNE KE LIYE question per chapter, DERIVATION type
   ("agar yeh na hota toh kya tootata?"), answer directly below in quote block.
5. KHUD DEKHO: optional 5-minute task on own phone/laptop, zero setup.
6. Every section opener page: 3-4 lines "yeh aapke business decision mein kahan aayegi".
7. Part 2 onward: first page = 5 recap questions from previous part.
8. Each part has its own mini-glossary at the end.
9. Every chapter starts on a new page (page-break div before H1).
10. Language: Hinglish, technical nouns always English. No em-dashes, no emojis.
11. Delivery per part: PDF + auto-verify report + 10-point manual checklist for user.
12. User checks part N before part N+1 begins.
