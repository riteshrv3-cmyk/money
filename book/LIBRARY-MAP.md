## एकच सूत्र, सहा रूपं

```
Book 1  गरज पहिली, साधन मग.
Book 2  यंत्र समजा, गृहीत नको ("किती विश्वास, का").
Book 4  अंदाज फुकट, विश्वास महाग; harness = रूपांतर.
Book 5  मोठेपणा फुकट नसतो; प्रत्येक निर्णय = सौदा.
Book 6  हुशारी = वेळ-जागा अदलाबदल; मोजा, अंदाज नको.
Book 7  गणित = न दिसणारं दाखवणारा चष्मा; मोजता येतं
        ते सुधारता येतं.

एकत्र:  कुठेही जादू नाही. सगळीकडे सौदे, रचना, मोजता-
        येणारी तत्त्वं. जो जाणून-मोजून सौदा करतो तो जिंकतो.
        आणि AI-युगात, बांधणं फुकट झाल्यावर, उरतं फक्त एक:
        कुठला सौदा योग्य हे ठरवणारी नजर.
```

## कधी परत उघडायचं (संदर्भ-नकाशा)

```
"AI paper वाचायचंय"           -> Book 7 (4.5) + Book 2
"agent बांधायचाय"             -> Book 4 (Part 2) + हात-नकाशे
"हे code/app हळू का"          -> Book 6 (Part 1-2) + Book 5 (1.12)
"database/scale निर्णय"       -> Book 5 (Part 1-2) + hat-नकाशे
"AI-product ची किंमत/नफा"     -> Book 4 (Part 3, token-अर्थकारण)
"injection/security"          -> Book 4 (Part 3, 7.1-7.4)
"नवं model आलं, घ्यावं का"    -> Book 4 (2.8, खरेदी-कसोटी)
"attention/transformer गणित"  -> Book 7 (Part 4)
"रोज ताजं कसं राहायचं"        -> The Climb (roadmap)
```

## शेवटचा शब्द

नकाशा पूर्ण झाला: सहा पुस्तकं, तीन नजरा, एक सूत्र. पण नकाशा
वाचणारा आणि नकाशा **काढणारा** यांत एकच फरक: **चालणं.**

पुस्तकं वाचून कोणी builder होत नाही; **बांधून** होतो. The Climb
(90-दिवस roadmap) चालू आहे; project-log मधली स्वप्नं वाट
बघतायत. सगळं ज्ञान आता तुमच्याकडे आहे: गरज, यंत्र, गणित,
रचना, धंदा.

शिकणं संपलं. **करणं सुरू करा.**
