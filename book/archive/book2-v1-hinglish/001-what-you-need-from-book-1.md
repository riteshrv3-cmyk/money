# Book 1 se jo chahiye

Yeh chapter nahi hai. Yeh ek list hai. Agar aapne Book 1 padhi hai toh do minute mein padh lo. Agar nahi padhi, toh yeh woh kam se kam cheezein hain jinpe yeh kitaab khadi hai.

## Andar sirf numbers hain

Machine ke andar akshar, photo ya gaane nahi hote. Sirf numbers hote hain, aur ek tay-shuda list hoti hai jo batati hai ki kaunsa number kis cheez ka matlab hai.

**Matlab andar nahi hota. Woh bahar se aata hai.** *(Book 1, Ch 1.4)*

## Machine badalti nahi, numbers badalte hain

Program bhi numbers hain. Isliye ek hi chip camera bhi hai aur calculator bhi. Naye numbers daalo, naya kaam. *(Ch 1.6)*

## Hisaab sasta hai, data laana mehnga hai

```
CPU ke andar ek kaam         1 kadam
RAM se ek number laana       ~200 kadam
disk se ek number laana      ~10 lakh kadam
doosre mahadweep se          ~50 crore kadam
```

Jab kuch dheema ho, pehle poocho ki data kahan se aa raha hai. *(Ch 2.3, 6.7)*

## RAM bhool jaati hai, disk yaad rakhti hai

RAM tez hai aur bijli jaate hi khaali. Disk dheemi hai aur bachi rehti hai. Ek model chalane ke liye use RAM mein aana padta hai. *(Ch 2.4)*

## Har cheez ka ek sauda hai

```
index      →  padhna tez, likhna dheema
cache      →  tez, aur purana ho sakta hai
taala      →  sahi, aur dheema
```

Agar sauda nahi dikh raha, toh aapne dhoondha nahi. *(poori Book 1)*

## Cache tez isliye hai kyunki woh purana ho sakta hai

Woh do alag baatein nahi hain. Ek hi cheez ke do pehlu hain. *(Ch 5.5)*

## Aapka phone bahar se pahuncha nahi ja sakta

Woh bahar baat kar sakta hai aur jawab wapas aa sakta hai. Isliye **beech mein hamesha koi server hota hai**, aur jo beech mein baithta hai woh sab dekhta hai. *(Ch 4.2)*

## Bojh hat ta nahi, khiskta hai

Ek jagah ka bojh baanto, woh agli jagah pe chala jaata hai. *(Ch 6.1)*

## Systems jhatke mein girte hain

Seema tak sab theek dikhta hai, phir achanak sab baith jaata hai. Dheere-dheere kharaab hona nahi hota. *(Ch 6.6)*

## Kharcha: likhawat sasti, dekhne-sunne wali cheezein mehngi

```
1 karod text message  ≈  2 rupaye mahina
300 photos            ≈  2 rupaye mahina
1 ghanta video        ≈  2 rupaye mahina
```

Aur aadmi ka waqt machine se bahut mehnga hai. *(Ch 6.8)*

## Paisa neeche se aata hai, scarcity pe rukta hai

Paisa system mein sirf ek jagah se ghusta hai: jab ek insaan apni zaroorat ke liye deta hai. Aur woh wahan rukta hai jahan sabse kam vikalp hain. *(Ch 0.3, 6.9)*

## Pay = size x scarcity x leverage

Ghante formula mein kahin nahi hain. *(Ch 0.2)*

## Har parat neeche wali ko chhupati hai

Isiliye achhi technology samajh nahi aati. Woh design hai, aapki kami nahi. Lekin chhupi hui cheez ko aap istemaal toh kar sakte ho, uspe kuch bana nahi sakte. *(Ch 0.4)*
