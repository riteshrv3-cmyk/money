# Chapter 6.5  [SPINE]
## Claude Code aapki files kaise edit karta hai

### Samvaad

**Madhav:** Ek AI aapke computer pe aapki files badal deta hai. Model kisi doosre desh mein hai. Yeh kaise ho raha hai?

**Kabir:** Model file badal hi nahi sakta. Woh sirf likh sakta hai.

**Madhav:** Toh badal kaun raha hai?

**Kabir:** Koi program jo mere computer pe chal raha hai.

**Madhav:** Toh do hisse hain.

**Kabir:** Haan. Dimaag door hai, haath yahan hain.

**Madhav:** Ab batao chakkar kaise chalega. Aapne kaha "iss file mein tarikh ka format theek karo."

**Kabir:** Program woh baat model ko bhejta hai. Model kehta hai "pehle file padho."

**Madhav:** Aur model ne file padhi?

**Kabir:** Nahi. Program ne padhi aur uska text wapas model ko bheja.

**Madhav:** Phir?

**Kabir:** Model dekh kar likhta hai ki kya badalna hai.

**Madhav:** Poori nayi file likhega?

**Kabir:** Woh mehnga hoga. Agar file bahut badi hai toh poori dobara likhni padegi.

**Madhav:** Aur uska output ka daam kya hai?

**Kabir:** Sabse mehnga. Chapter 4.2.

**Madhav:** Toh?

**Kabir:** Sirf badlav likhe. "Yeh line hata do, yeh daal do."

**Madhav:** Aur woh badlav kis pe lagega?

**Kabir:** Program lagayega. Mere computer pe.

**Madhav:** Ab ek problem. Model ne likha ki "line 42 badlo," lekin file beech mein badal gayi.

**Kabir:** Toh galat jagah badlega.

**Madhav:** Toh kya karna chahiye?

**Kabir:** Line number ki jagah asli text batao. "Yeh wala text dhoondho aur usse badlo."

**Madhav:** Aur agar woh text na mile?

**Kabir:** Toh badlav mat lagao, aur model ko bata do ki nahi mila.

**Madhav:** Bas. Ab aakhri, aur yeh sabse zaroori hai. Program aapke computer pe chal raha hai. Uske paas kya kya taakat honi chahiye?

**Kabir:** Utni jitni kaam ke liye chahiye.

**Madhav:** Kya woh koi bhi file badal sake?

**Kabir:** Nahi. Sirf uss project ki.

**Madhav:** Kya woh koi bhi command chala sake?

**Kabir:** Nahi... lekin code ke liye toh command chalani padti hai.

**Madhav:** Toh?

**Kabir:** Toh kuch chalane do aur kuch pe pooche.

**Madhav:** Kaunse pe poochhe?

**Kabir:** Jo wapas na aa sake. Mitana, bhejna, paisa.

**Madhav:** Wahi teen, phir se. Chapter 6.3.

### Naam

Do hisse, hamesha alag:

```
MODEL      kisi aur ki machine pe. Sirf text banata hai.
           Uske paas aapke computer ka koi rasta nahi hai.

PROGRAM    aapke computer pe. Iske paas asli taakat hai.
           Yeh padhta hai, badalta hai, command chalata hai.
```

Ek poora badlav aise hota hai:

```
1.  aapne kaha ki kya karna hai
2.  program ne file padh kar model ko bheji
3.  model ne likha: yeh text dhoondho, usse badlo
4.  program ne dhoondha
       mila     →  badla, aur "ho gaya" wapas bheja
       nahi mila →  kuch nahi kiya, aur "nahi mila" wapas bheja
5.  model agla kadam chunta hai (Chapter 6.4)
```

Teen baatein jo iss chapter ki jaan hain.

**Ek: model ke paas aapke computer ka koi rasta nahi hai.**

Har cheez us program se hokar jaati hai. Woh program aapke haath mein hai, aur wahi tay karta hai ki kya ho sakta hai.

Yeh Book 1 Chapter 3.4 hai, teesri baar: **jispe aapka control nahi, use taakat mat do. Use maangne do.**

**Do: poori file likhwana mehnga hai, badlav likhwana sasta.**

Output sabse mehnga hissa hai (Ch 4.2). Isliye achhe systems badlav likhwaate hain, poori file nahi. Sasta, tez, aur galti ka daayra bhi chhota.

**Teen: line number nahi, text se badlo.**

Line number khisak jaate hain. Asli text ka tukda ek pehchaan hai jo khiskta nahi. Aur agar woh na mile, toh badlav ruk jaata hai, jo chup-chaap galat jagah badalne se hamesha behtar hai.

Yeh Book 1 Chapter 7.3 ki soch hai: **rukna aur poochna, chup-chaap galat kar dene se behtar hai.**

Aur ek chauthi baat, jo iss poore Part ka nichod hai:

> **Model ke paas sirf woh taakat hai jo aapne di. Aur uski galtiyon ki keemat usi list se tay hoti hai.**

### Asli duniya se

Aisi cheezein aksar kuch bachaav ke saath aati hain, aur woh sab isi soch se aate hain:

```
DIKHAO PEHLE       badlav lagane se pehle dikhao ki kya badlega
POOCHHO            khatarnak command pe ijaazat maango
DAAYRA             sirf iss project ke andar, bahar nahi
WAPAS JAANE KA     git ka istemaal, taaki sab kuch wapas ho sake
```

Aakhri wala sabse zaroori hai, aur woh Book 1 Chapter 7.3 se seedha aata hai.

**Agar aapka kaam version control mein hai, toh AI se badlav karwana lagbhag surakshit hai**, kyunki har cheez wapas ki ja sakti hai aur har badlav dikh jaata hai.

Agar nahi hai, toh aap ek aise cheez ko likhne de rahe ho jo apni galti nahi pehchan sakti, bina kisi wapas jaane ke raaste ke.

**Yeh farak technology ka nahi hai. Yeh aadat ka hai, aur woh aadat Book 1 mein thi.**

### Yahan log kya galat samajhte hain

Sabse aam galti: **yeh sochna ki AI "aapke computer pe chal raha hai."**

Model kisi aur ki machine pe hai. Aapke computer pe ek chhota program hai jo uska haath hai.

Iska seedha nateeja: **jo bhi file woh padhta hai, woh us doosri machine pe jaati hai.** Yeh Chapter 6.6 ka vishay hai, aur zyadatar log iske baare mein nahi sochte.

Doosri galti: **yeh maan lena ki jo usne kaha ki kar diya, woh ho gaya.**

Chapter 6.1 ka wahi niyam. Badlav dekho, file dekho, git mein dekho ki kya badla.

Teesri galti, aur yeh sabse mehngi: **use aisa daayra dena jismein sab kuch aa jaaye.**

Agar woh program aapke poore computer ko chhoo sakta hai, toh ek galat kadam ka daayra bhi poora computer hai.

Aur galat kadam sirf model ki galti se nahi aata. Woh us cheez se bhi aa sakta hai jo model ne padhi. Agla chapter usi pe hai.

### Sochne ke liye

**1. (samajh check)** AI ne kaha ki usne teen files badal di. Aap kaise jaanchoge?

> **Jawab:** Git se. Woh saaf dikha dega ki kaunsi files badli aur kya badla, line by line. *(Book 1, Ch 7.3)*
>
> Agar git nahi hai, toh aapke paas koi bharosemand tareeka nahi hai. Aap sirf woh dekh sakte ho jo aapko yaad hai ki dekhna chahiye.
>
> **Isiliye git AI ke saath kaam karne ki sabse zaroori taiyaari hai, aur uska AI se koi rishta nahi hai.**

**2. (samajh check)** Line number ki jagah text se badalna kyun behtar hai?

> **Jawab:** Kyunki line number khisak jaate hain aur text nahi.
>
> Model ne file padhi, phir kuch aur hua, phir badlav laga. Beech mein agar ek line jud gayi, toh saare number khisak gaye.
>
> Text se badlo toh do mein se ek hoga: sahi jagah milegi, ya kuch nahi milega.
>
> **Aur "kuch nahi mila" ek achha nateeja hai.** Woh galat jagah badalne se hamesha behtar hai, kyunki woh dikhta hai.

**3. (jodne wala)** Book 1 Ch 3.4 mein OS ne app ko taakat nahi di thi, aur Ch 6.3 mein server ne client pe bharosa nahi kiya tha. Yahan wahi shakal teesri baar kahan hai?

> **Jawab:** Program model pe bharosa nahi karta.
>
> ```
> Book 1 Ch 3.4    OS  →  app ko taakat nahi deta
> Book 1 Ch 6.3    server → client pe bharosa nahi karta
> yahan            program → model pe bharosa nahi karta
> ```
>
> Teeno jagah wahi soch hai: **jo cheez aapke control mein nahi hai, woh maang sakti hai, kar nahi sakti.**
>
> Aur teeno jagah woh soch hi ek matra asli bachaav hai. Model ko "achha" banane se yeh bachaav nahi aata. Woh dhaanche se aata hai.
