# Chapter 4.4: काय डोक्यात, काय यंत्रावर

## आधी अंदाज लिहा

```
1. "सगळं शोधता येतं, मग पाठ कशाला" यात नेमकी
   चूक कुठे आहे? ________________________________
2. AI-युगात न शिकताच चालेल अशी गोष्ट खरंच आहे
   का? एक सांगा: ________________________________
```

## चार खणांचा युक्तिवाद

"पाठांतर मेलं" या घोषणेला उत्तर 1.5 मध्ये आधीच पेरलेलं
आहे. परत आणू:

विचार करणं म्हणजे working memory च्या **चार खणांच्या
टेबलावर** गोष्टी एकत्र आणून जोडणं. आणि टेबलावर पटकन
येतं फक्त **गोदामातलं** (डोक्यातले chunks). बाहेरचं
(शोधलेलं, विचारलेलं) आणायला दार उघडावं लागतं: वेळ
जातो, आणि दार उघडताना टेबलावरचं अर्धं खाली पडतं.

```
उदाहरण: समोरच्याशी घासाघीस चालू आहे. margin चं
गणित, पर्यायी भाव, मागच्या कराराचे आकडे: हे त्या
क्षणी टेबलावर हवं. "थांबा, विचारून घेतो" म्हणणारा
तो क्षण हरतो: क्षण शोध थांबून वाट बघत नाही.
```

म्हणून नियम असा:

> **जोडण्या फक्त डोक्यातल्या गोष्टींमध्येच होतात. जे
> डोक्यात नाही, त्याची कल्पनाही सुचत नाही: कारण
> सुचणं म्हणजे जुन्या chunks ची नवी जोडणी.**

AI ला काय विचारायचं हे सुचायलाही विषयाचा नकाशा
डोक्यात लागतो. **रिकाम्या डोक्याला चांगले प्रश्नही पडत
नाहीत:** हीच AI-युगातली खरी गरिबी.

## मग विभागणी कशी करायची?

दोन प्रकारचं ज्ञान वेगळं करा:

```
नकाशा-ज्ञान (डोक्यातच हवं):
   क्षेत्राची रचना: काय-काय अस्तित्वात आहे, काय
   कशाला जोडलेलं आहे, कुठला प्रश्न कुठल्या दिशेला
   नेतो, "बरोबर" साधारण कसं दिसतं (चव/तपास-नजर),
   आणि रोजच्या वापरातले गाभा-chunks.
पत्ता-ज्ञान (यंत्रावर सोडा, बिनधास्त):
   नेमके आकडे-तपशील, syntax, तारखा, व्याख्यांचे
   शब्दशः रूप, क्वचित लागणाऱ्या गोष्टी: जिथे "कुठे
   मिळेल हे माहीत असणं" पुरतं.
```

चाचणी सोपी आहे: **ती गोष्ट "वापरताना क्षणात, टेबलावर"
लागते का?** लागते: डोक्यात (Anki/वहीने पक्की करा).
नाही: पत्ता ठेवा, माल यंत्रावर.

लक्षात घ्या: हा नियम calculator-युगापासून तोच आहे.
हिशेब यंत्राने करतो; पण "हे उत्तर साधारण किती यायला
हवं" ही जाण डोक्यातच लागते: नाहीतर यंत्राची चूक
पकडता येत नाही. AI ने माल वाढवला; नियम बदलला नाही.

## आणि विभागणी बदलत राहते

एक प्रामाणिक भर: ही रेषा स्थिर नाही. जे काल नकाशा-
ज्ञान होतं ते उद्या पत्ता-ज्ञान होऊ शकतं (उदा. code
च्या syntax चं तपशीलवार पाठांतर 2020 त मोलाचं होतं;
2026 त AI ते लिहितो आणि **तपास-नजर** मोलाची झाली).
म्हणून वर्षातून एकदा स्वतःला विचारा: **"माझ्या क्षेत्रात
आता क्षणात काय लागतं?"** आणि 2.3 आठवा: ही रेषा
सरकल्याचं न ओळखणं = negative transfer. रेषेवर लक्ष
ठेवणं हाच AI-युगातला शिकणाऱ्याचा नवा rोजगार आहे.

## इथे लोक चुकतात

**दोन उलटी टोकं, दोन्ही चुकीची:**

```
टोक 1: "आता काहीच पाठ नको."
   निकाल: रिकामं टेबल, प्रश्न न सुचणं, AI-उत्तरं
   तपासता न येणं, संभाषणात-निर्णयात मंदपणा.
   (4.2 चं कर्ज याच वाटेने वाढतं.)
टोक 2: "AI वर विश्वास नाही, सगळं डोक्यातच हवं."
   निकाल: पत्ता-ज्ञान घोकण्यात आयुष्य; जे यंत्र फुकटात
   देतं त्यावर महाग मानवी तास; आणि नकाशा-ज्ञानाला
   वेळच उरत नाही.
```

शहाणपण मधे नाही, **विभागणीत** आहे: नकाशा आत,
पत्ते बाहेर, आणि रेषेवर डोळा.

```
4.4  चार खणांचा युक्तिवाद: जोडण्या डोक्यातल्याच मालात;
     नकाशा-ज्ञान आत, पत्ता-ज्ञान यंत्रावर; चाचणी:
     "क्षणात लागतं का?"; रेषा सरकते: वर्षाला तपासा
```

**सूत्राशी:** यंत्राच्या युगात सूत्राचा अर्थ अरुंद होत नाही,
नेमका होतो: **बाहेर काढायच्या लायकीचं काय, हे निवडणं**
हेच आता शिकणाऱ्याचं पहिलं काम.


कुठल्याही कठीण पानाला भिडायची पद्धत.
