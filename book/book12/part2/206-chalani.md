# Chapter 2.6: नव्या युक्तीची चाळणी: 5 प्रश्न

## आधी अंदाज लिहा

```
1. उद्या एक course जाहिरात दिसली: "मेंदूचं गुपित:
   10x वेगाने शिका!" ती खरी की खोटी हे ठरवायला
   तुम्ही पहिला प्रश्न कुठला विचाराल? ______________
```

## चाळणी का लागते

शिकण्याच्या टिप्स कधीच संपत नाहीत: नवे course, नव्या
apps, नवे "मेंदू-शास्त्रज्ञ" influencer. त्यातलं काही खरं
असतं (हे पुस्तकही अशाच संशोधनावर उभं आहे), बरंच
खोटं. प्रत्येक वेळी खोलात जायला वेळ नसतो. म्हणून ही
चाळणी: **5 प्रश्न, 3 मिनिटं.** भाग 1-2 मधलं सगळं या
पाचांत दाबून भरलंय.

## पाच प्रश्न

```
प्रश्न 1: ही युक्ती कष्ट वाढवते की घटवते?
   "बिनकष्टात, झोपेत, 7 दिवसांत" = लाल दिवा.
   खऱ्या पद्धती आठवण्याचे कष्ट वाढवतात (1.7).
   सोपेपणाचं आश्वासन = fluency illusion ची विक्री (2.1).

प्रश्न 2: यात retrieval आहे का?
   युक्तीच्या वर्णनात "आठवा, सोडवा, स्वतःची परीक्षा,
   कोरा कागद" यातलं काही आहे? नसेल, आणि फक्त
   "बघा/ऐका/वाचा/absorb करा" असेल, तर ती ओळख
   विकतेय, आठवण नाही (1.4).

प्रश्न 3: परिणाम कधी मोजलाय: लगेच की उशिरा?
   "workshop संपताना सगळ्यांना येत होतं!" निरर्थक:
   लगेचचं जमणं टिकण्याबद्दल काहीच सांगत नाही (1.2).
   विचारायचं: आठवड्याने, महिन्याने काय उरतं? तो
   आकडा कुणी मोजलाय का?

प्रश्न 4: पुरावा कुणी दिलाय: विकणाऱ्याने की तिसऱ्याने?
   विकणाऱ्याचे "results" [स्व] असतात. स्वतंत्र तपासणी,
   शक्यतो अनेक; एकच सनसनाटी अभ्यास असेल तर
   आठवा: प्रसिद्ध अभ्यासही परत केल्यावर पडतात
   (2.2 चा violin-प्रयोग, आणि पुढे 3.6 मध्ये अजून एक).

प्रश्न 5: हे कुणासाठी आणि कशासाठी सिद्ध झालंय?
   शब्द-याद्यांवर सिद्ध झालेली युक्ती गणिताला लागू
   असेलच असं नाही. "सगळ्यांना, सगळ्यासाठी, नेहमी"
   चालणारी युक्ती अस्तित्वात नाही: तसा दावा हीच खूण.
```

गुणपत्रक साधं: **5 पैकी 4-5 पास = वापरून बघा. 2-3 =
स्वस्त चाचणी करा (2.4 ची पद्धत: आधी उंबरठा लिहा!).
0-1 = पैसे आणि आठवडे वाचले.**

## चाळणी चालवून दाखवतो: तीन उदाहरणं

```
"Anki app वापरा" (अंतराने उजळणीचं app):
   कष्ट? वाढवते (रोज आठवावं लागतं). retrieval? गाभाच.
   उशिराचं मोजमाप? हो, हेच त्याचं काम. पुरावा? शंभर
   वर्षांचा, स्वतंत्र. कुणासाठी? तथ्यं-शब्द-व्याख्यांसाठी
   उत्तम (मर्यादा 3.7 मध्ये). निकाल: 5/5 पास.

"subliminal शिकणं: झोपेत ऐकून भाषा शिका":
   कष्ट? शून्य (लाल दिवा). retrieval? नाही. मोजमाप?
   विक्रेत्याचे दावे. निकाल: 0/5. (झोप आधी शिकलेलं
   पक्कं करते: झोपेत नवं भरता येत नाही: 1.6.)

"मी बनवलेल्या notes च्या PDF वाचा, वेळ वाचवा":
   कष्ट? घटवते. retrieval? नाही: दुसऱ्याचे chunks
   म्हणजे तुमच्या डोक्यात सुटी अक्षरं (1.5). generation
   effect दुसऱ्याने खाल्ला (1.4). निकाल: 1/5. दुसऱ्याच्या
   notes "काय शिकायचं" च्या नकाशाला ठीक; शिकणं नाही.
```

## इथे लोक चुकतात

**"चाळणी फक्त दुसऱ्यांच्या युक्त्यांना लावणं."**

सर्वात कठीण वापर: **स्वतःच्या चालू पद्धतींना** हीच चाळणी
लावणं. तुमची आजची अभ्यास-पद्धत, तुमचं course-निवडणं,
तुमचं "मला जमतंय" हे वाटणं: पाचही प्रश्न तिथेही लागू
होतात. चाळणी बाहेर रोखलेली असताना शहाणपणा वाटतो;
आत फिरवली की शिकणं सुरू होतं. (2.5 चा धडा इथेही:
तज्ज्ञ-आंधळेपणा स्वतःच्या पद्धतींबद्दलही असतो.)

## नकाशा

```
2.1  fluency illusion + गुणपत्रक
2.2  चार खोटे समज पडले
2.3  तीन यंत्रणा: interference, Einstellung, transfer
2.4  मत मोडायची पद्धत (उंबरठा आधी!)
2.5  तज्ज्ञांचा आजार + चार रचना
2.6  चाळणी: कष्ट? retrieval? उशिराचं मोजमाप? कुणाचा
     पुरावा? कुणासाठी? -- 4+ पास तरच वेळ द्या
```

**सूत्राशी:** चाळणीचा पहिला प्रश्नच सूत्र आहे: कष्ट कुठे
आहेत? कष्ट नसतील तर शिकणंही नाही.

## स्वतः करून बघा (5 मिनिटं)

हे पाच प्रश्न एका card वर हाताने लिहा (हाताने: कारण
आता तुम्हाला माहितीये, ती एक retrieval-फेरी आहे). Card
अभ्यासाच्या जागी ठेवा. पुढच्या वेळी कुठलीही नवी युक्ती/
course/app समोर आली की 3 मिनिटं, पाच प्रश्न.

## आठवा

```
अ) पाचही प्रश्न, न बघता? (हा या chapter चा पूर्ण
   अभ्यासक्रम आहे)
ब) "subliminal शिकणं" कुठल्या प्रश्नांवर पडलं?
क) (मागचं) 2.5: चार रचनांपैकी तुम्ही निवडलेली कुठली?
ड) (भाग 1 मधलं, लांबचं) 1.1: Ebbinghaus च्या savings
   method चा अर्थ? (पहिली फेरी लांब गेली: spacing
   काम करतंय का बघू)
```

भाग 2 संपला. पुढचं पान: उजळणी-फेरी (आता भाग 1
**आणि** 2 दोन्हींवर: अंतर वाढतंय, लक्षात आलं?), उत्तरं,
आणि भाग 3 ची चाहूल: **आता तत्त्वांकडून माणसांकडे.**

आणि प्रत्येकाच्या गोष्टीत खरं किती, फुगवलेलं किती, याची
लेबलं लावूनच.
