# Chapter 1.5 [SPINE]: धंद्याचं रूप: कोण देतं पैसे, आणि code चं राज्य

$65B+ चा वेग नक्की कुठून येतो? धंद्याचा एक्स-रे काढू: आणि
त्यात एक आश्चर्य आहे जे OpenAI च्या नेमकं उलटं आहे.

**एक्स-रे 1: API आधी, app नंतर.** बाहेरच्या विश्लेषकांचा अंदाज
(अधिकृत फोड IPO नंतरच येईल): कमाईत **~80% धंदे-गिऱ्हाईक
(API/enterprise), ~20% consumer-वर्गण्या.** OpenAI चा तराजू
उलटा (ChatGPT चं consumer-राज्य). म्हणजे: OpenAI **लोकांची**
कंपनी आहे, Anthropic **धंद्यांची.** आकडे: 3 लाखांवर business-
गिऱ्हाईकं; **हजारावर कंपन्या वर्षाला $1M+ देणाऱ्या**; Fortune
100 पैकी ~70% कुठे-ना-कुठे Claude वापरतात. आणि हे 1.3 शी
जोडून वाचा: enterprise नेमकं **विश्वास** विकत घेतं: safety-
रणनीती आणि 80-20 तराजू ही एकाच नाण्याची दोन अंगं.

**एक्स-रे 2: code चं राज्य.** Claude चं सर्वात मोठं एकल काम:
**programming.** Anthropic च्याच वापर-अभ्यासात (Economic
Index) claude.ai वरचा ~36% वापर coding चा; enterprise
AI-coding बाजारात Claude चा वाटा **अर्ध्याच्या आसपास**
(बाहेरचे अंदाज ~54%). का code च? Book 4 (5.4) चं उत्तर
आठवा: code हे AI साठी **परफेक्ट मैदान** आहे: उत्तर तपासता
येतं (चालतो की नाही!), चुकीची किंमत लगेच दिसते, आणि
गिऱ्हाईक (developers) नवं लगेच स्वीकारतो. Claude ची coding-
कीर्ती हा अपघात नाही: **जिथे विश्वास मोजता येतो तिथेच विश्वास-
विकणारा सर्वात आधी जिंकतो.**

**एक्स-रे 3: Claude Code: दुकानातलं नवं इंजिन.** Feb 2025:
संशोधन-झलक म्हणून जन्म; May 2025: GA. मग स्फोट: **~6
महिन्यांत $1B चा वेग** (enterprise-software इतिहासातली सर्वात
वेगवान $1B-धाव), Feb 2026 त $2.5B पार, आणि 2026 मध्येही
चढताच (नंतरचे आकडे अजून जाड पण अ-अधिकृत). हे product
वेगळं का: API विकते **विटा**; Claude Code विकतं **बांधकाम**:
वर चढलेला थर स्वतः agent आहे (Book 4 चा harness विकत
मिळतोय!). आणि आतली गंमत: Anthropic मध्येच Claude आता
बहुतांश code लिहितो: कंपनीच्या जाहीर विधानांत merged code
च्या ~70-90%, आणि Claude Code चा निर्माता Boris Cherny
(Jan 2026): स्वतःचा code आता "100%" Claude-लिखित. **दुकानदार
स्वतःच्या मालावर दुकान चालवतोय**: यापेक्षा मोठं demo नाही.

**एक्स-रे 4: consumer-बाजी: "जाहिराती नाहीत."** Feb 8, 2026:
Anthropic ची पहिली Super Bowl जाहिरात-मालिका: नेमकी OpenAI
ने ChatGPT त जाहिराती आणण्याच्या घोषणेनंतर: संदेश एकच:
**"Ads are coming to AI. But not to Claude."** निकाल: रोजचे
वापरकर्ते +11%, app अमेरिकी store त #7. चाल ओळखा (Book 8,
2.3): consumer-संख्येत OpenAI ला गाठणं अशक्य: मग **वेगळ्या
अक्षावर** लढ: "आम्ही तुमचं लक्ष विकत नाही" हा विश्वास-brand:
सूत्राचीच जाहिरात-आवृत्ती.

**मीरावर:** मीरा या नकाशात स्वतःला शोधते: ती $100 Max-वर्गणीत
Claude Code वापरते: म्हणजे ती त्या 20% consumer-प्रवाहात:
पण **काम** करते enterprise-जातीचं. तिचा निष्कर्ष: (अ) तिचं
मुख्य हत्यार (Claude Code) हे कंपनीचंही सर्वात वेगाने वाढणारं
अपत्य आहे: त्यात गुंतवणूक चालू राहणार: तिची विद्या शिळी होणार
नाही; (ब) जग जिथे पैसे ओततंय (code) तिथेच तिची सेवाही
आहे: लाटेच्या दिशेने पोहतेय: दोन्ही खात्री पुरवठादार-निवडीला
बळ देतात.

**CEO-चष्मा:** Dario साठी 80-20 तराजू ही निवड आहे: enterprise
= जाड, टिकाऊ, विश्वास-प्रीमियम देणारी कमाई; consumer =
brand आणि पुढच्या पिढीची सवय. मीरासाठी: पुरवठादाराची कमाई
**कुठून** येते हे बघणं = तो कुणाचं ऐकेल हे ओळखणं (तो
enterprise चं ऐकेल: म्हणजे स्थिरता-सुरक्षा-हमी या दिशेने वाढेल:
तिच्या पथ्यावरच).

## महाग चूक

"AI-कंपनीची ताकद तिच्या model च्या हुशारीत असते." अर्धसत्य:
आणि महाग. Model-हुशारी दर सहा महिन्यांनी सगळ्यांकडे येते
(स्पर्धक कॉपी करतात, benchmarks जुळतात: Book 8, 2.1 चा
'product = प्रवेश-फी'); टिकतं ते **वापराचं जाळं**: 3 लाख
धंदे-गिऱ्हाईकं ज्यांचे workflows-tools-सवयी Claude भोवती
विणल्यात (switching-cost खंदक), आणि Claude Code सारखी
थरावरची उत्पादनं. Model बदलता येतो एका रात्रीत; **विणलेलं
जाळं उसवायला वर्षं लागतात.** कंपन्या तोलताना model-स्कोअर
नका बघू; जाळं बघा.

## नकाशावर

```
1.1  फूट   1.2  जग-चित्र   1.3  safety=रणनीती
1.4  पैसा: $87M->$65B+, $965B चिठ्ठी
1.5  धंदा: ~80-20 (enterprise आधी); code=राज्य (~36% वापर,
     AI-coding बाजाराचा ~अर्धा); Claude Code: 6 महिन्यांत

```

**सूत्रावर:** enterprise जास्त पैसे कशाला देतं? हुशारीला नाही:
**जबाबदारीला.** 80-20 तराजू हा सूत्राचा ताळेबंद-पुरावा आहे:
विश्वास महाग विकला जातोय, प्रत्यक्ष, अब्जांत.

## स्वतः बघा (5 मिनिटं)

तुमच्या (किंवा ओळखीच्या कुणाच्या) धंद्याचा 80-20 काढा: कमाई
कुठल्या **जातीच्या** गिऱ्हाईकाकडून येते: थोडी मोठी की खूप
छोटी? मग Anthropic-प्रश्न: "जाड बाजू कुठली, आणि ती नेमकं
**काय** विकत घेते: माल की खात्री?" उत्तर 'खात्री' निघालं तर
तुमचा खरा माल विश्वास आहे: त्याची किंमत वेगळी लावायला
शिका.
