# Chapter 2.5 [SPINE]: MCP ची गोष्ट: फुकट वाटून जिंकलेलं युद्ध

**अडचण (2024):** AI-यंत्रं हुशार झाली, पण जगाशी **जोडलेली**
नव्हती: प्रत्येक कंपनीला आपला data-tools प्रत्येक AI शी जोडायला
वेगवेगळ्या जोडण्या बांधाव्या लागत (Book 4, 4.2: M x N समस्या:
M यंत्रं x N साधनं = M x N जोडण्या). जोडण्यांचा हा गोंधळ =
agent-युगाची अडलेली वाट.

**चाल (Nov 25, 2024):** Anthropic ने **Model Context Protocol
(MCP)** काढला: यंत्र-साधन जोडणीची **एक सामाईक भाषा**
(जोडणी एकदाच बांधा: MCP बोलणारं कुठलंही यंत्र ती वापरेल:
M x N चं M + N). आणि इथे खरी चाल: **पूर्ण open-source,
फुकट, स्पर्धकांनाही खुला.** जगाने विचारलं: स्वतःच्या खर्चाची
गोष्ट फुकट का?

**उत्तर सहा महिन्यांत मिळालं:** Mar 2025: **OpenAI ने MCP
स्वीकारला** (Altman जाहीरपणे: उत्कृष्ट, आम्हीही वापरणार).
Apr 2025: **Google DeepMind ही** (Hassabis चं समर्थन).
म्हणजे: तिन्ही राजांचं agent-जग आता **Anthropic ने लिहिलेल्या
भाषेत** बोलतं. मग शिखर-चाल Dec 9, 2025: MCP **दानच
करून टाकला**: Linux Foundation खालच्या Agentic AI Foundation
कडे (Block-OpenAI सह-संस्थापक; Google-Microsoft-AWS-
Cloudflare पाठीशी): "आता ही कुणा एका कंपनीची मालमत्ता
नाही." आकडे (2026): **10,000+ जाहीर MCP-servers**; महिन्याला
कोट्यवधी downloads; OpenAI ने तर आपली जुनी जोडणी-यंत्रणा
मोडीत काढून MCP-वाट धरली.

**हे Book 8 च्या चष्म्याने (standard-युद्धांची विद्या):** (1)
**नळ फुकट, पाणी विकत:** protocol फुकट वाटला की त्याभोवतीचं
जग (साधनं, सवयी, विद्या) वाढतं: आणि त्या जगात सर्वात मुरलेला
खेळाडू कोण? भाषा लिहिणाराच (Book 8, 2.2 चं platform-गणित:
इथे मैदानही फुकट वाटलं, कारण खेळाडू आपण सर्वात तयार);
(2) **दान = विश्वासाची किंमत:** मालकी ठेवली असती तर स्पर्धकांनी
पर्यायी standard काढला असता (युद्ध, विखंड); दान केल्याने
standard **एकच** राहिला: आणि "आम्ही मालकीसाठी नाही"
हा संदेश enterprise-विश्वासात जमा झाला (सूत्र!); (3) **नकळत-
आठवण:** हीच चाल इतिहासात Google ने Android शी (फुकट
OS -> जगाचं mobile-मैदान -> वर आपली दुकानं) खेळली होती:
Anthropic ने ती agent-जोडण्यांशी खेळली: नमुने फिरून येतात:
Book 8, 3.6 ची नजर असेल तर **आधी** दिसतात.

**Skills ची पुनरावृत्ती (Dec 2025):** तीच चाल पुन्हा: कौशल्य-
पुड्यांचं (2.4) रूपही open standard: व्यूह उघड आहे: **agent-युगाच्या
पायाभूत भाषा आपल्या लेखणीतून निघाव्यात**: कारण भाषा लिहिणाऱ्याला
भाषेच्या भविष्याची दिशा कळत राहते.

**मीरावर:** मीरासाठी MCP दुहेरी भेट: (अ) **बांधकाम स्वस्त:**
तिच्या गिऱ्हाईक-app ला हिशेब-software शी जोडायला तयार
MCP-server मिळतो: जोडणी-काम आठवड्याचं दिवसावर; (ब)
**विमा:** MCP-वर बांधलेलं तिचं काम कुठल्याही यंत्रासोबत चालेल
(standard सामाईक!): उद्या पुरवठादार बदलावा लागला तरी जोडण्या
जगतात: hedge फुकटात (Part 3, 3.5 ची शिस्त इथून सुरू).

**CEO-चष्मा:** Dario साठी MCP-दान म्हणजे छोटा त्याग, मोठं
राज्य: protocol ची मालकी गेली, **युगाच्या रचनेवरची छाप**
राहिली. मीरासाठी: standards दिसले की प्रश्न विचारायचा: "हे
कोण लिहितंय, आणि फुकट का?": उत्तरात पुढच्या दशकाचा
नकाशा असतो.

## महाग चूक

"Open-source/फुकट म्हणजे धर्मादाय: धंद्याचं गणित नाही."
Tech-इतिहासाची सर्वात न-समजलेली चाल. फुकट वाटणं ही
**वाटप-रणनीती** आहे (Book 8, 2.5): standard पसरवायचा
सर्वात जलद मार्ग = किंमत शून्य करणं. गणित सोपं: protocol-
विक्रीतून मिळणारे (समजा) काही million विरुद्ध standard-युगाच्या
केंद्रस्थानी राहण्याची किंमत: अब्जांची. पण उलटी चूकही टाळा:
सगळंच फुकट वाटणारा धंदा उभा राहत नाही: **फुकट तेच वाटायचं
जे पसरल्याने तुमच्या विकाऊ मालाची किंमत वाढते** (MCP पसरला
-> agents वाढले -> यंत्र-वापर वाढला -> Claude ची विक्री
वाढली). फुकटाचं गणित नेहमी विकतच्या गोष्टीकडे बोट दाखवतं.
