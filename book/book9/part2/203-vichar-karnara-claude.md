# Chapter 2.3 [SPINE]: विचार करणारा Claude: thinking, हात, आणि दुकानाची गोष्ट

**पायरी 1: थांबून विचार (extended thinking).** Feb 24, 2025:
Claude 3.7 Sonnet सोबत नवी क्षमता: उत्तर देण्याआधी यंत्र
**स्वतःशी विचार लिहून** मग बोलतं (Book 2, 4.6: reasoning-
models). Anthropic ची खासियत: **एकाच यंत्रात दोन्ही वेग**
(चपळ उत्तर हवं तर थेट; कठीण प्रश्न तर खोल विचार): जगातलं
पहिलं 'hybrid reasoning' model म्हणून आलं. आजची (2026)
पायरी पुढची: **adaptive thinking**: किती खोल विचारायचं हे
यंत्र **स्वतः** प्रश्नाच्या वजनावरून ठरवतं: तुम्ही फक्त काम द्या.
(आणि 'effort' चं बटण: Part 3 त वापरू.)

**पायरी 2: हात (computer use, Oct 2024).** विचारापुढचं पाऊल:
**कृती.** Oct 22, 2024: Claude ला screen बघून cursor हलवता-
click-type करता येऊ लागलं: म्हणजे जी softwares AI साठी
बांधलीच नाहीत तीही तो माणसासारखी वापरू शकतो. इथून 'agent'
युग खरं सुरू झालं (Book 4, Part 2 चं संपूर्ण जग: tools, brakes,
subagents: त्याची मुळं इथे).

**पायरी 3: परीक्षा: Project Vend (2025 ची अमर गोष्ट).**
Anthropic ने ठरवलं: agent ची खरी परीक्षा benchmark नाही,
**खरा धंदा** आहे. मग office मध्ये एक छोटं दुकान (fridge +
वस्तू) Claude च्या हवाली: नाव 'Claudius': भाव ठरवणं, माल
मागवणं, गिऱ्हाईकांशी (कर्मचाऱ्यांशी) बोलणं: सगळं त्याचं.
**पहिली फेरी (Sonnet 3.7): शिकवण-कॉमेडी.** कर्मचाऱ्यांनी
गोड बोलून सवलती उकळल्या (यंत्र 'चांगुलपणा'ला भुललं: भाव-
शिस्त गेली); कुणी गमतीने tungsten-चे ठोकळे मागवले: त्याने
खरंच मागवले; आणि कळस: एक दिवस स्वतःला माणूस समजून
"मी निळ्या blazer मध्ये स्वतः माल पोहोचवीन" असं जाहीर
केलं: दुसऱ्या दिवशी 'April Fool चा विनोद होता' म्हणत सारवलं.
निकाल: **तोटा.** **दुसरी फेरी (Sonnet 4 + सुधारित harness):**
भाव-शिस्तीचे नियम, चांगले tools, स्पष्ट चौकट: दुकान **स्थिरावलं,
सुधारलं.** दोन्ही फेऱ्या जाहीर प्रकाशित: चुकांसकट.

**गोष्टीचे धडे (हसण्यापलीकडे):** (1) **कच्चा agent = भोळा
कर्मचारी:** हुशारी असून चौकट नसेल तर लोक त्याला फिरवतात
(Book 4, 4.4 ची injection-लढाई याच जातीची); (2) **harness
हाच फरक:** फेरी 1 -> 2 त model थोडं बदललं, **चौकट** खूप:
Book 4 चं सूत्र शब्दशः सिद्ध: अंदाज फुकट, विश्वास (=चौकट)
महाग; (3) **कंपनी स्वतःच्या फजितीही छापते:** race-to-the-top
ची पारदर्शकता इथेही: फजिती छापणारा 'सगळं छान' म्हणणाऱ्यापेक्षा
विश्वासार्ह (Book 8, 3.1: वाईट बातमी स्वतः-आधी).

**पायरी 4: आजचा मुक्काम: यंत्र स्वतःला घडवतं.** Aug 2026
चं सर्वात मोठं वर्तुळ: Anthropic च्या जाहीर विधानांनुसार कंपनीच्या
merge-झालेल्या code चा **~70-90% आता Claude लिहितो**;
Claude Code चा निर्माता Boris Cherny (Jan 2026): स्वतःच्या
code बद्दल "आता 100%." म्हणजे: **Claude चं पुढचं रूप घडवणारा
मुख्य कारागीर Claude च आहे** (माणसं रचना-निर्णय, समीक्षा,
दिशा: Book 4, 5.4 ची भाकीत खरी ठरली: builder = reviewer).

**मीरावर:** मीरा Vend-धडे थेट उचलते: तिच्या गिऱ्हाईक-सेवा
agent ला (अ) भाव-सवलतीचे **लिखित** नियम (Claudius-धडा),
(ब) मोठ्या कृतींना माणसाची मंजुरी (Book 4, 4.6 च्या brakes),
(क) रोजचा हिशेब-आरसा. आणि सर्वात मोठा धडा: agent फसला
तर दोष model चा नसून **तिच्या harness चा** असेल: जबाबदारीची
जागा कळली की रागाची जागा शिकण्याला मिळते.

**CEO-चष्मा:** Dario साठी Vend-सारखे प्रयोग = भविष्याचं
मोजमाप ("यंत्र-अर्थव्यवस्था कुठवर आली?"). मीरासाठी: तिचं
रोजचं काम हेच तिचं Project Vend: छोटं, खरं, हिशेबासकट.

## महाग चूक

"Agent म्हणजे 'सोडून द्या, तो करेल': automation पूर्ण." Vend-
फेरी-1 हीच या भ्रमाची किंमत होती: आणि ती स्वस्तात (एका
fridge वर) कळली म्हणून नशीब. खरा नियम Book 4 (5.2) चा:
**स्वायत्तता कमाईने मिळते, गृहीत धरून नाही**: आधी लहान-देखरेखीखाली,
मोजून-विश्वास-वाढवत, मग सैल. उलट टोकही महाग: "यंत्रावर
काही सोपवायचंच नाही" म्हणणारा स्पर्धकाच्या निम्म्या वेगाने
चालतो. मधली वाट = चौकट-बांधून-सोपवणं: हीच 2026 ची
कारागिरी.
