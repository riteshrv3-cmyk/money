# Chapter 3.3 [SPINE]: विच्छेदन 3: Satya आणि मरगळलेल्या राक्षसाचं वळण

**पार्श्वभूमी (2014).** Microsoft: जुना राजा, नवं जग हुकलेलं.
Windows-साम्राज्याच्या रक्षणात mobile ची लाट पूर्ण हुकली
(वळण-बिंदू ओळखला नाही [2.4]); आतली संस्कृती कुप्रसिद्ध:
विभागा-विभागांत युद्ध. बाजार-किंमत ~$300 अब्ज: मोठी, पण
"जुनी कंपनी, संपत आलेली" हा जगाचा शिक्का. CEO झाला
हैदराबादेत वाढलेला, आतलाच 22 वर्षांचा engineer: Satya Nadella.

**शस्त्रक्रिया 1: चौकट बदलली [1.6 + Grove चा नवा-CEO-प्रश्न].**
जुनी चौकट: "Windows हेच घर; बाकी सगळं त्याचं रक्षण."
Satya ने नव्या-CEO-प्रश्नाचं जिवंत उत्तर दिलं (तो खरोखर नवा
होता, पण आतल्या मोहांसकट!): चौकट बदलून **"mobile-first,
cloud-first"**: Windows चं रक्षण नाही, **प्रत्येक** phone-वर
(Apple च्या सुद्धा!) Microsoft ची सेवा: Office iPad वर आणलं
(जुन्या चौकटीत हे देशद्रोह होतं). आणि Azure (cloud, AWS चा
पाठलाग [3.2 चं मैदान]) हे नवं घर. **Windows मेला नाही; तो
'एकुलता मुलगा' राहिला नाही**: हीच वळणाची व्याख्या.

**शस्त्रक्रिया 2: संस्कृती (खरं हत्यार).** Satya ने पुस्तकभर
सांगितलेली चौकट: Carol Dweck (Stanford च्या मानसशास्त्रज्ञ)
ची **growth mindset**: "know-it-all" (सगळं-माहीत-असणारे)
कंपनीचं रूपांतर **"learn-it-all"** (सगळं-शिकणारे) मध्ये. हे
भाषण नव्हतं, यंत्रणा होती: भरती-बढती-बैठकांचे निकष बदलले;
विभाग-युद्धाची कारणं (आतली स्पर्धा-रचना) मोडली; चुकांवर
शिक्षेऐवजी विच्छेदन (Book 5, 3.6 ची blameless-संस्कृती).
का चालतं हे? कारण [1.1 first principles]: कंपनीचे निर्णय =
हजारो लोकांची रोजची छोटी धाडसं; **भीती असेल तर धाडसं
शून्य** (Nokia चा मृत्यू नेमका इथेच होता: पुढचा chapter):
संस्कृती म्हणजे "मऊपणा" नाही, **निर्णय-यंत्रणेचं इंधन.**

**शस्त्रक्रिया 3: पैजा [1.4].** जुन्या इभ्रतीची पर्वा न करता
असमान पैजा: LinkedIn ($26 अब्ज, 2016), GitHub ($7.5 अब्ज,
2018: developers चं जग), आणि सर्वात गाजलेली: **OpenAI
मध्ये 2019 पासून टप्प्याटप्प्याने अब्जावधी** [why-now 1.5:
reasoning-लाट येण्याआधी!]: AI-लाट आली तेव्हा Microsoft
**आधीच आत** होता. निकाल: Aug 2026 ला बाजार-किंमत
~$3.7-3.8 trillion: दशकात **12 पट.** "संपलेली कंपनी" आज
शिखर-शर्यतीत.

**विच्छेदन-निष्कर्ष (पद्धत-चोरी):** (1) वळण चौकट-बदलाने
सुरू होतं, product ने नाही: आधी "आम्ही कोण" चं उत्तर बदला;
(2) संस्कृती ही यंत्रणा आहे: निकष बदला, भाषणं नकोत; (3)
जुनं राज्य **विकू नका, पण त्याचं रक्षण-कैदी होऊ नका**:
Windows जगला, पण चौकटीबाहेर; (4) मोठ्या लाटेआधी आत
बसणं (OpenAI-पैज) हे नशीब नाही: why-now ची नजर + हार-
परवडणारी रचना.

## नकाशावर

```
विभाग 1  सात हत्यारं   विभाग 2  पाच नजरा
3.1  Jensen/CUDA -> ~$5T   3.2  Bezos/AWS -> $169B/वर्ष
3.3  Satya: चौकट-बदल (cloud-first) + संस्कृती=यंत्रणा
     (learn-it-all) + आधी-आत-बसण्याच्या पैजा (OpenAI) ->
     $300B चे ~$3.7T (दशकात 12x)
```

**सूत्रावर:** Satya चा योग्य प्रश्न "Windows कसा वाचवू?"
नव्हता: **"Windows नसता तर आम्ही कोण असतो?"** होता.
जुने राजे प्रश्न बदलू शकत नाहीत म्हणून मरतात; वळण म्हणजे
नवा प्रश्न.

## स्वतः बघा (5 मिनिटं)

तुमच्या कामातलं तुमचं "Windows" शोधा: जुनं, कमावतं, पण
**तुम्हाला बांधून ठेवणारं** असं काय आहे (एक ग्राहक? एक
पद्धत? एक ओळख: "मी हेच करणारा")? लिहा: "हे नसतं तर
मी कोण असतो, काय करत असतो?" उत्तर अस्वस्थ करणारं
असेल तर तुम्ही Satya-2014 च्या खुर्चीत आहात: आणि आता
हत्यारंही तुमच्याकडे आहेत.
