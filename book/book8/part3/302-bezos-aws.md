# Chapter 3.2 [SPINE]: विच्छेदन 2: AWS चा खरा जन्म (दंतकथा बाजूला)

**आधी दंतकथा मारू.** "Amazon कडे सणासुदीसाठी घेतलेले जादा
servers वर्षभर रिकामे पडायचे, म्हणून भाड्याने द्यायची कल्पना
आली": ही गोष्ट इतकी गोड आहे की जगभर छापली गेली: आणि
ती **खोटी** आहे (खुद्द AWS च्या नेत्यांनी वारंवार नाकारलीये:
cloud-धंद्याला लागणारी यंत्रणा "जादा servers" पेक्षा पूर्ण वेगळी
असते). दंतकथा का धोकादायक? कारण ती धडा उलटा शिकवते:
"नशिबाने पडलेल्या मालाचा जुगाड" विरुद्ध खरा धडा: **स्वतःच्या
दुखण्यातून विकाऊ थर बांधणं.** [इशारा-पानाची आठवण: नेत्यांच्या
गोष्टी तपासूनच घ्यायच्या.]

**खरी गोष्ट.** 2000-03: Amazon आतून वैतागलेलं: प्रत्येक टीमला
नवं काही बांधायचं तर आधी **तेच-तेच पायाभूत काम** (servers,
storage, database-जोडणी): महिने जायचे. उपाय म्हणून आतली
शिस्त बदलली: प्रत्येक टीमने आपली यंत्रणा **इतर टीम वापरू
शकतील अशा स्वच्छ दारांतून** (APIs, Book 5, 2.5) द्यायची.
मग 2003: Andy Jassy च्या टीमचा **6-पानी निबंध** [हत्यार:
1.7: तोच June-2004-संस्कृतीचा काळ!]: "ही आतली यंत्रणा =
जगातल्या **प्रत्येक** developer चं दुखणं आहे: ती बाहेर विकू:
'internet चं operating system' बनू." Bezos चा हिशेब [1.4]:
हार = काही वर्षांचा बांधणी-खर्च (dot-com-नंतरच्या Amazon
ला जड, पण परवडणारा); जिंक = "जगाचं computing आमच्या
मीटरवर" (अमर्याद). आणि गुपित [2.3]: **"दुकानदार-कंपनी
infrastructure विकेल" यावर कुणीही सहमत नव्हतं**: म्हणूनच
2006 (S3/EC2) नंतर **7 वर्षं** मोठ्या स्पर्धकांनी ढुंकून बघितलं
नाही: रिकामं मैदान [1.5 चं लांब-क्षितिज], खंदक खोदायला
पुरेपूर वेळ.

**खंदक कुठले बांधले [2.1]:** switching-cost (तुमचा data +
तुमच्या टीमची AWS-विद्या: निघणं = घर हलवणं); मापाची बचत
(जगाचे servers घाऊक = प्रत्येक नग स्वस्त: आणि AWS दर
कपात **स्वतःहून** करत गेली: खंदक रुंदावणं); जाळं-छाया
(प्रत्येक नवं tool आधी AWS वर निघतं). निकाल: Aug 2026
ला AWS चा वेग ~$169 अब्ज/वर्ष: Amazon च्या नफ्याचा कणा
**दुकान नाही, हा थर आहे.**

**विच्छेदन-निष्कर्ष (पद्धत-चोरी):** (1) **सोन्याची खाण = स्वतःचं
दुखणं जे सगळ्यांचं दुखणं आहे**: तुम्ही आतून जे कष्टाने बांधलंत
ते दुसऱ्यालाही लागतं का, हा प्रश्न रोज विचारण्याजोगा; (2)
निर्णय खोलीत आवाजाने नाही, **निबंधाने** झाला: 6-पानं ->
भेगा-तपास -> पैज: यंत्रणा-निर्णय, मूड-निर्णय नाही; (3) "आमचा
धंदा हा नाही" हे वाक्य Bezos ने ऐकलं असतं तर AWS नसतं:
चौकट [1.6] "आम्ही काय विकतो" वर नाही, **"आमची विद्या
काय"** वर बांधली.

**सूत्रावर:** AWS चा योग्य प्रश्न "आम्ही आणखी काय विकू?"
नव्हता; **"आम्ही न विकता काय बांधून बसलोय?"** होता. असमान
पैजा बाहेर शोधायच्या नसतात इतक्या **आतल्या कपाटात**
सापडतात.
