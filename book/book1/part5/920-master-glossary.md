# MASTER GLOSSARY: पाचही parts, एका जागी

(शब्द -> एक ओळ -> chapter. Part-निहाय याद्या त्या-त्या part च्या
शेवटी आहेत; ही एकत्रित, वारंवार लागणाऱ्यांची.)

```
abstraction       आतली गुंतागुंत झाकून सोपं handle देणं (0.4)
API               programs चं ठरलेलं प्रश्नोत्तर-menu (7.4)
backend           kitchen: नियम, हिशोब, खरी तपासणी (7.3)
backup / restore  काळ-प्रत / परत आणणं (न तपासलेली = नाहीच) (6.7)
bit / byte        switch ची स्थिती / 8 bits = ~1 अक्षर (1.4)
bottleneck        साखळीतला अरुंद दुवा (7.6)
bug / edge case   लिहिलं-हवं ची फट / कोपऱ्यातली परिस्थिती (4.1)
cache             महाग उत्तर जवळ; किंमत: शिळेपणा (6.6)
CDN               जगभर प्रती: अंतर मारणं (7.7)
client / server   मागणारी / देणारी machine (5.1)
cloud             भाड्याच्या machines; लवचीकपणा हेच मोल (7.5)
compiler/interpreter  भाषांतर आधी / सोबत-सोबत (3.3)
CPU               recipe चालवणारा; fetch-decode-execute (1.3, 2.4)
database          data चा दरबान-server (6.1)
DNS / domain      नाव->number शिडी / website चं नाव (5.5)
deploy / DevOps   code खऱ्या जगात नेणं / त्याची व्यवस्था (4.4)
egress            बाहेर जाणाऱ्या data ची जकात (7.8)
encryption        गणिती लिफाफा; public + private किल्ली (5.6)
environment       code भोवतीचा माहोल (4.4)
failover          प्रत आपोआप पुढे येणं (7.2)
frontend          दिसणारा भाग; विश्वास ठेवायचा नाही (7.3)
Git / commit      बदलांची रोजकीर्द / एक नोंद-photo (4.3)
HTTP / HTTPS      web चे नियम / सुरक्षित रूप (5.4, 5.6)
index / query     लावलेली यादी / विचारलेला प्रश्न (6.2)
IP address        machine चा number-पत्ता (5.2)
latency           फेऱ्याचा वेळ; bandwidth पेक्षा वेगळा (2.3, 5.3)
leverage          काम एकदा, फायदा पुन्हा-पुन्हा (0.2)
```

```
load balancer     दारावरचा वाटप करणारा (7.1)
lock / race       कुंडी / नशिबावरची शर्यत (6.4)
loop / variable   पुन्हा-करा / नावाचा खण (3.2)
MVP               पहिलं छोटं चालतं रूप (4.5)
network effect    नवा user जुन्यांची किंमत वाढवतो (8.5)
nines / SLA       उपलब्धतेची मोजपट्टी / लिखित वचन (7.2)
n-squared         जोड्या वर्गाने वाढतात; protocol ने मरतो (5.1)
open source       खुला code; सामायिक हत्यार (3.7)
OS / platform     machine चा मालक / दरवाजा + जकात (3.5)
packet / TCP/UDP  message चा तुकडा / बरोबरपणा vs वेग (5.3)
pixel / sample    photo चा ठिपका / आवाजाचा क्षण (2.2)
process / state   जिवंत copy / तिची आत्ताची अवस्था (3.6)
program / code    machine साठी लिहिलेली recipe (1.3, 3.2)
protocol/standard आधीच ठरलेले नियम / सर्वमान्य रूप (5.4, 5.8)
queue / async     कामांची रांग / नोंदवा-आत्ता, करा-नंतर (6.5)
RAM / storage     मेज (विसराळू) / गोदाम (पक्कं) (2.5)
rate limit        दार आवळणं (7.6)
replication       जिवंत प्रत; चूकही copy करते (6.7)
rollback          अर्धा गठ्ठा उलटा फिरवणं (6.4)
scarcity          किती कमी लोकांना जमतं (0.2)
spec              सात-प्रश्नी नेमकी मागणी (8.3)
SQL / table       tables ची भाषा / खण-आकार (6.3)
stack             थरांचा मनोरा: कोण कोणावर (0.3, 3.4)
stateless         server रिकामा; state सामायिक जागी (7.1)
transaction       सगळं-किंवा-काहीच-नाही गठ्ठा (6.4)
transistor        विजेने दाबला जाणारा switch (1.1)
unit economics    user-मागचा खर्च vs कमाई (7.8)
universal machine कुठलीही recipe चालवणारी एकच machine (1.6)
version control   बदलांच्या इतिहासाची व्यवस्था (4.3)
```
