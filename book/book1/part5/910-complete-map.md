**पैशाचं जग + machine (Parts 1-2):**

```
LEVEL 4 AI / 3 TECH / 2 BUSINESS / 1 गरज: पैसा फक्त
  Level 1 वर घुसतो, वर चढतो (0.1, 0.3)
कमाई = size x scarcity x leverage; तास नाहीत (0.2)
लपलेला थर = महाग थर (abstraction, 0.4)
transistor -> gates -> CPU: numbers वर आधीच लिहिलेली
  recipe, billion पावलं/second (1.1-1.5)
recipe = numbers => एक machine, सगळी कामं (1.6)
1 byte = अक्षर; text:photo:video = 1:हजार:लाख (2.1, 2.2)
RAM = मेज (विसराळू) / storage = गोदाम (पक्कं) (2.5)
भाषांतर-शिडी: machine code -> languages -> AI (3.1-3.4)
OS = मालक: पाळ्या, भिंती, दरबान; platform-जकात (3.5)
फुकट: दरवाजा/freemium/तुम्ही-माल/open source (3.7)
bugs = जोड्यांचा स्फोट (4.1); tests = तपासणीचा code (4.2)
Git = रोजकीर्द (4.3); software = code + माहोल (4.4)
estimate चुकणारच: छोटे चालते तुकडे, MVP (4.5)
```

