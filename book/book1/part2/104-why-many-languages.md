# Chapter 3.4 [SPINE]: इतक्या साऱ्या languages का आहेत

Python, Java, C, JavaScript, Swift, Kotlin, Go, Rust... शंभरपेक्षा
जास्त आहेत. नव्या माणसाला वाटतं हा वेडेपणा आहे, किंवा fashion.
नाही. कारण तेच आहे जे गाड्यांचं आहे.

Truck, bike, car, tractor: सगळे "जाण्याचं साधन" आहेत, तरी चार का?
कारण प्रत्येक design एक **सौदा** आहे: truck सामान जास्त, वेग कमी;
bike स्वस्त, पावसात भिजाल. एक साधन सगळं best करू शकत नाही, कारण
खुब्या एकमेकींशी भांडतात.

Languages चे सौदेही मोजके आहेत, चार मुख्य:

**वेग vs आराम.** Machine च्या जवळ लिहा (C) तर वेगवान पण प्रत्येक
गोष्ट स्वतः सांभाळा; दूर लिहा (Python) तर आराम पण हळू. (मागच्या
chapter चा सौदा.)

**स्वातंत्र्य vs सुरक्षा.** काही भाषा तुम्हाला काहीही करू देतात
(C: memory पर्यंत थेट हात); ताकद मिळते, पण चुकीचं दारही उघडं.
काही बंधनं घालतात (Rust, Java); चुकांची पूर्ण जातच संपते.

**सर्व कामं vs खास काम.** काही प्रत्येक कामासाठी (Python, Java).
काही एकाच कामासाठी बनल्या, पण त्या कामात राणी: SQL फक्त data ला
प्रश्न विचारण्यासाठी (Part 4 मध्ये भेटेल), HTML फक्त page चं रूप
सांगण्यासाठी.

**जागेचा कब्जा.** काही भाषा यासाठी चालतात कारण त्यांचा एका जागेवर
कब्जा आहे: browser च्या आत फक्त JavaScript चालते, iPhone app
साठी Apple ने Swift ठेवली आहे, Android साठी Kotlin. तिथे काम
करायचं तर तीच भाषा.

बस. प्रत्येक language या चार सौद्यांची एक जोडणी आहे. "सगळ्यात
चांगली language कुठली" हा प्रश्न "सगळ्यात चांगली गाडी कुठली"
सारखाच आहे: काम सांगितल्याशिवाय उत्तर नाहीच.

एका project मध्ये वापरलेल्या सगळ्या भाषा आणि tools च्या जोडणीला
**tech stack** म्हणतात (Chapter 0.3 वाला शब्द परत, आता छोट्या
आकारात). Zomato च्या आत एकाच वेळेस किमान पाच भाषा जिवंत आहेत:
app Kotlin/Swift मध्ये (phones चा कब्जा), मागचे servers Java/Go
मध्ये (वेग + भरवसा), data चे प्रश्न SQL मध्ये, AI चं काम Python
मध्ये, website JavaScript मध्ये. वेडेपणा नाही: प्रत्येक जागी तीच
भाषा जी त्या जागेचा सौदा जिंकते. मंडईसारखं आहे: भाजीवाला हातगाडी
वापरतो, घाऊक व्यापारी tempo, आणि बाहेरचा माल train ने येतो; कोणी
"एकच साधन" वापरत नाही.

## इथे लोक काय चुकीचं समजतात

लोक language ला धर्म बनवतात ("मी Python वाला"). Engineers चे हे
वाद खरे असतात, पण तुम्ही founder च्या नजरेने बघा: language ही एक
**hiring** decision आहे. Python/JavaScript वाल्यांची गर्दी मोठी
(स्वस्त, लवकर मिळतो), Rust वाल्यांची छोटी (महाग, शोधावा लागेल).
नव्या startup चा अर्धा निर्णय इथेच होतो, technology च्या आधी.

## MAP वर

Scarcity चा उलटा खेळ बघा: COBOL 1959 ची भाषा आहे, कोणी शिकत नाही.
पण जगातल्या banks चे जुने core systems तिच्यावरच उभे आहेत, आणि ते
बदलणं इतकं धोक्याचं आहे की कोणी बदलत नाही. निकाल: उरलेल्या
म्हाताऱ्या COBOL वाल्यांना banks जाड fees देतात. धडा: पैसा नव्यात
पण आहे, आणि त्या जुन्यातही ज्याला सगळे सोडून गेले पण जग अजून
ज्याच्यावर उभं आहे. Scarcity दोन्ही टोकांना बनते.
