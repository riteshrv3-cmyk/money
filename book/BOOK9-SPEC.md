## सूत्र (book law)
"AI-युगातली सर्वात महाग वस्तू विश्वास आहे. Anthropic ची पैज:
सुरक्षितता हा खर्च नाही, खंदक आहे: आणि जो यंत्राला सर्वात खोल
समजतो तोच त्याच्यावर सर्वात मोठं बांधतो."
(Book 4 च्या "अंदाज फुकट, विश्वास महाग" चं कंपनी-रूप; Book 8
च्या खंदक-नजरेशी जोड.)

## Running example
"मीराचं एक-माणसी software-घर": solo builder (Ritesh-mirror),
Claude Code वर धंदा बांधतेय. प्रत्येक chapter मध्ये तिचा एक खरा
निर्णय (कुठल्या कंपनीवर पैज? कुठलं model? किती खर्च? काय धोका?)
: कंपनी-गोष्ट आणि वाचकाचा वापर एका दोरीने.
+ device: "CEO-चष्मा" - प्रत्येक chapter शेवटी एक ओळ: हीच गोष्ट
Dario च्या खुर्चीतून कशी दिसते vs मीराच्या खुर्चीतून.

## Curriculum (3 विभाग, 20 ch)

### विभाग 1: कंपनी आणि पैज (7 ch)
1.1 [SPINE] फूट आणि जन्म: OpenAI सोडून का निघाले; भावंडं-जोडी
    (Dario+Daniela); 2021.
1.2 [SPINE] Dario चं जग-चित्र: scaling hypothesis; "Machines of
    Loving Grace"; compressed 21st century.
1.3 [SPINE] सुरक्षितता हीच रणनीती: constitutional AI धोरण म्हणून;
    RSP/ASL पायऱ्या; "race to the top" ची चाल.
1.4 [SPINE] पैशाचं गणित: funding timeline (Google/Amazon/rounds),
    valuation, run-rate उड्या, compute-खर्चाचं अजगर-गणित.
1.5 [SPINE] धंद्याचं रूप: API-first vs consumer; enterprise;
    coding = सर्वात मोठा वापर; Claude Code चा धंदा.
1.6 [SPINE] स्पर्धेचा नकाशा Aug 2026: vs OpenAI (consumer-राजा),
    Google (सगळं-एकात), Meta (विकत-विद्या), open-source; enterprise
    API share; Book 8 च्या नजरा लावून.
1.7 [DEPTH] भारत आणि Claude: India वापर, office, संधीची जागा.
900 part-end: recap + परीक्षा + चाहूल + शब्दकोश.

### विभाग 2: यंत्र आणि उत्पादनं (7 ch)

    AI/RLAIF; constitution म्हणजे काय; character-घडण. (Book 2/4
    recap + Claude-specific खोली.)
2.2 [SPINE] घराणं: Fable 5/Mythos 5 (एकच यंत्र, दोन दारं), Opus,
    Sonnet, Haiku: कुठलं-कशाला; किंमत-पट्टी (छापण्याजोगी).
2.3 [SPINE] विचार करणारा Claude: extended thinking, agents,
    computer use; Project Vend सारख्या खऱ्या गोष्टी.
2.4 [SPINE] उत्पादन-नकाशा: claude.ai (Free/Pro/Max), Claude Code
    (CLI/desktop/web), API/console, mobile, Chrome, Skills,
    artifacts, memory: कुठलं दार कुणासाठी.
2.5 [SPINE] MCP ची गोष्ट: प्रश्न-नळ्यांचा standard; open-source
    चाल; स्पर्धकांनीही स्वीकारला (Book 8 platform-नजरेचं जिवंत
    उदाहरण).
2.6 [SPINE] काय जमतं, काय नाही: benchmarks-थोडक्यात, coding-राजा,

2.7 [DEPTH] सुरक्षा-कवचं: classifiers, injection-लढाई, ASL-3

### विभाग 3: मालक-वापर (6 ch)
