# दोन पट्ट्या + MASTER GLOSSARY (भिंतीवर लावा)

## पट्टी 1: Latency (यंत्रातले वेग: जवळ vs दूर)

```
जागा                वेळ (ढोबळ)     "1ns = 1 सेकंद" तर
CPU रजिस्टर         ~शून्य          आत्ता, हातात
L1 cache            ~1 ns          1 सेकंद
L2/L3 cache         ~4-40 ns       काही सेकंद
RAM                 ~100 ns        ~2 मिनिटं
SSD वाचन            ~16-100 us     ~दिवस-दोन
जुनी HDD            ~2-10 ms       ~महिने
एकाच DC जाळं        ~0.5 ms        ~आठवडे
भारत->अमेरिका जाळं   ~180-250 ms    ~वर्षं!

धडा: जवळ ठेवा (cache); दूर (disk/खंडापार) टाळा.
```

## पट्टी 2: Big-O (वाढीचा दर: आकार दुप्पट -> काम किती-पट)

```
O(1)        स्थिर: आकार कितीही, वेळ तोच. (hash, array-index)
O(log n)    लॉग: आकार दुप्पट, वेळ +1 पाऊल. (binary search, tree)
O(n)        रेषीय: आकार दुप्पट, वेळ दुप्पट. (यादी चाळणं)
O(n log n)  आकार दुप्पट, थोडं जास्त. (हुशार sorting)
O(n²)       चौरस: आकार दुप्पट, वेळ चौपट. (धोका! प्रत्येक x प्रत्येक)
O(2^n)      स्फोटक: मृत्यू. (भोळं recursion; DP ने टाळा)

धडा: लहान-data फसवं; "10x, 100x वाढलं तर?" आधी विचारा.
```

## MASTER GLOSSARY: Book 6 चे सगळे शब्द

```
array/linked     शेजारी-खोल्या (थेट-बोट) vs पत्ता-साखळी (मध्ये-घुसवणं)
Big-O            वाढीचा दर; महागडं ओळखणं (1.1)
binary search    क्रमबद्ध यादीत अर्धं-अर्धं O(log n) (1.6)
cache            CPU जवळची जलद memory (2.2)
CPU              transistor-स्विचांचा मेंदू; आकड्यांची वाट बघतो (2.1)
deadlock         परस्पर-कोंडी; अरुंद पुलावर दोन ट्रक (3.1)
distributed      अनेक यंत्रं; महाग संवाद + नवे अपयश (3.3)
DP               recursion + आठवण; जागा विकत वेळ घेत (1.7)
GIL              एका वेळी एकच Python-thread (2.6)
GPU              हजारो साधे-एकसुरी हात; AI-parallel साठी (3.2)
graph            टिंबं + जोडण्या (जाळं); BFS/DFS (1.5)
hash table       नाव -> थेट जागा O(1); क्रमहीन (1.3)
latency          कृतीचा वेळ; जवळ<->दूर हजारो पट (2.2)
lock             सामायिक गोष्टीवर "एका वेळी एकच" (3.1)
OS               hardware-app मधला मुकादम (scheduler+virt mem) (2.4)
parallel/concurrent खरं-एकत्र vs आळीपाळी-हाताळणं (3.2)
process/thread   स्वतंत्र-घर vs घरातले-हात (2.3)
race condition   सामायिक गोष्टीवर टक्कर; वाढ हरवते (3.1)
recursion        स्वतःला बोलावणं; base case ने थांबा (1.7)
tree             वंशावळ; O(log n), क्रमबद्ध, संतुलित हवं (1.4)
virtual memory   प्रत्येक app ला "पूर्ण memory" चा भ्रम (2.4)
```
