# Chapter 3.5 [SPINE]: AI-युगात CS-पाया का उरतो

चंदूचा समारोप-प्रश्न: agents code लिहितात, मग CS-पाया शिळा
झाला का? उत्तर पूर्ण मालिकेचा कळस आहे, आणि तो Book 4-5-7
शी जोडतो: **AI-युगात हा पाया अधिक मौल्यवान होतो, कमी नाही.**

**काय बदललं, काय नाही (Book 5, 4.5 चा तोच धडा).** बदललं:
code **टाइप करणं** (agents करतात, जलद). नाही बदललं: (1)
**"हे हळू का, कुठला संशयित"** ओळखणारी नजर (3.4); (2) "कुठली
रचना योग्य" (hash की tree, Part 1); (3) "हे 10x वाढलं तर
कोसळेल का" (Big-O, 1.8); (4) agent ने बांधलेलं **कार्यक्षम
आहे का** हे तपासणं. Agent code देतं; पण ते **चांगलं** आहे
का (O(n²) लपलंय का? चुकीची रचना? memory-सापळा?) हे
ठरवणारी नजर तुमची. Code = कच्चा माल (स्वस्त); **कार्यक्षमतेची
नजर = मूल्य** (Book 4, 9.2 चा खंदक).

**आणि एक नवा, तीक्ष्ण मुद्दा: agent चुकीचं-कार्यक्षम code सहज
देतं.** Agent बहुधा "चालणारं" code देतो, पण ते **सर्वात कार्यक्षम**
असेलच असं नाही: तो एखादा O(n²) किंवा N+1 सापळा (1.8) सहज
लिहू शकतो, कारण छोट्या-test ला चालतं. जो CS-पाया **नसलेला**
माणूस ते स्वीकारतो (आणि production-गर्दीत कोसळतो); जो पाया-
**असलेला** माणूस agent ला "हे O(n²) आहे, hash वापर" म्हणून
दुरुस्त करवतो. **म्हणजे AI-युगात CS-पाया ही "code लिहायची"
कला नाही, "code तपासायची आणि दिशा द्यायची" कला आहे: आणि
तीच आता दुर्मिळ, म्हणून मौल्यवान.** नवखा agent-वापरकर्ता
आंधळा; पाया-असलेला दृष्टिवान.

**GPU-युगाशी थेट जोड (Book 6 चा शेवटचा पूल).** आणि हा
पाया AI **समजायलाही** लागतो: GPU का (3.2: parallel-एकसारखं-
गणित), memory-bound का (2.2: latency-पट्टी), training महाग
का (अब्जावधी parallel गुणाकार): हे सगळं Book 6 च्या तळातून
येतं. जो हा तळ जाणतो तो AI-bill वाचतो, AI-वेग सुधारतो, AI-
papers समजतो (Book 7). **CS-पाया आणि AI विरुद्ध नाहीत;
CS-पाया हा AI समजण्याचा-वापरण्याचा तळ आहे.**

**पूर्ण मालिकेचा समारोप (सहा पुस्तकं, एक नजर).** आता चित्र
पूर्ण: Book 1 (machine), 2 (AI यंत्र), 4 (harness: AI वर धंदा),
5 (मोठं software), 7 (AI चं गणित), 6 (यंत्राचा तळ). सहा वेगळे
चष्मे, पण एक समान धडा: **कुठेही जादू नाही; सगळीकडे सौदे,
रचना, आणि मोजता-येणारी तत्त्वं.** आणि AI-युगात, जेव्हा बांधणं
स्वस्त होतं, तेव्हा उरतं फक्त एक: **कुठला सौदा योग्य, कुठली
रचना कार्यक्षम, कशावर किती विश्वास: हे ठरवणारी नजर.** ती
नजर या सहा पुस्तकांनी दिली. आणि ती नजर कुणी agent विकत
घेऊ शकत नाही: ती तुम्ही **साचवली.** तेच तुमचं न-नकलता-येणारं
भांडवल.

## इथे लोक काय चुकीचं समजतात

"AI code लिहितं, आता CS शिकायची गरज नाही." सर्वात महाग
गैरसमज, आणि तो तुम्हाला आंधळा-agent-वापरकर्ता बनवतो: agent
जे देईल ते (कदाचित O(n²), कदाचित असुरक्षित) स्वीकारणारा,
production मध्ये कोसळणारा. उलट: जितकं बांधणं स्वस्त, तितकी
"हे कार्यक्षम/बरोबर आहे का" ची नजर मौल्यवान. CS-पाया आता
"लिहायची" नाही "तपासायची-दिशा-द्यायची" कला: आणि तीच दुर्मिळ.
Agent हा हात; नजर steering: steering शिवाय हात चुकीच्या
जागी वेगात नेतो.

ती नजर सहा पुस्तकांनी साचवली: तेच तुमचं भांडवल.

## स्वतः बघा (5 मिनिटं)

AI ला एक साधं काम द्या: "10 लाख नावांत शोध करणारं code
लिही." उत्तर बघा आणि Part 1 ची नजर लावा: त्याने hash/tree
(O(1)/O(log n)) वापरलं की भोळं चाळणं (O(n))? विचारा "हे
10 कोटींना चालेल का?" बघा उत्तर कसं बदलतं. तुम्ही agent ला
**तपासताय आणि दिशा देताय**: हीच AI-युगातली तुमची भूमिका,
आणि तिला CS-पाया लागतो.
