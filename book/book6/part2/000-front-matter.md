# THE ENGINE ROOM

## Book 6, Part 2: यंत्राचा तळ

**मागच्या भागाचा शेवट:** चंदूचं algorithm बरोबर झालं, तरी
app कधी हळू. संशयित आता यंत्राच्या **तळात**: memory, CPU,
disk, OS. हा भाग यंत्र **प्रत्यक्ष कसं चालतं** ते दाखवतो: का
काही गोष्टी 1000 पट हळू, CPU एका वेळी किती करतो, आणि
तुमचं Python code चालतं म्हणजे नक्की काय होतं. तपास हार्डवेअरच्या
खोलीत.

## सूत्र (पुन्हा)

```
प्रत्येक हुशारी ही वेळ आणि जागा (memory) यांची अदलाबदल आहे.
फुकट वेग नसतो. आणि: यंत्राचा तळ जितका जवळ, तितका जलद;
जितका दूर, तितका हळू (हजार पट).
```

## Part 1 ची उजळणी: 3 प्रश्न (बोलून; उत्तरं खाली)

**1.** App test मध्ये जलद, कार्यक्षम का?

> नाही: लहान data फसवं; Big-O बघा ("10x वाढलं तर?"). (1.1)

**2.** "नाव -> थेट माहिती" कुठली रचना, मर्यादा?

> hash table O(1); पण क्रम नाही, collision-जोखीम. (1.3)

**3.** DP चा सौदा?

> जागा (आठवण) विकत, वेळ (पुनरावृत्ती टाळून) घेत. (1.7)

## या भागात काय

Transistor ते CPU (Book 1 खोल), memory ची उतरंड +
latency-पट्टी (छापण्याजोगी), process/thread, OS एका CPU वर
हजार कामं, virtual memory, आणि Python चालतो म्हणजे काय +
GIL 2026. तपास तळात.
