# भाग 3: सहा धंद्यांचे playbooks

Playbook = त्या धंद्याचं अर्धं audit आधीच केलेलं: चक्र
कसं फिरतं, दुखणी बहुधा कुठली, काय विकलं जातं, भाव
कुठल्या पट्ट्यात, दारात पहिलं वाक्य काय.

```
3.1  दुकान / किराणा / distributor
3.2  clinic / hospital / lab
3.3  coaching / class / college
3.4  hotel / restaurant / cloud-kitchen
3.5  कारखाना / workshop / बांधकाम
3.6  सेवा-धंदे (CA, वकील, salon, agency) + नव्या
     धंद्याचं playbook स्वतः बनवायची पद्धत
```

वापरायची पद्धत: दारावर जायच्या आदल्या रात्री तो एक
playbook 10 मिनिटं परत वाचा (Book 12: spacing!),
पहिलं वाक्य तोंडी म्हणून बघा, आणि audit-पत्रकावर
त्या धंद्याची अपेक्षित दुखणी पेन्सिलने आधीच खुणा करा:
**पेन्सिलने: कारण खरं दुखणं मालकाच्या तोंडूनच यायचंय**
(2.1 चा नियम). playbook हा नकाशा आहे; प्रदेश तो
माणूसच.

एक इशारा: सहाही playbooks मध्ये तुम्हाला **तीच 5
recipes** परत परत दिसतील (उत्तर-bot, वसुली, आठवण,
quotation, review). हे कंटाळवाणं नाही; हेच सोनं आहे:
**एकच शस्त्रागार, साठ दारं.**


# Chapter 3.1 [SPINE]: Playbook: दुकान / किराणा / distributor

## आधी अंदाज लिहा

```
1. दुकानाचं सर्वात मोठं दुखणं भाग 1-2 वरून आठवतंय?
   ______________________________________________
2. दुकानदाराला भेटायची योग्य वेळ? ________________
```

## धंद्याचा नकाशा

```
चक्र: वस्ती-ओळख -> counter/फोन/WhatsApp वरून order
   -> माल देणं/पोचवणं -> निम्मं रोख, निम्मं उधार ->
   नातं टिकतं (पण online-स्वस्ताई कुरतडते)
margin: पातळ (किराणा 2-6%; कपडे-भांडी जरा जास्त)
   -> म्हणून रोकड आणि वसुली जीवघेणी (1.2)
मालकाची घडी: सकाळ-संध्याकाळ गर्दी; दुपार 2-5 शांत
   (भेटीची वेळ!); रविवार निम्मा
आधीच हाती: WhatsApp (पक्कं), UPI (पक्कं), उधारी-वही
   (कागदी), कधी billing-machine
```

## Top-3 दुखणी (अपेक्षित: पेन्सिल-खुणा)

```
1. थकलेली उधारी: वस्ती-दुकानात गल्ल्याच्या 10-20%
   रक्कम कायम बाहेर; distributor कडे लाखांत (शिंदे-
   case: ₹1.75L). मागायचा संकोच = दुखण्याचं खरं रूप.
2. गर्दीत सुटलेले फोन/संदेश: गर्दीच्याच वेळी order-फोन
   येतात (सगळ्यांची तीच वेळ!): सुटला की order शेजारच्या
   दुकानात.
3. "संपलंय": माल-अंदाज वहीत नाही, डोक्यात: विक्री जाते
   किंवा माल पडून मरतो.
```

## विकण्याजोगी solutions (recipe-क्रमांकासकट)

```
अ. वसुली-यंत्र (R2): पहिली निवड: टोचणारं + मोजता
   येणारं + हिरवं. भाव: setup ₹8-15K, retainer ₹3-5K.
ब. उत्तर+order-bot (R1): "आहे का/भाव/order घ्या":
   चोवीस तास. भाव: setup ₹10-25K, retainer ₹2-4K.
   (दुकानाच्या आकाराप्रमाणे; distributor ला मोठा.)
क. परत-बोलावणं (R5-चं रूप): 30 दिवसांत न आलेल्या
   गिऱ्हाईकांना आठवण/offer. भाव: retainer मध्ये जोड
   ₹1-2K. (आधी अ/ब चालू झाल्यावरची वाढ-पायरी.)
जोड-विक्री (नंतरची): "संपत-आलं" ची यादी (billing-
   data असेल तरच: 2.2 ची चाळणी आठवा!)
```

## दारातलं पहिलं वाक्य

> "काका, मी [नाव], इथेच [खूण] जवळ असतो. दुकानांची
> रोजची डोकेदुखी: उधारीच्या आठवणी, सुटलेले फोन: अशी
> कामं आपोआप करून देतो. विकायला नाही आलो: दोनच
> मिनिटं: तुमच्याकडे उधारीचं कसं असतं?"

(थेट P-प्रश्नात उतरणारं. "आपोआप" आहे, "AI" नाही.)

## धोक्याच्या जागा

```
1. "पोरगं आहे की मग": घरचा-फुकट-मजूर आक्षेप (1.5)
   इथे सर्वात जास्त. उत्तर: "पोरगं delivery ला हवं की
   वहीत डोकं घालायला? यंत्र वही बघेल, पोरगं गल्ली."
2. billing-data नसणं: अंदाज-solutions विकू नका (चाळणी
   प्र.2): आधी नोंदी-recipe, अंदाज पुढच्या वर्षी.
3. हंगाम: दिवाळी-लग्नसराईत मालक बोलायलाही मोकळा
   नसतो: विक्री-भेटी हंगामाआधी/नंतर.
```

## इथे लोक चुकतात

**"छोट्या दुकानाला छोटं समजणं."** एक वस्ती-दुकान ₹3-5K
देईल; पण त्याच्या मागे उभा distributor (शिंदे) ₹15-20K
देतो, आणि त्याच्या वर stockist. **दुकानातून वर चढा:**
दुकानदाराला विचारलेला एक प्रश्न: "तुमचा माल कुठून येतो?"
= पुढच्या, मोठ्या गिऱ्हाईकाचा पत्ता. साखळीच्या प्रत्येक
पायरीवर तीच दुखणी, मोठ्या आकड्यांत.

## नकाशा

```
3.1  दुकान: उधारी-फोन-माल ही त्रिमूर्ती; R2 पहिली, R1
     दुसरी; पगार-पट्टीत भाव; "पोरगं" आक्षेपाचं उत्तर;
     दुकान -> distributor -> stockist अशी चढण
```

**सूत्राशी:** याच धंद्यावर आपण पूर्ण साखळी शिकलो (शिंदे):
playbook म्हणजे तीच साखळी घडी करून खिशात.

## स्वतः करून बघा (field-काम 15)

तुमच्या 10-दारांच्या यादीतल्या (1.5) दुकानांसमोर या
playbook चे अपेक्षित-दुखणं + recipe + भाव पेन्सिलने भरा.
एका दुकानात हे पहिलं वाक्य **आज वापरून बघा.**

## आठवा

```
अ) दुकानाची top-3 दुखणी आणि पहिली recipe?
ब) "पोरगं आहे की" चं उत्तर?
क) (मागचं) 2.6: retainer इंजिन का आहे?
```

पुढचं दार: पांढरा कोट. clinic चं जग: जिथे margin जाड
आहे आणि रिकामी खुर्ची हीच सर्वात महाग गोष्ट आहे.


# Chapter 3.2 [SPINE]: Playbook: clinic / hospital / lab

## आधी अंदाज लिहा

```
1. clinic ची रिकामी 20-मिनिटांची वेळ "महाग" का असते?
   ______________________________________________
2. डॉक्टरशी बोलायला कोण भेटेल: डॉक्टर की आणखी कोण?

```

## धंद्याचा नकाशा

```
चक्र: ओळख/Google/जुने रुग्ण -> फोन/walk-in वेळ ठरते
   -> तपासणी/उपचार -> रोख/UPI (वसुली सोपी; packages
   अडकतात) -> follow-up-भेटी, वार्षिक तपासण्या (टिकवणं:
   जवळजवळ कुणीच करत नाही)
margin: जाड: मुख्य खर्च डॉक्टरचा वेळ + भाडं. म्हणून:
   रिकामी वेळ = जवळजवळ पूर्ण नफा गमावला (1.2 ची
   शिडी): no-show हे इथलं राज-दुखणं.
खरा दरवाजा: receptionist/मालक-डॉक्टरची जोडीदार व्यक्ती.
   फोन तीच उचलते, वेळा तीच सांभाळते: तिचा त्रास
   कमी करणारं यंत्र = तिची शिफारस = डॉक्टरचा होकार.
   (तिला वगळून थेट डॉक्टरकडे = यंत्राची शत्रू घरातच.)
भेटीची वेळ: दुपारी OPD-नंतरची घडी (2-4) किंवा
   ठरवून-संध्याकाळ.
```

## Top-3 दुखणी

```
1. No-show: भारतीय OPD त ठरलेल्या 5 पैकी 1 रुग्ण
   येत नाही [थोडं: 18-30% चे अंदाज; खरा आकडा
   त्यांच्याच वहीतून काढा: I-प्रश्न!]. 20 no-show x
   ₹500-800 = ₹10-16K/महिना: जाड-margin मुळे
   जवळजवळ सगळा नफा.
2. फोनचा भडिमार: "वेळ मिळेल का/report आले का/
   रस्ता कुठून" चे तेच-तेच फोन: receptionist चा अर्धा
   दिवस + engaged-फोनमुळे नवे रुग्ण दुसरीकडे.
3. सुटलेला follow-up: "15 दिवसांनी परत या" म्हटलेले
   अर्धे येत नाहीत: रुग्णाचं नुकसान + क्लिनिकचं उत्पन्न-
   गळती + अपूर्ण उपचाराची जोखीम.
```

## विकण्याजोगी solutions

```
अ. आठवण-यंत्र (R3): पहिली निवड: आदल्या दिवशी +
   सकाळी मराठी आठवण, "येणार/बदला" बटणं; बदल
   यादीत आपोआप. आठवण-संदेशांनी no-show लक्षणीय
   घटतात हे संशोधनात जुनं-सिद्ध [पक्कं]. भाव: setup
   ₹10-20K, retainer ₹3-6K.
ब. उत्तर-bot (R1): वेळा/पत्ता/fees/तयारी ("उपाशी या")
   ची उत्तरं + "report तयार आहेत" ची आपोआप खबर
   (lab साठी सोन्याचं). भाव: setup ₹10-25K, retainer
   ₹2-5K.
क. follow-up-यंत्र (R2-चं वैद्यकीय रूप): "15-दिवसांनी"
   वाल्यांची यादी + आपोआप आठवण. retainer-जोड ₹1-2K.
मर्यादा-रेषा (1.6 ची लाल!): यंत्र वैद्यकीय सल्ला देणार
   नाही: लक्षणं/औषधांचे प्रश्न -> "डॉक्टरांनाच विचारा" +
   receptionist ला नोंद. हे करारात (कलम 2) लिहायचंच:
   इथे over-promise धोकादायक नाही, बेकायदेशीर आहे.
```

## दारातलं पहिलं वाक्य (receptionist ला)

> "नमस्कार, मी [नाव]. clinics ची फोन-डोकेदुखी कमी
> करणारी यंत्रणा लावून देतो: आठवणी आपोआप, तेच-तेच
> प्रश्नांची उत्तरं आपोआप. तुमचा फोन दिवसात किती वेळा
> वाजतो साधारण?"

(तिच्या दुखण्यापासून सुरुवात: ती जिंकली की डॉक्टर भेटतो.)

## धोक्याच्या जागा

```
1. Data-नाजूकपणा: रुग्ण-याद्या ही अति-नाजूक माहिती:
   करार कलम-सीमा (2.8) इथे दुप्पट कडक; कुठलाही
   रुग्ण-data तुमच्या मशीनवर साठवायचा नाही.
2. डॉक्टरचा अहं: "माझे रुग्ण मला सोडून जात नाहीत"
   ऐकू येईल: वाद नको (2.7): फक्त I-प्रश्न: "गेल्या
   महिन्याच्या वहीत किती नावं 'आले नाहीत' ची?"
3. Hospital = समिती: 10+ खाटांच्या hospital मध्ये निर्णय
   एकाचा नसतो: सुरुवात एकल-डॉक्टर clinic/lab पासूनच.
```

## इथे लोक चुकतात

**"डॉक्टर busy, म्हणून pitch पण घाईत."** उलट: डॉक्टर
हा तुमचा सर्वात शिकलेला गिऱ्हाईक आहे: त्याला यंत्रणा-
विचार (protocol, dosage, follow-up) रोजचाच आहे. आकडे
आणि रचना दाखवणाऱ्याला तो गंभीरपणे घेतो; "जादू" विकणाऱ्याला
हाकलतो. त्याच्याशी बोलताना प्रामाणिक पट्टी (1.6) हीच
तुमची जाहिरात: "हे यंत्र सल्ला देणार नाही, फक्त वेळा-
आठवणी" हे वाक्य त्याचा विश्वास **वाढवतं.**

## नकाशा

```
3.1  दुकान: उधारी-फोन-माल
3.2  clinic: no-show हे राज-दुखणं (जाड margin!); दरवाजा
     receptionist; R3+R1+follow-up; लाल रेषा: वैद्यकीय

```

**सूत्राशी:** "निकाल विकता": इथे निकाल = भरलेली खुर्ची.
ती मोजता येते: आठवड्याच्या वहीतच.

क) इथली लाल रेषा कुठली?

## सेवा-धंद्यांचा झटपट नकाशा

सेवा-धंद्यांत "देणं" = माणसाचा वेळ आणि कौशल्य. म्हणून
सगळ्यांचं मूळ-गणित clinic सारखं: **रिकामी वेळ = गेलेला
नफा; आणि मालकाचा वेळ प्रश्न-उत्तरांत जळणं = दुहेरी
नुकसान.** चौघांची झटपट ओळख:

```

   युद्ध!), तेच-तेच प्रश्न ("refund कधी?"), fees-वसुली.
   विका: कागद-मागणी-स्मरण-यंत्र (R2-रूप: "31 आधी
   हे 5 कागद पाठवा" च्या पायऱ्या), प्रश्न-bot (R1),
   fees-आठवण. deadline-हंगामाआधी विका (फेब्रु-मे).
   भाव: retainer ₹4-8K (CA स्वतः यंत्रणा-प्रेमी: चांगला
   गिऱ्हाईक, आणि पुढे तोच तुम्हाला त्याचे 100 clients
   दाखवणारा referral-राजा: 4.3!)
वकील:
   दुखणी: तारखा-आठवणी (client ला + स्वतःला), कागद-
   गोंधळ, "केसचं काय झालं" चे फोन.
   विका: तारीख-स्मरण (R3-रूप), client-खबर-यंत्र
   ("पुढची तारीख __"). भाव: ₹3-6K retainer.

```

## आता खरं शस्त्र: playbook-बनवायची पद्धत

सहा playbooks पाठ करण्यापेक्षा हे एक चौकट पाठ करा.
**कुठलाही नवा धंदा** समोर आला की पाच प्रश्न (जागच्या
जागी, 5 मिनिटांत):

```
प्रश्न 1: "देणं" काय आहे: माल की वेळ?
   माल -> दुकान-कुळ: वसुली-माल-अंदाज बघा (3.1)
   वेळ -> clinic-कुळ: रिकामी-वेळ/no-show बघा (3.2)
   प्रकल्प (आठवडे लागणारं) -> workshop-कुळ: quotation-
   वसुली बघा (3.5)
प्रश्न 2: गिऱ्हाईक कोण: माणसं की धंदे?
   माणसं (B2C) -> गर्दी-हंगाम-reviews महत्त्वाचे
   धंदे (B2B) -> quotation-वसुली-नातं महत्त्वाचे
प्रश्न 3: margin जाड की पातळ? (1.2 ची शिडी)
   जाड -> एक गिऱ्हाईक वाचवणं = मोठी किंमत: आठवणी/
   चौकशी-यंत्रं विका
   पातळ -> रोकड-वसुली विका
प्रश्न 4: चौकशी कुठून येते आणि कोण उत्तरतो?
   (उत्तर-उशीर दिसला की R1+R2 ची जागा तयार)
प्रश्न 5: या धंद्यात "तेच-तेच" काय? (1.3 ची खूण:
   मालकालाच विचारा: उत्तर तेच playbook चं हृदय)
```

पाच उत्तरं मिळाली की playbook तयार: कुळ ठरलं,
राज-दुखण्याचा अंदाज ठरला, recipe ठरली, भाव-पट्टी
margin वरून ठरली. **यादी संपली तरी पद्धत संपत नाही:**
हेच Book 12 (3.5) चं transfer-सत्य: चाली नाही,
नमुने न्या.
