# Chapter 3.5: Playbook: कारखाना / workshop / बांधकाम

## आधी अंदाज लिहा

```
1. workshop-मालकाला quotation बनवायला किती वेळ
   जात असेल, आणि तो का टाळतो? ________________
2. B2B धंद्यात (धंदा-ते-धंदा) उधारीचं दुखणं दुकानापेक्षा
   मोठं की छोटं? ______________________________
```

## धंद्याचा नकाशा

```
चक्र: ओळख/जुने गिऱ्हाईक/site-वाले -> चौकशी ("40
   खुर्च्या होतील का? भाव?") -> quotation -> घासाघीस
   -> order -> बनवणं/बसवणं (आठवडे-महिने!) -> बिल ->
   ...वसुली (B2B: 30-90+ दिवस थकते: देशाचा ₹7.34
   लाख कोटींचा डोंगर मुख्यतः इथेच) -> पुढची order
margin: मध्यम (माल + मजुरी); पण order-आकार मोठा:
   एक गिऱ्हाईक = लाखांचं वर्ष: नातं दीर्घ.
खासियत: इथला व्यवहार कागदांचा आहे: quotation, बिल,
   माप-नोंदी, GST: आणि नेमके कागदच अस्ताव्यस्त.
```

## Top-3 दुखणी

```
1. Quotation-घोळ: चौकशी आली की मालक "संध्याकाळी
   हिशेब करून पाठवतो" म्हणतो: संध्याकाळ होत नाही:
   2-3 दिवसांनी पाठवतो तोवर गिऱ्हाईक दुसऱ्याकडून
   करून मोकळं (speed-to-lead: B2B तही तेच सत्य!).
   शिवाय घाईत केलेल्या हिशेबात माल-दर जुने = margin
   नकळत कापला जातो.
2. B2B वसुली: बिलं 60-90 दिवस थकतात; मोठ्या
   गिऱ्हाईकाला मागायची भीती ("order बंद करील"):
   दुकानाच्या संकोचाचं मोठं-रकमी रूप.
3. Supplier-follow-up + कागद-गोंधळ: माल वेळेवर आला
   नाही की पूर्ण schedule कोसळतं; आणि GST-बिलांचा
   ढीग महिनाअखेरीस CA कडे जाताना युद्ध.
```

## विकण्याजोगी solutions

```
अ. Quotation-यंत्र (R4): पहिली निवड: मालकाने बोलून
   सांगितलं (voice-note चालेल!) की 5 मिनिटांत letterhead-
   वर PDF: चालू माल-दरांच्या यादीतून, GST-हिशेबासकट.
   demo केवळ जादुई दिसतो: त्याच्या समोर त्याच्याच
   जुन्या एका order चं quotation 3 मिनिटांत बनवून
   दाखवा. भाव: setup ₹15-35K, retainer ₹3-6K.
ब. वसुली-यंत्र (R2, B2B-रूप): बिल-तारखेप्रमाणे विनम्र
   स्मरण-पत्रं (इथे WhatsApp + email दोन्ही), 30/45/60
   दिवसांच्या पायऱ्या, मालकाला "कोण-किती-कधीपासून"
   ची यादी. B2B त संदेश अधिक औपचारिक: "आपल्या
   सोयीसाठी बिल क्र... ची प्रत पुन्हा जोडली आहे."
   भाव: setup ₹10-20K, retainer ₹3-5K.
क. Supplier-स्मरण + कागद-नोंदी (R2+R1 जोड): येणाऱ्या
   मालाच्या तारखांची यादी-आठवण; बिलांचे फोटो ->
   महिन्याची नीट यादी CA-कडे. जोड ₹2-3K.
```

## धोक्याच्या जागा

```
1. दर-यादी अद्ययावत ठेवणं: माल-भाव बदलले आणि यंत्र
   जुन्या दराने quotation देत राहिलं तर मालकाचा तोटा
   = तुमची चूक: करारात "दर-बदल मालक कळवणार"
   हे कलम-5 मध्ये स्पष्ट + महिन्याची दर-तपासणी-आठवण
   यंत्रच देईल असं ठेवा.
2. "पोरगं-नेटवर्क": इथले मालक एकमेकांना ओळखतात
   (association, बाजार-गल्ली): एक चांगलं काम = 3
   referrals; एक फसलेलं = गल्ली बंद. delivery-शिस्त
   (4.1) इथे सर्वात कडक.
3. site-वाले (बांधकाम): फिरते, फोनवर कठीण: त्यांचं
   दुखणं मुख्यतः मजूर-हजेरी/माल-नोंदी: वेगळं जग:
   पहिल्या 10 त घेऊ नका.
```

## इथे लोक चुकतात

**"factory म्हणजे मोठं-तांत्रिक: माझ्या आवाक्याबाहेर."**
तुम्ही machines automate करायला जात नाही आहात
(ते खरं engineering: लाल पट्टा तुमच्यासाठी): तुम्ही
**office automate करताय**: quotation, बिलं, स्मरणं,
नोंदी. 10 माणसांच्या workshop चं office = मालकाचा
खिसा आणि डोकं. तिथली 3 कामं आपोआप झाली की
तुम्ही "त्यांचा IT-वाला" आहात: आणि workshop-मालक
हा भागातल्या सर्वात जास्त पैसे देऊ शकणाऱ्या गिऱ्हाईकांपैकी
आहे (order-आकार बघा).
