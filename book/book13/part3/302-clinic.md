# Chapter 3.2 [SPINE]: Playbook: clinic / hospital / lab

## आधी अंदाज लिहा

```
1. clinic ची रिकामी 20-मिनिटांची वेळ "महाग" का असते?
   ______________________________________________
2. डॉक्टरशी बोलायला कोण भेटेल: डॉक्टर की आणखी कोण?
   ______________________________________________
```

## धंद्याचा नकाशा

```
चक्र: ओळख/Google/जुने रुग्ण -> फोन/walk-in वेळ ठरते
   -> तपासणी/उपचार -> रोख/UPI (वसुली सोपी; packages
   अडकतात) -> follow-up-भेटी, वार्षिक तपासण्या (टिकवणं:
   जवळजवळ कुणीच करत नाही)
margin: जाड: मुख्य खर्च डॉक्टरचा वेळ + भाडं. म्हणून:
   रिकामी वेळ = जवळजवळ पूर्ण नफा गमावला (1.2 ची
   शिडी): no-show हे इथलं राज-दुखणं.
खरा दरवाजा: receptionist/मालक-डॉक्टरची जोडीदार व्यक्ती.
   फोन तीच उचलते, वेळा तीच सांभाळते: तिचा त्रास
   कमी करणारं यंत्र = तिची शिफारस = डॉक्टरचा होकार.
   (तिला वगळून थेट डॉक्टरकडे = यंत्राची शत्रू घरातच.)
भेटीची वेळ: दुपारी OPD-नंतरची घडी (2-4) किंवा
   ठरवून-संध्याकाळ.
```

## Top-3 दुखणी

```
1. No-show: भारतीय OPD त ठरलेल्या 5 पैकी 1 रुग्ण
   येत नाही [थोडं: 18-30% चे अंदाज; खरा आकडा
   त्यांच्याच वहीतून काढा: I-प्रश्न!]. 20 no-show x
   ₹500-800 = ₹10-16K/महिना: जाड-margin मुळे
   जवळजवळ सगळा नफा.
2. फोनचा भडिमार: "वेळ मिळेल का/report आले का/
   रस्ता कुठून" चे तेच-तेच फोन: receptionist चा अर्धा
   दिवस + engaged-फोनमुळे नवे रुग्ण दुसरीकडे.
3. सुटलेला follow-up: "15 दिवसांनी परत या" म्हटलेले
   अर्धे येत नाहीत: रुग्णाचं नुकसान + क्लिनिकचं उत्पन्न-
   गळती + अपूर्ण उपचाराची जोखीम.
```

## विकण्याजोगी solutions

```
अ. आठवण-यंत्र (R3): पहिली निवड: आदल्या दिवशी +
   सकाळी मराठी आठवण, "येणार/बदला" बटणं; बदल
   यादीत आपोआप. आठवण-संदेशांनी no-show लक्षणीय
   घटतात हे संशोधनात जुनं-सिद्ध [पक्कं]. भाव: setup
   ₹10-20K, retainer ₹3-6K.
ब. उत्तर-bot (R1): वेळा/पत्ता/fees/तयारी ("उपाशी या")
   ची उत्तरं + "report तयार आहेत" ची आपोआप खबर
   (lab साठी सोन्याचं). भाव: setup ₹10-25K, retainer
   ₹2-5K.
क. follow-up-यंत्र (R2-चं वैद्यकीय रूप): "15-दिवसांनी"
   वाल्यांची यादी + आपोआप आठवण. retainer-जोड ₹1-2K.
मर्यादा-रेषा (1.6 ची लाल!): यंत्र वैद्यकीय सल्ला देणार
   नाही: लक्षणं/औषधांचे प्रश्न -> "डॉक्टरांनाच विचारा" +
   receptionist ला नोंद. हे करारात (कलम 2) लिहायचंच:
   इथे over-promise धोकादायक नाही, बेकायदेशीर आहे.
```

## दारातलं पहिलं वाक्य (receptionist ला)

> "नमस्कार, मी [नाव]. clinics ची फोन-डोकेदुखी कमी
> करणारी यंत्रणा लावून देतो: आठवणी आपोआप, तेच-तेच
> प्रश्नांची उत्तरं आपोआप. तुमचा फोन दिवसात किती वेळा
> वाजतो साधारण?"

(तिच्या दुखण्यापासून सुरुवात: ती जिंकली की डॉक्टर भेटतो.)

## धोक्याच्या जागा

```
1. Data-नाजूकपणा: रुग्ण-याद्या ही अति-नाजूक माहिती:
   करार कलम-सीमा (2.8) इथे दुप्पट कडक; कुठलाही
   रुग्ण-data तुमच्या मशीनवर साठवायचा नाही.
2. डॉक्टरचा अहं: "माझे रुग्ण मला सोडून जात नाहीत"
   ऐकू येईल: वाद नको (2.7): फक्त I-प्रश्न: "गेल्या
   महिन्याच्या वहीत किती नावं 'आले नाहीत' ची?"
3. Hospital = समिती: 10+ खाटांच्या hospital मध्ये निर्णय
   एकाचा नसतो: सुरुवात एकल-डॉक्टर clinic/lab पासूनच.
```

## इथे लोक चुकतात

**"डॉक्टर busy, म्हणून pitch पण घाईत."** उलट: डॉक्टर
हा तुमचा सर्वात शिकलेला गिऱ्हाईक आहे: त्याला यंत्रणा-
विचार (protocol, dosage, follow-up) रोजचाच आहे. आकडे
आणि रचना दाखवणाऱ्याला तो गंभीरपणे घेतो; "जादू" विकणाऱ्याला
हाकलतो. त्याच्याशी बोलताना प्रामाणिक पट्टी (1.6) हीच
तुमची जाहिरात: "हे यंत्र सल्ला देणार नाही, फक्त वेळा-
आठवणी" हे वाक्य त्याचा विश्वास **वाढवतं.**

## स्वतः करून बघा (field-काम 16)

म्हणूनही चालेल) 10 मिनिटं टिपा: फोन किती वाजले,
receptionist ने तेच उत्तर किती वेळा दिलं, "आले नाहीत"
चा उल्लेख ऐकू आला का. playbook च्या पेन्सिल-खुणा
भरा.
