# Chapter 3.1 [SPINE]: Playbook: दुकान / किराणा / distributor

## आधी अंदाज लिहा

```
1. दुकानाचं सर्वात मोठं दुखणं भाग 1-2 वरून आठवतंय?
   ______________________________________________
2. दुकानदाराला भेटायची योग्य वेळ? ________________
```

## धंद्याचा नकाशा

```
चक्र: वस्ती-ओळख -> counter/फोन/WhatsApp वरून order
   -> माल देणं/पोचवणं -> निम्मं रोख, निम्मं उधार ->
   नातं टिकतं (पण online-स्वस्ताई कुरतडते)
margin: पातळ (किराणा 2-6%; कपडे-भांडी जरा जास्त)
   -> म्हणून रोकड आणि वसुली जीवघेणी (1.2)
मालकाची घडी: सकाळ-संध्याकाळ गर्दी; दुपार 2-5 शांत
   (भेटीची वेळ!); रविवार निम्मा
आधीच हाती: WhatsApp (पक्कं), UPI (पक्कं), उधारी-वही
   (कागदी), कधी billing-machine
```

## Top-3 दुखणी (अपेक्षित: पेन्सिल-खुणा)

```
1. थकलेली उधारी: वस्ती-दुकानात गल्ल्याच्या 10-20%
   रक्कम कायम बाहेर; distributor कडे लाखांत (शिंदे-
   case: ₹1.75L). मागायचा संकोच = दुखण्याचं खरं रूप.
2. गर्दीत सुटलेले फोन/संदेश: गर्दीच्याच वेळी order-फोन
   येतात (सगळ्यांची तीच वेळ!): सुटला की order शेजारच्या
   दुकानात.
3. "संपलंय": माल-अंदाज वहीत नाही, डोक्यात: विक्री जाते
   किंवा माल पडून मरतो.
```

## विकण्याजोगी solutions (recipe-क्रमांकासकट)

```
अ. वसुली-यंत्र (R2): पहिली निवड: टोचणारं + मोजता
   येणारं + हिरवं. भाव: setup ₹8-15K, retainer ₹3-5K.
ब. उत्तर+order-bot (R1): "आहे का/भाव/order घ्या":
   चोवीस तास. भाव: setup ₹10-25K, retainer ₹2-4K.
   (दुकानाच्या आकाराप्रमाणे; distributor ला मोठा.)
क. परत-बोलावणं (R5-चं रूप): 30 दिवसांत न आलेल्या
   गिऱ्हाईकांना आठवण/offer. भाव: retainer मध्ये जोड
   ₹1-2K. (आधी अ/ब चालू झाल्यावरची वाढ-पायरी.)
जोड-विक्री (नंतरची): "संपत-आलं" ची यादी (billing-
   data असेल तरच: 2.2 ची चाळणी आठवा!)
```

## दारातलं पहिलं वाक्य

> "काका, मी [नाव], इथेच [खूण] जवळ असतो. दुकानांची
> रोजची डोकेदुखी: उधारीच्या आठवणी, सुटलेले फोन: अशी
> कामं आपोआप करून देतो. विकायला नाही आलो: दोनच
> मिनिटं: तुमच्याकडे उधारीचं कसं असतं?"

(थेट P-प्रश्नात उतरणारं. "आपोआप" आहे, "AI" नाही.)

## धोक्याच्या जागा

```
1. "पोरगं आहे की मग": घरचा-फुकट-मजूर आक्षेप (1.5)
   इथे सर्वात जास्त. उत्तर: "पोरगं delivery ला हवं की
   वहीत डोकं घालायला? यंत्र वही बघेल, पोरगं गल्ली."
2. billing-data नसणं: अंदाज-solutions विकू नका (चाळणी
   प्र.2): आधी नोंदी-recipe, अंदाज पुढच्या वर्षी.
3. हंगाम: दिवाळी-लग्नसराईत मालक बोलायलाही मोकळा
   नसतो: विक्री-भेटी हंगामाआधी/नंतर.
```

## इथे लोक चुकतात

**"छोट्या दुकानाला छोटं समजणं."** एक वस्ती-दुकान ₹3-5K
देईल; पण त्याच्या मागे उभा distributor (शिंदे) ₹15-20K
देतो, आणि त्याच्या वर stockist. **दुकानातून वर चढा:**
दुकानदाराला विचारलेला एक प्रश्न: "तुमचा माल कुठून येतो?"
= पुढच्या, मोठ्या गिऱ्हाईकाचा पत्ता. साखळीच्या प्रत्येक
पायरीवर तीच दुखणी, मोठ्या आकड्यांत.

## नकाशा

```
3.1  दुकान: उधारी-फोन-माल ही त्रिमूर्ती; R2 पहिली, R1
     दुसरी; पगार-पट्टीत भाव; "पोरगं" आक्षेपाचं उत्तर;
```

playbook म्हणजे तीच साखळी घडी करून खिशात.
