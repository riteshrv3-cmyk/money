# Chapter 3.3 [SPINE]: Playbook: coaching / class / college

## आधी अंदाज लिहा

```
1. class ला महिन्याला 100 चौकश्या येतात. साधारण
   किती admissions होत असतील? __________________
2. class चं उत्पन्न वर्षातल्या कुठल्या 2-3 महिन्यांत
   ठरतं? ______________________________________
```

## धंद्याचा नकाशा

```
चक्र: निकाल-बोर्ड/ओळख/भावंडं -> चौकशी (फोन/walk-in/
   Insta) -> demo-lecture/भेट -> admission + fees
   (हप्ते!) -> वर्षभर शिकवणं -> पुढचं वर्ष + भावंडं +
   मित्र (टिकवणं = खरं सोनं)
margin: जाड (खर्च: शिक्षक + जागा). एक admission =
   ₹15-60K+ : म्हणून एक हरवलेली चौकशी चार-आकडी
   नुकसान.
हंगाम-युद्ध: निकाल ते जून = admission-हंगाम: 70-80%
   उत्पन्न याच खिडकीत ठरतं. या काळात चौकशी-यंत्रणा
   जितकी वेगवान तितका class भरतो. (आणि विक्रेत्यासाठी
   अर्थ: यंत्र हंगामाआधी 2 महिने विकायचं-बसवायचं:
   ऐन हंगामात मालक बोलायलाही मोकळा नसतो.)
```

## Top-3 दुखणी

```
1. चौकशी-गळती: चौकशीतून admission चं प्रमाण साधारण
   6-10% च असतं [थोडं: क्षेत्र-वापरातले आकडे; walk-in
   चं 25-35%]. आणि इथे विक्री-संशोधनाचं मोठं सत्य:
   चौकशीला जितकं लवकर उत्तर तितकी admission ची
   शक्यता कैकपट [पक्कं: speed-to-lead हे जुनं-सिद्ध]:
   संध्याकाळी 7 ची चौकशी सकाळी 10 ला उत्तरली =
   बहुधा दुसऱ्या class ला गेलेली.
2. fees-हप्त्यांची वसुली: शिक्षकाला पालकांकडे पैसे मागायची
   सर्वात जास्त लाज: हप्ते महिनोंमहिने लटकतात (आपली
   जुनी ओळख: वसुली + संकोच).
3. पालक-प्रश्नांचा भडिमार: "बस कुठून/वेळापत्रक/सुट्टी/
   test कधी/निकाल काय": रोज तेच, शिकवण्याच्या वेळात.
```

## विकण्याजोगी solutions

```
अ. चौकशी-यंत्र (R1+R2 जोड): पहिली निवड: चौकशीला
   60 सेकंदांत मराठी उत्तर (course-माहिती, fees-पट्टी,
   demo-lecture ची वेळ ठरवणं) + न-ठरलेल्यांना 2-4-8
   दिवसांची follow-up-शिडी + मालकाला रोज यादी:
   "आज 6 नव्या, 2 demo ला येणार, 3 थंड."
   भाव: setup ₹15-30K, retainer ₹4-8K (हंगामात या
   यंत्राची किंमत त्यांना स्पष्ट दिसते: admission-भाषेत
   विका: "महिन्याला 2 admissions जरी वाढल्या तरी
   ₹30-100K").
ब. fees-आठवण (R2): विनम्र, "class च्या नावाने", हप्ता-
   वेळापत्रकानुसार: शिक्षकाची लाज यंत्राने मिटते. retainer-
   जोड ₹2-3K.
क. पालक-उत्तर-bot (R1): वेळापत्रक/बस/सुट्टी ची उत्तरं
   + परीक्षा-आठवणी. जोड ₹1-2K.
वाढ-विक्री (नंतर): absent-आठवण ("आज आर्यन आला
   नाही" ची पालकांना खबर): पालकांना सर्वात आवडणारी:
   class ची "काळजी घेणारा" प्रतिमा = referral-इंधन.
```

> हंगामात किती चौकश्या आल्या आणि किती admissions

(शेवटचा प्रश्न = थेट I-पायरी: 100 आणि 8 हे आकडे

## धोक्याच्या जागा

```
1. हंगाम चुकवणं: जुलैत विकायला गेलात तर "आता पुढच्या
   वर्षी": विक्री-खिडकी जाने-मार्च.
2. "Insta-मुलगा": मोठ्या classes कडे marketing-पोरगं
   असतं: त्याला शत्रू करू नका (2.7 चा सल्लागार-नियम):
   "तुझ्या ads ना उत्तरं द्यायचं यंत्र" म्हणून त्यालाच विका.
3. निकाल-हमी मागणं: "admissions वाढतील ना नक्की?"
   -> प्रामाणिक पट्टी: "चौकशी एकही गळणार नाही एवढी
   हमी; admission चं गणित तुमच्या निकालांवर." (हमी
   द्यायची ती process ची, निकालाची नाही: over-promise
   रेषा.)
```

## इथे लोक चुकतात

**"शिक्षकाला शिकवायला जाणं."** class-मालक हा गावातला
सर्वात बोलका-शिकलेला माणूस: त्याला "तुमचं marketing
चुकतंय" ऐकवणं = दार बंद. त्याची भाषा **विद्यार्थी-भाषा**
आहे: "हुशार मुलं चौकशी करून दुसरीकडे जातात कारण
उत्तर उशिरा येतं" हे वाक्य त्याला टोचतं: तो हुशार मुलांसाठीच
जगतो. दुखणं तेच, शब्द त्याच्या जगातले (1.6 चा नियम
प्रत्येक धंद्यात नव्याने).
