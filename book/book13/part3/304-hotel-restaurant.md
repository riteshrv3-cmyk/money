# Chapter 3.4: Playbook: hotel / restaurant / cloud-kitchen

## आधी अंदाज लिहा

```
1. restaurant चा माल-खर्च विक्रीच्या किती % असावा
   लागतो? ______________________________________
2. वाईट Google-review ला उत्तर देणं इतकं महत्त्वाचं का?
   ______________________________________________
```

## धंद्याचा नकाशा

```
चक्र: पाटी/Google/Zomato-Swiggy/ओळख -> order (टेबल/
   parcel/delivery-app) -> बनवणं-वाढणं -> रोख/UPI/app-
   settlement -> परत येणं (चव + आठवण + review)
margin: मध्यम-नाजूक: माल-खर्च (food cost) विक्रीच्या
   28-32% च्या आत राहिला पाहिजे [पक्कं: भारतीय
   क्षेत्र-प्रमाण]: 2% घसरला की नफा जवळजवळ गायब.
   delivery-apps चं commission (20-30%) margin अजून
   कापतं: म्हणून "थेट order" चं मोल मोठं.
घडी: सकाळ-तयारी, दुपार-रात्र सेवा: भेटीची वेळ:
   दुपारी 3:30-6 (दोन पाळ्यांच्या मध्ये).
```

## Top-3 दुखणी

```
1. Review-जखमा: नवं गिऱ्हाईक आधी stars बघतं. वाईट
   review ला उत्तर नाही = "मालकाला पर्वा नाही" ची
   जाहीर पाटी; उत्तरं द्यायला मालकाला वेळ-इंग्रजी-संयम
   तिन्ही कमी.
2. फोन-order चा गोंधळ: गर्दीच्या वेळीच order-फोन:
   ऐकू येत नाही, चुकतं लिहिलं जातं, engaged राहतो
   (= गेलेली order); parcel "कधी तयार होईल" चे
   परत-परत फोन.
3. आवक-अंदाज/वाया माल: शनिवारी किती भाजी? अंदाज
   चुकला की वाया (food cost फुगतो) किंवा "संपलं"
   (गिऱ्हाईक नाराज). (चाळणी-इशारा: नोंदी असतील तरच!)
```

## विकण्याजोगी solutions

```
अ. Review-यंत्र (R5): पहिली निवड: प्रत्येक review ला
   2 तासांत वैयक्तिक, विनम्र उत्तर (मराठी/English:
   गिऱ्हाईकाच्या भाषेत); वाईट review ची मालकाला लगेच
   खबर + मसुदा-उत्तर approve ला. भाव: setup ₹8-15K,
   retainer ₹2-4K. (demo अप्रतिम सोपा: त्यांच्याच
   जुन्या 3 reviews ना समोरच उत्तरं बनवून दाखवा!)
ब. WhatsApp-order-यंत्र (R1): menu-कार्ड बटणांसकट,
   order नोंद, "तयार झालं" ची खबर: फोन-गोंधळ संपतो
   आणि delivery-app चं commission वाचवणारा "थेट"
   रस्ता उघडतो: हे मालकाला भाषांतरित करून सांगा:
   "app ला 25% देता; या रस्त्याने आलेली order पूर्ण
   तुमची." भाव: setup ₹15-30K, retainer ₹3-6K.
क. परत-बोलावणं (R2-रूप): जुन्या गिऱ्हाईकांना (नंबर
   असतील तर) नव्या पदार्थाची/weekend ची आठवण.
   जोड ₹1-2K.
```

## दारातलं पहिलं वाक्य

> "दादा, मी [नाव]. hotels ची दोन कामं आपोआप करून
> देतो: Google-reviews ना वेळेवर चांगली उत्तरं, आणि
> WhatsApp वरून थेट orders: app-commission शिवाय.
> तुमच्या reviews ना सध्या उत्तरं कोण देतं?"

## धोक्याच्या जागा

```
1. खोट्या reviews चा मोह: "चांगले reviews टाकून द्या
   ना" अशी मागणी येईल: स्पष्ट नकार: ते बेकायदेशीर
   आणि (Book 11 च्या Medvi-धड्याप्रमाणे) उघडं पडणारं.
   "खरे reviews मिळवायचं यंत्र लावू: जेवणानंतर विनम्र
   विनंती-संदेश" हे कायदेशीर उत्तर.
2. Owner-वेळ-भ्रम: छोट्या hotel-मालकाकडे बसून बोलायला
   वेळच नसतो: pitch 5 मिनिटांचा ठेवा, demo 2 चा.
3. Cloud-kitchen वेगळं जग: तिथे सगळं delivery-app वर:
   दुखणं = app-ratings आणि packaging-नोंदी: R5 चढवा,
   R1 चं order-यंत्र गौण.
```

## इथे लोक चुकतात

**"चव माझं काम नाही म्हणून hotel-धंदा टाळणं."** खरंय:
चव तुमचं काम नाही (ते "देणं": मालकाचं). पण आठवा
1.1: **वाईट धंदा चवीने मरतो असं नाही; बहुतेक बरे-चवीचे
धंदे चक्राच्या बाकी चाकांनी मरतात:** दिसत-नाही (reviews),
उचलत-नाही (फोन), परत-बोलावत-नाही. तिथे तुम्ही आहात.
"चव चांगली असून गर्दी का नाही?" हा प्रश्न घेऊन फिरणाऱ्या
प्रत्येक मालकाचं उत्तर या playbook मध्ये आहे.
