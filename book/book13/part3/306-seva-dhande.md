# Chapter 3.6 [SPINE]: सेवा-धंदे + playbook स्वतः बनवायची पद्धत

## आधी अंदाज लिहा

```
1. CA आणि salon: दोन्ही "सेवा": दुखणी सारखी असतील
   का? __________________________________________
2. यादीत नसलेला धंदा समोर आला (उदा. pet-clinic,
   gym, travel-agent): काय कराल? ________________
```

## सेवा-धंद्यांचा झटपट नकाशा

सेवा-धंद्यांत "देणं" = माणसाचा वेळ आणि कौशल्य. म्हणून
सगळ्यांचं मूळ-गणित clinic सारखं: **रिकामी वेळ = गेलेला
नफा; आणि मालकाचा वेळ प्रश्न-उत्तरांत जळणं = दुहेरी
नुकसान.** चौघांची झटपट ओळख:

```
CA / tax-वाले:
   दुखणी: client कडून कागद वेळेवर न येणं (deadline-
   युद्ध!), तेच-तेच प्रश्न ("refund कधी?"), fees-वसुली.
   विका: कागद-मागणी-स्मरण-यंत्र (R2-रूप: "31 आधी
   हे 5 कागद पाठवा" च्या पायऱ्या), प्रश्न-bot (R1),
   fees-आठवण. deadline-हंगामाआधी विका (फेब्रु-मे).
   भाव: retainer ₹4-8K (CA स्वतः यंत्रणा-प्रेमी: चांगला
   गिऱ्हाईक, आणि पुढे तोच तुम्हाला त्याचे 100 clients
   दाखवणारा referral-राजा: 4.3!)
वकील:
   दुखणी: तारखा-आठवणी (client ला + स्वतःला), कागद-
   गोंधळ, "केसचं काय झालं" चे फोन.
   विका: तारीख-स्मरण (R3-रूप), client-खबर-यंत्र
   ("पुढची तारीख __"). भाव: ₹3-6K retainer.
   (लाल रेषा परत: कायदेशीर सल्ला यंत्राकडून नाही!)
salon / parlour:
   दुखणी: no-show + रिकाम्या खुर्च्या (clinic चं जुळं),
   परत-न-येणं (टिकवणं).
   विका: R3 आठवणी + R2-रूप "6 आठवडे झाले" ची
   परत-बोलावणी + R5 reviews. भाव: ₹2-4K retainer
   (लहान गल्ला: भाव खालच्या पट्ट्यात).
छोटी agency / फोटोग्राफर / event-वाले:
   दुखणी: चौकशी-गळती + quotation + advance-वसुली:
   coaching आणि workshop चं मिश्रण.
   विका: R1+R4+R2 ची जोड. भाव: ₹4-8K.
```

## आता खरं शस्त्र: playbook-बनवायची पद्धत

सहा playbooks पाठ करण्यापेक्षा हे एक चौकट पाठ करा.
**कुठलाही नवा धंदा** समोर आला की पाच प्रश्न (जागच्या
जागी, 5 मिनिटांत):

```
प्रश्न 1: "देणं" काय आहे: माल की वेळ?
   माल -> दुकान-कुळ: वसुली-माल-अंदाज बघा (3.1)
   वेळ -> clinic-कुळ: रिकामी-वेळ/no-show बघा (3.2)
   प्रकल्प (आठवडे लागणारं) -> workshop-कुळ: quotation-
   वसुली बघा (3.5)
प्रश्न 2: गिऱ्हाईक कोण: माणसं की धंदे?
   माणसं (B2C) -> गर्दी-हंगाम-reviews महत्त्वाचे
   धंदे (B2B) -> quotation-वसुली-नातं महत्त्वाचे
प्रश्न 3: margin जाड की पातळ? (1.2 ची शिडी)
   जाड -> एक गिऱ्हाईक वाचवणं = मोठी किंमत: आठवणी/
   चौकशी-यंत्रं विका
   पातळ -> रोकड-वसुली विका
प्रश्न 4: चौकशी कुठून येते आणि कोण उत्तरतो?
   (उत्तर-उशीर दिसला की R1+R2 ची जागा तयार)
प्रश्न 5: या धंद्यात "तेच-तेच" काय? (1.3 ची खूण:
   मालकालाच विचारा: उत्तर तेच playbook चं हृदय)
```

पाच उत्तरं मिळाली की playbook तयार: कुळ ठरलं,
राज-दुखण्याचा अंदाज ठरला, recipe ठरली, भाव-पट्टी
margin वरून ठरली. **यादी संपली तरी पद्धत संपत नाही:**
हेच Book 12 (3.5) चं transfer-सत्य: चाली नाही,
नमुने न्या.

## इथे लोक चुकतात

**"प्रत्येक नव्या धंद्याला नवं शिकावं लागेल" ही भीती
(आणि तिची उलटी बहीण: "सगळे धंदे सारखेच" ही घाई.)**

दोन्ही चुकीचे. 80% यंत्रणा सारखी (चक्र, 5 recipes,
SPIN, भाव-गणित): 20% त्या धंद्याची माती (शब्द, हंगाम,
लाल रेषा, दरवाजा-कोण). ते 20% उडवलंत तर clinic ला
"stock" विचारणारे आणि दुकानदाराला "appointment"
विकणारे व्हाल: हास्यास्पद. ते 20% = वरचे पाच प्रश्न +
पहिल्या 10 मिनिटांचे डोळे (2.1). **80% आत्मविश्वास
घ्या, 20% नम्रता ठेवा.**

## नकाशा

```
3.1  दुकान: वसुली-फोन-माल        3.4  hotel: reviews-order
3.2  clinic: no-show, दरवाजा      3.5  कारखाना: quotation-
     receptionist                      B2B-वसुली
3.3  coaching: चौकशी x वेग,       3.6  सेवा: CA-वकील-salon-
     हंगाम-खिडकी                       agency; playbook-चौकट:
                                       देणं?/B2B-B2C?/margin?/
                                       चौकशी?/तेच-तेच?
```

**सूत्राशी:** सूत्र धंदा बदलला तरी तेच: बघा (5 प्रश्न),
बांधा (recipe), दाखवा (demo), बोला (SPIN). playbook
म्हणजे "बघा" चा वेग वाढवणारी उशी: बदली नाही.

## स्वतः करून बघा (field-काम 20)

तुमच्या 10-दारांच्या यादीत **यादीबाहेरचा** एखादा धंदा
असेल (gym? medical? travel?), त्याला 5-प्रश्नांची चौकट
लावून त्याचं playbook अर्ध्या पानात लिहा: कुळ, राज-दुखणं,
recipe, भाव-पट्टी, पहिलं वाक्य. (नसेल तर pet-clinic
वर सराव करा: गंमत म्हणून.)

## आठवा

```
अ) playbook-चौकटीचे पाच प्रश्न?
ब) CA हा "referral-राजा" का?
क) 80/20 चं वाटप: सारखं काय, बदलणारं काय?
ड) (मागचं) 3.1-3.5: पाचही playbooks ची राज-दुखणी
   एका-एका शब्दात? (उधारी / no-show / चौकशी-वेग /
   reviews / quotation-वेग: न बघता आलं का?)
```

भाग 3 संपला: सहा दारं + एक चौकट. पुढचं पान:
उजळणी. आणि मग शेवटचा भाग: **विकल्यानंतरचं जग:**
30 दिवसांत देणं, टिकवणं, पहिल्या 10 गिऱ्हाईकांची
यंत्रणा, गुरु-hype चं सत्य, आणि service-ते-product
चा जिना.
