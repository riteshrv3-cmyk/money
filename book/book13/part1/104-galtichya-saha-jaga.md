# Chapter 1.4 [SPINE]: गळतीच्या 6 जागा + किंमत-सूत्रं

## आधी अंदाज लिहा

```
1. दुकानाचा फोन वाजला, कुणी उचलला नाही. या एका
   घटनेची किंमत रुपयांत कशी काढाल? ______________
2. "गिऱ्हाईक परत आलं नाही" याची किंमत कशी काढाल?
   ______________________________________________
```

## सहा जागा

चक्र (1.1) कुठल्याही धंद्यात याच सहा जागी गळतं. प्रत्येक
जागेला: ती कशी दिसते, आणि **किंमत काढायचं एक-ओळ
सूत्र.** हीच सूत्रं तुमचं fluent English आहेत: बोलणं
अडखळलं तरी सूत्र मांडता आलं की मालक ऐकतो.

```
गळती 1: हरवलेली विचारपूस (चक्र-जागा: मिळवणं)
   दिसते: न उचललेले फोन, उत्तर न दिलेले WhatsApp,
   उशिरा उत्तर ("तुमच्याकडे उत्तर उशिरा येतं").
   सूत्र: हरवलेल्या विचारपुसा/महिना x त्यातून गिऱ्हाईक
   होण्याचं प्रमाण x सरासरी बिल x margin = ₹/महिना
   उदा (coaching): 30 चौकश्या हरवल्या x 10% प्रवेश
   x ₹40,000 fee x जाड margin (~60%) = ₹72,000/महिना

गळती 2: विसरलेला follow-up (मिळवणं)
   दिसते: "पाठवतो/कळवतो" म्हटलं आणि राहिलं; quotation
   पाठवलं, पुढे काही नाही. विचारपूस लगेच धरली तर
   गिऱ्हाईक होण्याची शक्यता कैकपट, हे विक्री-संशोधनात
   जुनं सिद्ध आहे [पक्कं: वेग निर्णायक; नेमका पट
   अभ्यासागणिक बदलतो]
   सूत्र: गळती-1 चंच, फक्त "हरवलेल्या" जागी "थंड पडलेल्या"

गळती 3: न आलेलं गिऱ्हाईक: no-show (देणं)
   दिसते: clinic/salon/class ची ठरलेली वेळ रिकामी गेली.
   भारतीय OPD त साधारण 5 पैकी 1 रुग्ण ठरवून येत
   नाही [थोडं: 18-30% चे अंदाज, नेमका आकडा जागेवर
   मोजायचा]
   सूत्र: रिकाम्या वेळा/महिना x सरासरी बिल x margin
   उदा (दाताचं clinic): 20 no-show x ₹800 x ~80%
   = ₹12,800/महिना: आणि आठवण-संदेशाने no-show
   लक्षणीय घटतात हे सिद्ध आहे [पक्कं]

गळती 4: थकलेली वसुली (वसुली)
   दिसते: उधारी-वही, "देतो पुढच्या आठवड्यात", संकोचाने
   न केलेले फोन. (देश-पातळी: ₹7.34 लाख कोटी: 1.2)
   सूत्र इथे दुहेरी:
   (अ) अडकलेली रक्कम x महिने x तुमच्या पैशाची किंमत
       (कर्जाचा व्याज-दर ~1.5-2%/महिना) = बुडणारं व्याज
   (ब) + त्यातली कधीच न येणारी टक्केवारी (जुनी उधारी
       जितकी जुनी तितकी मरते)
   उदा: ₹1,80,000 सरासरी 3 महिने अडकले = ₹8-10
   हजार फक्त व्याज-रूपाने/चक्रात + बुडीत

गळती 5: चुकलेला माल-अंदाज (देणं)
   दिसते: "संपलंय, उद्या या" (विक्री गेली) किंवा पडून
   राहिलेला-कालबाह्य माल (रोकड अडकली/मेली). भारतीय
   retail मध्ये मालाची गळती जागतिक सरासरीहून जास्त
   नोंदलेली आहे [थोडं: जुना अभ्यास ~3%; नवे विक्रेते-
   आकडे फुगीर]
   सूत्र: ("संपलं" म्हटलेल्या वेळा x सरासरी बिल x margin)
   + (मेलेला माल ₹/महिना)

गळती 6: गेलेलं-परत-न-आलेलं गिऱ्हाईक (टिकवणं)
   दिसते: कुणी मोजतच नाही: म्हणून सर्वात मोठी आणि
   सर्वात अदृश्य. जुनं गिऱ्हाईक टिकवणं नवं मिळवण्यापेक्षा
   कैकपट स्वस्त (Book 11, 3.3 चं LTV-गणित इथेच).
   सूत्र: दर महिन्याला गळणारी गिऱ्हाईकं x वर्षभराचं
   त्यांचं गिऱ्हाईक-मूल्य (LTV) = वर्षाचा खड्डा
   उदा: महिन्याला 10 गिऱ्हाईकं गळाली x वर्षाला ₹6,000
   चं गिऱ्हाईक x margin 15% = ₹9,000/महिना वाढत
   जाणारा खड्डा
```

## गळती-पत्रक (छापण्याजोगं: हेच तुमचं calculator)

```
धंदा: ______________  तारीख: ______
                       महिन्याचा   आकडा    ₹ गळती
गळती                   अंदाज-प्रश्न  (मालकाकडून) /महिना
1 हरवलेली विचारपूस     किती? x %  x बिल    ______
2 थंड follow-up        किती थंड?           ______
3 no-show              रिकाम्या वेळा?       ______
4 थकलेली वसुली         अडकलेले ₹? महिने?   ______
5 माल-अंदाज            "संपलं"? मेलेला माल? ______
6 न परतलेली गिऱ्हाईकं   गळती? LTV?          ______
                       एकूण दुखणं:         ______
सर्वात मोठ्या दोन गळत्या: ____ आणि ____
```

**एकूण दुखण्याचा आकडा हा तुमच्या विक्रीचा पाया आहे.**
भाव त्याच्यावरून ठरतो (2.5): वाचवलेल्याचा 10-20% हा
न्याय्य आणि सोपा युक्तिवाद: "महिन्याला ₹70,000 गळतंय;
मी ₹8,000 त निम्मं थांबवतो."

## दोन प्रामाणिक नियम

**नियम 1: आकडे मालकाच्या तोंडून यायला हवेत.** तुम्ही
सांगितलेला आकडा तो नाकारू शकतो; **त्याने सांगितलेला
नाही.** म्हणून audit मध्ये (2.1) प्रश्न विचारायचे, भाषण
नाही: "महिन्याला साधारण किती चौकश्या येतात? त्यातल्या
किती राहून जातात?" तो म्हणेल "अंदाजे 30 येतात, 8-10
राहतात": झालं: आता 2.3 च्या पद्धतीने त्यालाच गुणाकार
करू द्यायचा.

**नियम 2: अंदाजाला अंदाज म्हणा.** "साधारण", "ढोबळ",
"तुमचे आकडे टाकून बघू" हे शब्द वापरणारा माणूस विश्वासू
वाटतो; "नक्की एवढं वाचेल!" म्हणणारा course-विक्रेता
वाटतो. आकड्याची ताकद नेमकेपणात नाही, **मोजण्याच्या
कृतीत** आहे: मालकाने आजवर हे कधी मोजलेलंच नसतं.

## इथे लोक चुकतात

**"सहाही गळत्या दाखवून सहाही बुजवायचं promise करणं."**

audit मध्ये सहाही मोजायच्या (पूर्ण चित्र + तुमची
विश्वासार्हता), पण **विकायची फक्त सर्वात मोठी एक** (फार
तर दोन). कारण: (अ) मालकाचा विश्वास अजून उधारीवर
आहे: छोटी सुरुवात, लगेच निकाल, मग वाढ (1.3 चा धडा);
(ब) सहा गोष्टी एकदम = मोठा project = भीती = "नंतर
बघू"; (क) आणि तुमचं delivery-ओझं (4.1) झेपेल एवढंच
घ्यायचं. उरलेल्या चार गळत्या पळून जात नाहीत: त्या
तुमच्या पुढच्या सहा महिन्यांची विक्री-यादी आहेत.

## नकाशा

```
1.1  चक्र   1.2  पैसा   1.3  वेळ
1.4  सहा गळत्या: विचारपूस, follow-up, no-show, वसुली,
     माल-अंदाज, न-परतलेली गिऱ्हाईकं: प्रत्येकीचं ₹-सूत्र;
     गळती-पत्रक = calculator; आकडे मालकाच्या तोंडून;
     मोजा सहा, विका एक
```

**सूत्राशी:** "आधी बघा" चं मोजण्याचं रूप हेच. सूत्रातलं
"निकाल विकता" म्हणजे या पत्रकाच्या शेवटच्या रकान्यातला
आकडा लहान करणं: बाकी सगळ्या गप्पा.

## स्वतः करून बघा (20 मिनिटं: field-काम 4)

तुमच्या निवडलेल्या धंद्याचं गळती-पत्रक भरा: जमेल तिथे
मालकाला विचारून, बाकी अंदाजाने (अंदाजावर * खूण करा).
एकूण ₹-आकडा काढा. **तो आकडा बघून तुम्हालाच धक्का
बसेल: तोच धक्का पुढे मालकाला बसणार आहे: आणि तीच
तुमची विक्री आहे.**

## आठवा

```
अ) सहा गळत्या, चक्राच्या जागांसकट?
ब) गळती-1 चं सूत्र, तुमच्या शब्दांत, एका उदाहरणासकट?
क) "मोजा सहा, विका एक" चं कारण?
ड) (मागचं) 1.3: "तेच-तेच" ही खूण कशाची?
```

गळत्या मोजता आल्या. आता ज्या जमिनीवर हे विकायचं
ती जमीन: भारतातला छोटा धंदा नेमका कसा आहे: किती
आहे, काय वापरतो, **कशाला पैसे देतो आणि कशाला
मरूनही देत नाही.** शेवटच्या प्रश्नाचं उत्तर दोन प्रसिद्ध
app-कंपन्यांच्या प्रेतांवर लिहिलेलं आहे.
