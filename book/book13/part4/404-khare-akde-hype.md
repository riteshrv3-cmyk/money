## गुरु-यंत्राची चिरफाड (एकदा, नीट)

"AI Automation Agency" ही जगभर लाट आहे, आणि
तिच्यावर गुरूंचं एक ठरलेलं यंत्र चालतं. त्याची ओळख:

```
1. आकड्यांचा उगम: सगळे प्रसिद्ध दावे ($72K/महिना,
   "3 महिन्यांत $300K") स्वतःच सांगितलेले आहेत:
   एकही स्वतंत्र-तपासलेला नाही [पक्कं: आम्ही शोधलं:
   सापडला नाही].
2. खरा धंदा: दाव्यांच्या मागोमाग course/community
   येते. म्हणजे कमाईचा मोठा वाटा गिऱ्हाईकांकडून नाही,
   तुमच्याकडून (शिकणाऱ्यांकडून) आहे. सर्वात प्रसिद्ध
   गुरूने स्वतःच्याच लेखनात कबूल केलंय: $10K+ देणारे
   client फार थोडे; आणि "automation बांधणं" झपाट्याने
   स्वस्त-सामान्य होतंय [स्व: पण त्याचंच].
3. ओळख-चाचणी (Book 12 ची चाळणी इथेही): कमाई-
   दाव्यानंतर course-link आली की विषय संपला. खरा
   पैसा गिऱ्हाईकं-सेवेतून येतो; गुरु-पैसा स्वप्न-विक्रीतून.
```

**पण इथे मोठी गोष्ट: यंत्रणा खोटी नाही.** दुखणी खरी
(₹7.34 लाख कोटी!), tools खरे, धंदे खरे. खोटा आहे तो
वेग आणि सोपेपणा. hype काढला की उरतं ते हे:

## खरं पहिलं वर्ष (जमिनीवरचं गणित)

```
महिने 1-2: शिकणं + demos + पहिली 10-20 दारं:
   उत्पन्न ~₹0 (कदाचित पहिलं setup)
महिने 3-6: 3-6 गिऱ्हाईकं रुजतात:
   ₹15-40K/महिना (setups + retainers मिळून)
महिने 7-12: referral-झाड + कुळ-खोली + वाढ-विक्री:
   ₹50K-1L/महिना पल्ल्यात येतं: जर टिकवण्याची शिस्त
   (4.1-4.2) पाळली असेल तर
वर्ष-2: 15-25 टिकलेली गिऱ्हाईकं x ₹5-8K सरासरी =
   ₹1-2L/महिना: एकट्याच्या देखरेखीची साधारण मर्यादा
   इथे येते: पुढे 4.5 चा फाटा (product किंवा माणसं:
   Book 11, 3.5 चं फाटा-सूत्र)
```

हे आकडे हमी नाहीत; **प्रामाणिक पल्ला** आहेत (मेहनत,
भाग, कुळ यांनी वर-खाली). नोकरीच्या पगाराशी तुलना
करा आणि एक गोष्ट लक्षात घ्या: पगार वर्षाला 10% वाढतो;
**हे यंत्र चक्रवाढीने वाढतं** (टिकलेली गिऱ्हाईकं + referrals
+ वाढ-विक्री): वर्ष-1 पगाराशी हरतं, वर्ष-3 त बहुधा जिंकतं.
आणि जोडीला Book 11 चं दार उघडं राहतं (4.5).

## फसलेल्या 5 ची gallery (प्रत्येकाचा प्रतिबंध-नियम)

```
मृत्यू 1: over-promise वाला. "सगळं automatic होईल"
   विकलं; यंत्र फुगीर-वचनावर अडलं; मालकाने वस्तीत
   सांगितलं. नियम: हिरवा पट्टा (1.6) + करार-कलम-2.
मृत्यू 2: फुकट-pilot च्या खड्ड्यातला. "आधी फुकट करून
   दाखवतो" x 4 गिऱ्हाईकं: 2 महिने काम, उत्पन्न शून्य,
   आणि फुकटचं कुणीच वापरलं नाही (गुंतवणूक = लक्ष:
   2.6). नियम: demo फुकट, बांधणी कधीच नाही:
   advance-शिवाय-हात-नाही (2.8).
मृत्यू 3: demo-त कोसळलेला. भर भेटीत bot अडला:
   "यांचंच चालत नाही." नियम: 2-मिनिटांची रिहर्सल +
   offline-पर्याय (screenshot-मालिका खिशात: net गेलं
   तरी गोष्ट दाखवता येते).
मृत्यू 4: scope-राक्षसाने खाल्लेला. ₹8K च्या कामात
   "हे पण जरा" x 9: तीन महिने एकाच गिऱ्हाईकात,
   बाकी दारं थंड. नियम: "कागदात नाही: पुढच्या
   कागदात" (2.8) + क्रम: टिकवणं > वाढवणं > नवं (4.2).
मृत्यू 5: एकाच खांबावरचा. सगळं उत्पन्न एका मोठ्या
   गिऱ्हाईकाकडून; त्याने सोडलं, धंदा गेला. नियम:
   कुठलंही एक गिऱ्हाईक उत्पन्नाच्या 30% वर जाऊ
   देऊ नका: गेलं तर महिन्यात भरून निघेल एवढंच
   प्रत्येकाचं वजन. (Book 11, 2.6 चीच गोष्ट गल्लीत.)
```

## इथे लोक चुकतात

**"hype नाकारला म्हणून संधीही नाकारणं."**

गुरूंचा तिटकारा येऊन "हे सगळंच थोतांड" म्हणणं ही
उलटी चूक: **बाळासकट पाणी फेकणं.** चाचणी सोपी आहे:
थोतांड course विकतो; खरा धंदा गिऱ्हाईक विकत घेतो.
तुमच्या हातात आता जे आहे: verified दुखणी, 5 recipes,
worked भाव-गणित, delivery-शिस्त: याला hype ची गरजच
नाही. **खऱ्या यंत्रणेची खूण हीच: ती फुगवावी लागत नाही.**
