# Chapter 2.1 [SPINE]: 45 मिनिटांचं audit

## आधी अंदाज लिहा

```
1. धंद्यात शिरल्यावर पहिली 10 मिनिटं काय करायचं
   असेल: बोलणं की बघणं? ________________________
2. मालकाला न दुखावता त्याच्या गळत्या कशा विचाराल?
   ______________________________________________
```

## Audit म्हणजे काय आणि आत कसं शिरायचं

Audit (तपासणी) = चक्राच्या चार चाकांवर प्रश्न विचारून
गळती-पत्रक भरणं. वेळ: 45 मिनिटं. जागा: त्याचा धंदा
(office नाही: counter जवळ, गोदामात, जिथे काम घडतं).

आत शिरायची तीन दारं (सोपं ते अवघड):

```
1. ओळख: "काकांचा भाचा", "तुमच्याकडचं नेहमीचं गिऱ्हाईक"
   -> "एक नवीन काम शिकतोय, तुमच्या धंद्याबद्दल 10
   मिनिटं विचारू का?" (10 म्हणा; रस लागला की तोच
   45 करतो)
2. गिऱ्हाईक-वाट: आधी त्याचं गिऱ्हाईक व्हा/असा; गप्पांतून
   ("उधारीचा त्रास किती हो?": 1.2 चं field-काम)
3. थेट: दुपारी 2-5 च्या शांत वेळी जा; "मी जवळच
   राहतो, दुकानांची छोटी कामं आपोआप करून देतो;
   विकायला नाही, फक्त 2 प्रश्न विचारायला आलोय"
   (आणि खरंच त्या दिवशी काही विकायचं नाही!)
```

## पहिली 10 मिनिटं: फक्त डोळे

बोलण्याआधी बघा (सूत्र!). counter जवळ उभं राहून हे
टिपायचं:

```
फोन किती वेळा वाजतो? कोण उचलतं? किती सुटतात?
वही कुठली-कुठली? (order-वही, उधारी-वही, appointment-वही)
भिंतीवर काय? (भाव-पत्रक, वेळापत्रक, देवाचा फोटो शेजारी
   थकबाकीदारांची यादी?)
मालक स्वतः काय करतोय? (1.3 ची वर्गवारी: निर्णय की
   पुनरावृत्ती?)
गिऱ्हाईक काय विचारतात? (तेच-तेच प्रश्न कुठले?)
```

ही 10 मिनिटं तुमच्या प्रश्नांना धार देतात: "मघाशी 3 फोन
सुटले बघितले..." असं म्हणणारा माणूस "software विकायला
आलेला" वाटत नाही; **लक्ष देणारा** वाटतो.

## प्रश्नांची यादी (चक्रावर, क्रमाने)

नियम आठवा (1.4): आकडे **त्याच्या** तोंडून. प्रश्न छोटे,
मोकळे, आणि "तुमचं चुकतंय" चा वास नसलेले:

```
मिळवणं:
   "नवं गिऱ्हाईक कसं येतं तुमच्याकडे: ओळखीने की कसं?"
   "दिवसाला साधारण किती फोन/चौकश्या येतात?"
   "गर्दीच्या वेळी फोन उचलायला जमतं का?" <- सुटलेल्या
   विचारपुसांकडे नेणारा हळू रस्ता
   "कुणी 'नंतर सांगतो' म्हटलं तर पुढे काय होतं?"
देणं:
   "दिवसातला सर्वात कटकटीचा तास कुठला?"
   "कुठलं काम रोजचं-रोजचं आहे, तेच-तेच?" <- सोन्याची खूण
   ("संपलंय" किती वेळा? रिकाम्या वेळा? धंद्याप्रमाणे)
वसुली:
   "या धंद्यात उधारीचं कसं असतं हो?" <- सगळेच बोलतात
   "साधारण किती अडकलेलं असतं? किती जुनं?"
   "आठवण करायला कसं वाटतं?" <- संकोचाचं दुखणं
टिकवणं:
   "जुनं गिऱ्हाईक गळालं हे कधी कळतं का?"
   "परत बोलावण्यासाठी काही करता का?"
शेवटी (सर्वात महत्त्वाचा):
   "जादूची कांडी असती तर धंद्यातली कुठली एक कटकट
   कायमची घालवली असती?"
```

शेवटच्या प्रश्नाचं उत्तर अनेकदा तुमच्या पत्रकात नसलेलं
काहीतरी असतं: ते नोंदवा: **मालकाने स्वतः सांगितलेलं दुखणं
हे विकायला सर्वात सोपं दुखणं असतं** (2.3 मध्ये का ते
कळेल).

## भरलेलं खरं पत्रक (worked उदाहरण: पूर्ण धागा सुरू)

इथून पुढचे chapters एकाच खऱ्या-वाटणाऱ्या case वर चालतील:
**"शिंदे एजन्सी": किराणा-मालाचा distributor, 2 पोरं
delivery ला, वस्तीतली 60-70 दुकानं गिऱ्हाईक.** त्याचं
audit-पत्रक, 45 मिनिटांनंतर:

```
धंदा: शिंदे एजन्सी (distributor)   margin: पातळ (~4-5%)
उलाढाल: ~₹18 लाख/महिना (त्याच्या तोंडून: "लाख-सव्वा
   लाखाचा माल रोज जातो")
गळती-पत्रक:
1 विचारपूस: "गर्दीत फोन सुटतात" - अंदाज 5-6/दिवस;
   त्यातले निम्मे order असतात; सरासरी order ₹1,500
   -> 80 x ₹1,500 x 4% margin = ~₹4,800/महिना *
2 follow-up: quotation दिलेली 4 नवी दुकानं थंड पडली
   -> 4 x ₹40,000/महिना-order x 4% = ₹6,400/महिना
   शक्यता-गुणिले-अर्धा = ~₹3,200 *
3 no-show: लागू नाही (distributor)
4 वसुली: "दीड-दोन लाख कायम बाहेर असतात, काही
   दिवाळीपासूनचे" -> ₹1.75 लाख x 3 महिने सरासरी x
   1.5%/महिना व्याज-किंमत = ~₹7,900/चक्र + जुनी
   बुडीत ~₹15,000/वर्ष *
5 माल-अंदाज: "संपलंय" आठवड्याला 8-10 वेळा ->
   ~₹5,000/महिना *; पडून-मेलेला माल "थोडाफार"
6 न-परतलेली दुकानं: "2 दुकानं गेल्या महिन्यात दुसऱ्याकडे
   गेली: उत्तर उशिरा म्हणून" -> 2 x ₹40,000 x 4% x
   12 महिने = ₹38,400/वर्ष = ₹3,200/महिना
एकूण दुखणं: ~₹24,000/महिना (* = अंदाज)
सर्वात मोठ्या दोन: वसुली + हरवलेली विचारपूस/उत्तर-उशीर
जादूची कांडी (त्याच्या शब्दांत): "पैसे मागायचा कंटाळा
   आलाय: आणि पोरं order घ्यायला विसरतात"
```

बघा: मालकाने "जादूची कांडी" मध्ये **स्वतःच** पत्रकातल्या
सर्वात मोठ्या दोन गळत्या सांगितल्या. असंच घडतं: पत्रक
तुमच्या डोक्यात, कांडी त्याच्या तोंडून: जुळलं की विक्री
अर्धी झालेली असते. (हा case 2.5 च्या भेटीत आणि 2.6
च्या भाव-गणितात पुढे चालेल.)

## इथे लोक चुकतात

**"Audit च्या भेटीतच विकायला लागणं."**

दुखणं ऐकताच तोंडात solution येतं: "अरे यावर मी...!"
थांबा. आजचा दिवस फक्त बघण्याचा (सूत्राचा क्रम!). कारणं:
(1) न मागता दिलेलं solution फुकट वाटतं आणि विसरलं
जातं; (2) demo शिवाय बोललात तर तुम्ही "बोलणारा"
झालात: आणि तो असले दहा बघून बसलाय (1.5); (3)
घाईने चुकीचं दुखणं पकडलं जातं (चाळणी अजून लावलेलीच
नाही: 2.2). आजचं शेवटचं वाक्य फक्त हे: **"मला यातलं
एक काम आपोआप करून दाखवता येईल असं वाटतंय. दोन
दिवसांत एक छोटी गोष्ट बनवून आणून दाखवू? पैसे नाही:
फक्त बघा."** आणि निघायचं.

## नकाशा

```
2.1  audit: आत शिरायची 3 दारं; पहिली 10 मिनिटं फक्त
     डोळे; चक्रावर प्रश्न (आकडे त्याच्या तोंडून); जादूची-
     कांडी प्रश्न; शिंदे-case: एकूण ₹24K/महिना, कांडी =
     वसुली+उत्तर-उशीर; आज विकायचं नाही: demo चं
     आमंत्रण घेऊन निघायचं
```

**सूत्राशी:** "आधी बघा" या दोन शब्दांचा हा पूर्ण chapter.
बोलणं आलंच, पण प्रश्न-रूपात: भाषण शून्य.

## स्वतः करून बघा (field-काम 7: या आठवड्यात)

भाग 1 च्या धंद्यावर (किंवा 10-दारांच्या यादीतल्या सर्वात
सोप्या दारावर) **खरं 45-मिनिट audit** करा: वरची प्रश्न-
यादी वहीत उतरवून न्या. भरलेलं पत्रक = मोहीम-नोंदीत
audit #1 पूर्ण. (भीती वाटतेय? पुढच्या chapter मध्ये
Claude-सोबत सराव आहे: आधी तो करा, मग जा.)
