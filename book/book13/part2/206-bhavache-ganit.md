# Chapter 2.6 [SPINE]: भावाचं पूर्ण गणित

## आधी अंदाज लिहा

```
1. WhatsApp-bot चा "योग्य" भाव कसा काढाल: तुमच्या
   कष्टावरून की आणखी कशावरून? __________________
2. फार स्वस्त विकण्यात नेमकं काय बिघडतं? __________
```

## भावाची तीन दिशा-यंत्रं

भाव काढताना तीन होकायंत्रं एकत्र वापरायची:

```
यंत्र 1: दुखण्याचा अपूर्णांक (मुख्य)
   भाव = मोजलेल्या गळतीच्या 10-20%
   शिंदे: गळती ~₹24,000/महिना -> retainer ₹3-5,000
   योग्य. मालकाचा हिशेब सोपा: "5 देऊन 20 वाचतात."
यंत्र 2: पगार-पट्टी (मालकाच्या डोक्यातली फूटपट्टी)
   तो प्रत्येक खर्च पगाराशी ताडतो (1.5). counter-माणूस
   ₹10-15K/महिना. तुमचा retainer त्याच्या अर्ध्याखाली
   असला की "स्वस्त माणूस" वाटतो: ₹3-8K हा भारतीय
   micro-धंद्याचा सुखाचा पट्टा.
यंत्र 3: बाजार-पट्टी (तुम्ही एकटे नाही)
   भारतात या कामांचे चालू भाव [थोडं: विक्रेते-यादीतून,
   पण सुसंगत]: साधा WhatsApp-bot ₹15-50K setup;
   जोडण्यांसकट ₹50K-1.5L; चालू खर्च+retainer
   ₹3-15K/महिना. या पट्टीच्या तळाशी शिरा (नवखे
   आहात), मध्यावर वाढा (4.2).
```

**Setup + retainer ही रचना का:** setup तुमच्या बांधणीचे
पैसे देतो (आणि "फुकटात करून बघू" वाल्यांना चाळतो:
पैसे दिलेला मालकच यंत्र वापरतो: गुंतवणूक = लक्ष);
retainer तुमचं खरं इंजिन आहे: Book 11 चं MRR-गणित:
10 गिऱ्हाईकं x ₹5K = ₹50K/महिना **आपोआप येणारे,**
आणि तुमचा चालू खर्च (API-tokens, platform-भाडं)
गिऱ्हाईकागणिक काही शेकड्यांत: margin जाड.

## शिंदे-सौद्याचं पूर्ण गणित (तुमच्या बाजूने)

```
setup ₹12,000 (घासाघिशीनंतर)
   बांधणी: master-recipe तयार होती -> re-skin + वही
   भरणं + चाचणी = ~10 तास काम -> ₹1,200/तास
retainer ₹4,000/महिना
   चालू खर्च: API + platform ~₹500-800/महिना
   पहिला महिना देखरेख: ~4 तास; नंतर: ~1-2 तास/महिना
   -> दुसऱ्या महिन्यापासून ₹3,200+ नफा = 80% margin
आणि खरी गोम: शिंदे 12 महिने टिकले तर एक सौदा =
   ₹12K + 48K = ₹60,000. म्हणून 4.2 (टिकवणं) हा
   chapter भावाइतकाच महत्त्वाचा आहे.
```

## स्वस्त-विकण्याचा सापळा (नीट, एकदाच)

नवख्याचा मोह: "₹1,000 त करून देतो, फक्त हो म्हणा."
काय बिघडतं:

```
1. भाव = तुमची किंमत-पाटी. ₹1,000 वाला "पोरगं"
   असतो; ₹12,000 वाला "व्यावसायिक". स्वस्त भावाला
   मालक कमी गंभीरपणे घेतो: यंत्र वापरत नाही: चाललं
   नाही: churn: आणि वस्तीत खबर "त्याचं चाललं नाही."
   स्वस्त विकून वाईट-खबर विकत घेतली!
2. गणित बुडतं: ₹1,000 x 10 गिऱ्हाईकं = ₹10K साठी
   10 धंद्यांची देखरेख: वेळ संपतो, वाढ थांबते.
3. भाव वर काढणं जवळजवळ अशक्य: पहिला भाव नांगर
   (anchor) होतो. खाली सुरुवात = कायम खाली.
उतारा: भाव कमी करायचाच झाला तर पैसे नको, आकार
   कापा: "₹12K जड? मग आधी फक्त वसुली-यंत्र, उत्तर-
   bot नंतर: ₹8K." काम कापा, दर नाही.
```

आणि उलटा सापळा एक ओळ: फार महागही नको: पहिल्या
5 गिऱ्हाईकांत तुम्ही भाव नाही, **case-गोष्टी** कमावताय
(4.3): बाजार-पट्टीच्या तळाशी या, पण **तळाच्या खाली
कधीच नाही.**

## भाव सांगायची पद्धत (30 सेकंद)

```
1. आधी दुखण्याचा आकडा परत: "तुमचं महिन्याला ~₹20-25
   हजार गळतंय असं आपणच काढलं."
2. मग भाव, पगार-पट्टीत: "हे चालू करायला ₹12 हजार
   एकदा, आणि महिन्याला ₹4: म्हणजे पोराच्या पगाराच्या
   तिसऱ्या हिश्श्यात."
3. मग जोखीम-उलट: "पहिला महिना बघा; नाही पटलं तर
   महिन्याचे पैसे परत."
4. मग शांतता. (पहिला जो बोलतो तो हरतो, हे विक्रीतलं
   जुनं आणि खरं वाक्य: भाव सांगून झाल्यावर समर्थनाची
   बडबड सुरू केली की भाव पोकळ वाटतो.)
```

## इथे लोक चुकतात

**"भाव तासांवरून काढणं."**

"माझे 10 तास गेले, तासाला ₹500, म्हणून ₹5,000" हे
गणित दोन्ही बाजूंनी चुकतं: master-recipe मुळे तुमचे तास
घटत जातील (मग भाव घटणार का? वेडेपणा!) आणि
मालकाला तुमच्या तासांशी देणंघेणं नाही: **त्याला त्याच्या
वाचलेल्या रुपयांशी आहे.** किंमत निकालाची असते, कष्टांची
नाही (सूत्र!). Picasso ची जुनी गोष्ट: रेखाटन 30 सेकंदांचं,
बिल आयुष्यभराच्या सरावाचं. तुमचं ही तेच: recipe 30
मिनिटांत re-skin होते **कारण** तुम्ही ती महिनाभर घडवलीये.

## नकाशा

```
2.1-2.5  (audit -> चाळणी -> SPIN -> demo -> भेट)
2.6  भाव: दुखण्याचा 10-20% x पगार-पट्टी x बाजार-पट्टी;
     setup (चाळणी+बांधणी) + retainer (इंजिन, ~80%
     margin); स्वस्त-सापळा: पाटी-गणित-नांगर: काम कापा,
     दर नाही; सांगायची 4-पायरी + शांतता; तास नको,
     निकाल
```

**सूत्राशी:** "निकाल विकता" चं रुपयांतलं रूप: भाव निकालाला
बांधला की घासाघीसही निकालाबद्दल होते, तुमच्या "खर्चा"बद्दल
नाही.
