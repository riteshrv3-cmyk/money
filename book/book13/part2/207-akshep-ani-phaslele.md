# Chapter 2.7 [SPINE]: आक्षेप, एक फसलेली भेट, follow-up यंत्र

## आधी अंदाज लिहा

```
1. "विचार करून सांगतो" चा खरा अर्थ बहुधा काय असतो?
   ______________________________________________
2. विक्री जास्त कुठे मरते: भेटीत की दोन भेटींच्या मध्ये?
   ______________________________________________
```

## पाच आक्षेप, पाच उत्तरं

```
आ.1 "महाग वाटतं."
   उत्तर = 2.6 ची पद्धत: दुखण्याचा आकडा परत + काम
   कापायची offer (दर नाही). आणि एक तपास-प्रश्न:
   "महाग म्हणजे: उपयोग होईल का शंका आहे, की या
   महिन्यात एवढे नाहीत?" (पहिल्याला demo-हमी उत्तर;
   दुसऱ्याला "setup दोन हप्त्यांत" चालतं.)
आ.2 "स्टाफला/मला हे जमणार नाही."
   उत्तर: "तुम्हाला काहीच शिकायचं नाहीये: यंत्र WhatsApp
   वरच राहतं, जे तुम्ही आत्ताही वापरता. आणि पहिला
   आठवडा मी रोज इथे येऊन सोबत बसणार." (4.1 चं
   वचन: आणि ते पाळायचंही.)
आ.3 "आधी एकाकडून software घेतलं, पडून आहे."
   उत्तर: सहानुभूती + फरक: "बरोबरच आहे सावधपणा.
   म्हणूनच मी आधी बनवून दाखवतोय, आणि महिन्याची
   हमी देतोय: पडून राहिलं तर पैसे माझे गेले, तुमचे
   नाही." (त्याचा भूतकाळ हा तुमचा शत्रू नाही; तुमच्या
   हमीचं कारण आहे.)
आ.4 "मुलाला/भाच्याला विचारून सांगतो."
   उत्तर: टाळाटाळ नाही: खरी रचना आहे (घरचा tech-
   सल्लागार!). "जरूर: त्यांचा नंबर द्या, मी त्यांनाच demo
   पाठवतो: त्यांना पटलं तर तुम्हाला पटेल." (सल्लागाराला
   वगळू नका: भरती करा.)
आ.5 "बघू, नंतर, दिवाळीनंतर..."
   उत्तर: एक ठोस छोटं पाऊल + तारीख: "चालेल. एक
   करू: वही भरायचं काम आत्ता 20 मिनिटांत करून
   ठेवू: चालू कधी करायचं ते तुम्ही दिवाळीनंतर सांगा."
   (होकाराची किंमत शून्यावर आणा; नकाराला तारीख द्या.)
```

**सोनेरी नियम:** आक्षेपाशी कधीही वाद घालायचा नाही. आधी
"बरोबर आहे" (खरंच बरोबर असतं!), मग रचना. आणि 10
भेटींत 7-8 नकार **हे यश आहे** (4.3 चा protocol): नकाराची
नोंद करा: कुठला आक्षेप, कुठलं उत्तर दिलं, पुढे काय.

## एक फसलेली भेट (शब्दशः: मुद्दाम)

(जोशी क्लासेस: coaching class. विक्रेता घाईत आहे:
audit न करता, ऐकीव माहितीवर थेट pitch ला गेलाय.)

```
वि.: सर, मी AI automation करतो. तुमच्या class साठी
   chatbot बनवून देतो: admission enquiries आपोआप
   handle होतील, follow-up automatic, CRM पण...
   >> पहिल्याच वाक्यात: "AI", English-jargon, आणि
   >> विचारण्याआधी solution. 1.6 + 2.3 दोन्ही मोडले.
जोशी: enquiries चं काही अडत नाही आमचं. admissions
   full आहेत यंदा.
   >> audit नाही -> दुखणं चुकलं. जोशींचं खरं दुखणं
   >> (नंतर कळलं असतं): fees चे थकलेले हप्ते आणि
   >> parents च्या शंका-प्रश्नांत जाणारा वेळ.
वि.: पण sir, future साठी important आहे. आजकाल
   सगळे class हे वापरतात. तुम्ही मागे पडाल.
   >> भीती-विक्री + "सगळे वापरतात" [दंत]. मालकाला
   >> हे रोज ऐकू येतं: विमा-वाले, hoarding-वाले...
जोशी: (फोन बघत) बरं, quotation पाठवा WhatsApp वर.
   >> "quotation पाठवा" = विनम्र नकार. demo नाही,
   >> आकडा नाही, दुखणं नाही: quotation कशाचं?
वि.: पाठवतो sir! खूप स्वस्तात करून देईन.
   >> न मागता "स्वस्त": स्वतःच्या पाटीवर स्वतःच
   >> "पोरगं" लिहिलं (2.6).
(quotation गेलं. उत्तर कधीच आलं नाही. विक्रेत्याची नोंद:
"जोशी: interested नाही." खरी नोंद हवी होती: "मी audit
न करता गेलो.")
```

**चिरफाड:** भेट दारातच मेली नव्हती: ती **आदल्या दिवशी**
मेली होती: बघितलं नाही, बांधलं नाही, दाखवलं नाही:
फक्त बोलला. सूत्राचा क्रम उलटा केला की निकालही उलटा.
(आणि "quotation पाठवा" ऐकल्यावर वाचायचा एकच रस्ता
होता: "quotation कसलं देऊ sir: आधी तुमचं नेमकं काय
अडतं ते दोन मिनिटं सांगाल? कदाचित माझं काम तुम्हाला
लागतच नसेल." प्रामाणिक माघार अनेकदा दार परत उघडते.)

## Follow-up यंत्र (भेटी-मधलं)

विक्री-संशोधनाचं जुनं सत्य: बहुतेक होकार पहिल्या भेटीत
येत नाहीत; आणि बहुतेक विक्रेते दुसरा प्रयत्नच करत
नाहीत. तुमचं यंत्र (स्वतःवरच recipe-2 चालवा!):

```
दिवस 0: भेट. संध्याकाळी थ ैंक्स-संदेश + ठरलेली गोष्ट
   ("गुरुवारी demo घेऊन येतो").
दिवस 1-2: demo-भेट (24-48 तास: 2.4 चा नियम).
दिवस 4: न ठरल्यास: त्याच्या आकड्याची आठवण:
   "काका, आपण काढलेला हिशेब परत बघत होतो:
   महिन्याला ~₹24 हजार. विचार झाला का?"
दिवस 8: नवं मूल्य: त्याच्या धंद्याशी संबंधित एखादी
   उपयोगी गोष्ट पाठवा (GST-तारखेची आठवण, त्याच्या
   मालाची बाजार-बातमी): विक्री-संदेश नाही, मदत.
दिवस 15: शेवटचा थेट: "जागा 2 च उरल्यात या महिन्यात
   माझ्याकडे (खरं तेच सांगा): नंतर पुढच्या महिन्यात."
मग: यादीत 'थंड' खूण; महिन्याने recipe-2 च्या मऊ
   फेरीत. (नकार चिरंतन नसतो; वेळ चुकलेली असते.)
```

प्रत्येक संदेश **मराठीत, छोटा, आणि त्याच्या आकड्याशी/
धंद्याशी जोडलेला.** "sir reminder" छाप इंग्रजी-संदेश =
हटवला जातो.

## इथे लोक चुकतात

**"नकाराचा अर्थ 'मी वाईट आहे' असा घेणं."**

फसलेल्या भेटीची नोंद "जोशी वाईट/मी वाईट" अशी झाली
की शिकणं शून्य. नोंद **यंत्रणेची** करायची: कुठली पायरी
उडाली? (जोशी-case: audit.) Book 12 (2.4) चा उंबरठा-
विचार इथे लावा: प्रत्येक नकारानंतर एका ओळीचं post-
mortem: "पायरी __ उडाली/कच्ची: पुढच्या वेळी __."
10 नकारांच्या नोंदी = तुमचा वैयक्तिक विक्री-course:
कुठल्याही गुरूपेक्षा खरा.

## नकाशा

```
2.1-2.6  (audit -> ... -> भाव)
2.7  पाच आक्षेप (वाद नाही: "बरोबर आहे" + रचना);
     फसलेली भेट: आदल्या दिवशी मेलेली (क्रम उलटा);
     follow-up यंत्र 0-2-4-8-15 + थंड-फेरी; नकाराचं
     post-mortem = यंत्रणेवर, स्वतःवर नाही
```

**सूत्राशी:** फसलेली भेट = सूत्र उलटं वाचल्याचा जिवंत
पुरावा: बोलला-आधी, बघितलं-कधीच-नाही.
