# Chapter 2.8: एका पानाचा करार + सीमा

## आधी अंदाज लिहा

```
1. छोट्या धंद्याशी 10-पानी legal करार करावा का? ______
2. करारात "काय देणार" पेक्षा महत्त्वाचं काय असू शकतं?
   ______________________________________________
```

## एक पान का (आणि तरी का)

10-पानी legal-भाषा शिंदेंना संशयीच करते ("वकील कशाला
मध्ये?"). पण **काहीच लिखित नसणं** त्याहून वाईट: कारण
स्मरण दोघांचंही निवडक असतं (Book 12!): सहा महिन्यांनी
"तू म्हणाला होतास सगळं होईल" विरुद्ध "मी असं कधीच
म्हटलं नव्हतं" हे भांडण ठरलेलं. एका पानाचा, साध्या
मराठीतला, दोघांच्या सह्यांचा कागद = भांडण-विमा.

## कागद (जसाच्या तसा वापरा: 900 मध्ये कोरा साचा)

```
कामाचा कागद: शिंदे एजन्सी x [तुमचं नाव]  दि. ______
1. काय बनवणार: उधारी-आठवण यंत्र: (अ) थकबाकी-यादीतून
   ठरलेल्या दिवशी WhatsApp-आठवणी (7/15/30 दिवसांच्या
   पायऱ्या); (ब) मालकाला रोज सकाळी वसुली-यादी.
2. काय नाही: गिऱ्हाईकांशी भाव-बोलणी नाही; पैसे
   हलवणं नाही; याखेरीज नवी कामं = नवा कागद.
3. कधी: वही-भरणी + चालू: __ तारखेपर्यंत. पहिला
   आठवडा रोज तपासणी माझी.
4. किती: चालू करणं ₹______ (आज निम्मे, चालू झाल्यावर
   निम्मे); महिना ₹______ (प्रत्येक महिन्याच्या 5 ला,
   UPI). पहिल्या महिन्यात न पटल्यास महिन्याचे पैसे परत.
5. लागणारं: मालकांकडून थकबाकी-यादी + महिन्यातले बदल;
   यंत्राचे संदेश मालकांच्या नावाने जातात, मजकूर आधी
   दाखवलेला.
6. थांबवणं: कुणीही, 15 दिवस आधी सांगून. डेटा (याद्या,
   नोंदी) मालकांचा: थांबल्यास पूर्ण परत.
सह्या: मालक ______   मी ______
```

सहा कलमं, अर्धं पान. वाचा नीट: **कलम 2 (काय नाही)
हे कलम 1 इतकंच जाड आहे.** scope-वाढीचा राक्षस (सगळं
करून देतो चा धाकटा भाऊ) याच कलमाने बांधला जातो:
"हे कागदात नाही: करू, पण पुढच्या कागदात" हे वाक्य
भांडणाशिवाय म्हणता येतं: कागद बोलतो, तुम्ही नाही.

## तीन सीमा ज्या कधीच सोडायच्या नाहीत

```
1. Advance शिवाय बांधणी नाही. "चालू झाल्यावर देतो"
   = बहुधा कधीच नाही. निम्मा setup आधी ही खूण
   आहे: तो गंभीर आहे का याची शेवटची चाळणी.
   (अपवाद: demo. तो फुकटच: तो तुमचा विक्री-खर्च.)
2. डेटा मालकाचा, प्रामाणिकपणा तुमचा. त्याच्या गिऱ्हाईकांचे
   numbers ही त्याची संपत्ती: ती दुसरीकडे वापरणं
   म्हणजे धंद्याची आत्महत्या (वस्तीची खबर-यंत्रणा आठवा).
   आणि Book 4 ची security-शिस्त इथे व्यवहारात:
   दुसऱ्याच्या डेटाला तिजोरीसारखं वागवा.
3. यंत्राचे संदेश मालकाच्या नावाने आणि त्याच्या मंजुरीने.
   मजकूर आधी दाखवायचा: त्याच्या गिऱ्हाईकांशी त्याचं
   नातं आहे: तुम्ही त्या नात्याचे विश्वस्त आहात, मालक
   नाही.
```

## इथे लोक चुकतात

**"नात्यात कागद कशाला: काका तर ओळखीचे आहेत."**

उलट आहे: **ओळखीतच कागद जास्त लागतो.** अनोळखी
फसवला तर धंदा जातो; ओळखीचा दुखावला तर घर-दार-
मंडळ सगळीकडे किंमत मोजावी लागते. कागद ओळखीला
धक्का नाही: "आपलं ठरलेलं विसरायला नको म्हणून लिहून
ठेवू काका" हे वाक्य कुणीही नाकारत नाही. आणि जो
नाकारतो ("कागद-बिगद काही नको!") तो 2.2 च्या फुकट-
जातीची घंटा वाजवतोय: ऐका.
