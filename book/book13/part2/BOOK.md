## Audit म्हणजे काय आणि आत कसं शिरायचं

Audit (तपासणी) = चक्राच्या चार चाकांवर प्रश्न विचारून
गळती-पत्रक भरणं. वेळ: 45 मिनिटं. जागा: त्याचा धंदा
(office नाही: counter जवळ, गोदामात, जिथे काम घडतं).

आत शिरायची तीन दारं (सोपं ते अवघड):

```
1. ओळख: "काकांचा भाचा", "तुमच्याकडचं नेहमीचं गिऱ्हाईक"
   -> "एक नवीन काम शिकतोय, तुमच्या धंद्याबद्दल 10
   मिनिटं विचारू का?" (10 म्हणा; रस लागला की तोच
   45 करतो)
2. गिऱ्हाईक-वाट: आधी त्याचं गिऱ्हाईक व्हा/असा; गप्पांतून
   ("उधारीचा त्रास किती हो?": 1.2 चं field-काम)
3. थेट: दुपारी 2-5 च्या शांत वेळी जा; "मी जवळच
   राहतो, दुकानांची छोटी कामं आपोआप करून देतो;
   विकायला नाही, फक्त 2 प्रश्न विचारायला आलोय"
   (आणि खरंच त्या दिवशी काही विकायचं नाही!)
```

## पहिली 10 मिनिटं: फक्त डोळे

बोलण्याआधी बघा (सूत्र!). counter जवळ उभं राहून हे
टिपायचं:

```
फोन किती वेळा वाजतो? कोण उचलतं? किती सुटतात?
वही कुठली-कुठली? (order-वही, उधारी-वही, appointment-वही)
भिंतीवर काय? (भाव-पत्रक, वेळापत्रक, देवाचा फोटो शेजारी
   थकबाकीदारांची यादी?)
मालक स्वतः काय करतोय? (1.3 ची वर्गवारी: निर्णय की
   पुनरावृत्ती?)
गिऱ्हाईक काय विचारतात? (तेच-तेच प्रश्न कुठले?)
```

ही 10 मिनिटं तुमच्या प्रश्नांना धार देतात: "मघाशी 3 फोन
सुटले बघितले..." असं म्हणणारा माणूस "software विकायला
आलेला" वाटत नाही; **लक्ष देणारा** वाटतो.

## प्रश्नांची यादी (चक्रावर, क्रमाने)

नियम आठवा (1.4): आकडे **त्याच्या** तोंडून. प्रश्न छोटे,
मोकळे, आणि "तुमचं चुकतंय" चा वास नसलेले:

```
मिळवणं:
   "नवं गिऱ्हाईक कसं येतं तुमच्याकडे: ओळखीने की कसं?"
   "दिवसाला साधारण किती फोन/चौकश्या येतात?"
   "गर्दीच्या वेळी फोन उचलायला जमतं का?" <- सुटलेल्या
   विचारपुसांकडे नेणारा हळू रस्ता
   "कुणी 'नंतर सांगतो' म्हटलं तर पुढे काय होतं?"
देणं:
   "दिवसातला सर्वात कटकटीचा तास कुठला?"
   "कुठलं काम रोजचं-रोजचं आहे, तेच-तेच?" <- सोन्याची खूण
   ("संपलंय" किती वेळा? रिकाम्या वेळा? धंद्याप्रमाणे)
वसुली:
   "या धंद्यात उधारीचं कसं असतं हो?" <- सगळेच बोलतात
   "साधारण किती अडकलेलं असतं? किती जुनं?"
   "आठवण करायला कसं वाटतं?" <- संकोचाचं दुखणं
टिकवणं:
   "जुनं गिऱ्हाईक गळालं हे कधी कळतं का?"
   "परत बोलावण्यासाठी काही करता का?"
शेवटी (सर्वात महत्त्वाचा):
   "जादूची कांडी असती तर धंद्यातली कुठली एक कटकट
   कायमची घालवली असती?"
```

शेवटच्या प्रश्नाचं उत्तर अनेकदा तुमच्या पत्रकात नसलेलं
काहीतरी असतं: ते नोंदवा: **मालकाने स्वतः सांगितलेलं दुखणं
हे विकायला सर्वात सोपं दुखणं असतं** (2.3 मध्ये का ते
कळेल).

## भरलेलं खरं पत्रक (worked उदाहरण: पूर्ण धागा सुरू)

इथून पुढचे chapters एकाच खऱ्या-वाटणाऱ्या case वर चालतील:
**"शिंदे एजन्सी": किराणा-मालाचा distributor, 2 पोरं
delivery ला, वस्तीतली 60-70 दुकानं गिऱ्हाईक.** त्याचं
audit-पत्रक, 45 मिनिटांनंतर:

```
धंदा: शिंदे एजन्सी (distributor)   margin: पातळ (~4-5%)
उलाढाल: ~₹18 लाख/महिना (त्याच्या तोंडून: "लाख-सव्वा
   लाखाचा माल रोज जातो")
गळती-पत्रक:
1 विचारपूस: "गर्दीत फोन सुटतात" - अंदाज 5-6/दिवस;
   त्यातले निम्मे order असतात; सरासरी order ₹1,500
   -> 80 x ₹1,500 x 4% margin = ~₹4,800/महिना *
2 follow-up: quotation दिलेली 4 नवी दुकानं थंड पडली
   -> 4 x ₹40,000/महिना-order x 4% = ₹6,400/महिना
   शक्यता-गुणिले-अर्धा = ~₹3,200 *
3 no-show: लागू नाही (distributor)
4 वसुली: "दीड-दोन लाख कायम बाहेर असतात, काही
   दिवाळीपासूनचे" -> ₹1.75 लाख x 3 महिने सरासरी x
   1.5%/महिना व्याज-किंमत = ~₹7,900/चक्र + जुनी
   बुडीत ~₹15,000/वर्ष *
5 माल-अंदाज: "संपलंय" आठवड्याला 8-10 वेळा ->
   ~₹5,000/महिना *; पडून-मेलेला माल "थोडाफार"
6 न-परतलेली दुकानं: "2 दुकानं गेल्या महिन्यात दुसऱ्याकडे
   गेली: उत्तर उशिरा म्हणून" -> 2 x ₹40,000 x 4% x
   12 महिने = ₹38,400/वर्ष = ₹3,200/महिना
एकूण दुखणं: ~₹24,000/महिना (* = अंदाज)
सर्वात मोठ्या दोन: वसुली + हरवलेली विचारपूस/उत्तर-उशीर
जादूची कांडी (त्याच्या शब्दांत): "पैसे मागायचा कंटाळा
   आलाय: आणि पोरं order घ्यायला विसरतात"
```

बघा: मालकाने "जादूची कांडी" मध्ये **स्वतःच** पत्रकातल्या
सर्वात मोठ्या दोन गळत्या सांगितल्या. असंच घडतं: पत्रक
तुमच्या डोक्यात, कांडी त्याच्या तोंडून: जुळलं की विक्री
अर्धी झालेली असते. (हा case 2.5 च्या भेटीत आणि 2.6
च्या भाव-गणितात पुढे चालेल.)

## इथे लोक चुकतात

**"Audit च्या भेटीतच विकायला लागणं."**

दुखणं ऐकताच तोंडात solution येतं: "अरे यावर मी...!"
थांबा. आजचा दिवस फक्त बघण्याचा (सूत्राचा क्रम!). कारणं:
(1) न मागता दिलेलं solution फुकट वाटतं आणि विसरलं
जातं; (2) demo शिवाय बोललात तर तुम्ही "बोलणारा"
झालात: आणि तो असले दहा बघून बसलाय (1.5); (3)
घाईने चुकीचं दुखणं पकडलं जातं (चाळणी अजून लावलेलीच
नाही: 2.2). आजचं शेवटचं वाक्य फक्त हे: **"मला यातलं
एक काम आपोआप करून दाखवता येईल असं वाटतंय. दोन
दिवसांत एक छोटी गोष्ट बनवून आणून दाखवू? पैसे नाही:
फक्त बघा."** आणि निघायचं.

## पाच प्रश्नांची चाळणी

Audit मधून 4-5 दुखणी निघतात. विकायचं **एक.** निवडीसाठी
प्रत्येक दुखण्याला पाच प्रश्न (गुण 0/1/2):

```
प्र.1 आकडा मोठा आहे का?
     (₹/महिना जितका मोठा तितका भाव मोठा: 1.4)
प्र.2 हिरव्या पट्ट्यात सुटतं का?
     (1.6: आठवणी-उत्तरं-नोंदी-follow-up = हो;
     "पोरं शिस्तीत वागत नाहीत" = यंत्राचं काम नाही!)
प्र.3 निकाल लगेच आणि डोळ्यांना दिसेल का?
     (2 आठवड्यांत मालकाला फरक दिसला पाहिजे:
     वसूल झालेले ₹, उचललेले फोन: मोजता येणारं)
प्र.4 मालकाला टोचतं का?
     (जादूच्या कांडीत आलं = 2 गुण; तुम्हालाच फक्त
     दिसतंय = 0: 2.3 मध्ये टोचणं वाढवता येतं, पण
     शून्यातून नाही)
प्र.5 मला 24-48 तासांत demo बांधता येईल का?
     (2.4 च्या recipes पैकी एकात बसतं का?)
गुण: 8-10 = हेच घ्या | 5-7 = दुसरं बघा | <5 = सोडा
```

## शिंदे-case वर चाळणी चालवू

```
दुखणं            प्र.1  प्र.2  प्र.3  प्र.4  प्र.5  एकूण
वसुली-आठवणी      2     2     2     2     2     10
उत्तर-उशीर/       1     2     2     2     2      9
  order-नोंदी
थंड quotations    1     2     1     1     2      7
माल-अंदाज         1     1     1     0     1      4
```

निवड स्पष्ट: **वसुली-आठवणी** (10/10). उत्तर-उशीर 9 वर:
तो "पुढचा टप्पा" म्हणून खिशात ठेवायचा (4.2 ची वाढ-
यादी). माल-अंदाज 4: आकर्षक वाटतो ("AI ने अंदाज!")
पण प्र.2 वर अडतो: विक्रीचा इतिहास नीट नोंदलेलाच नाही,
मग यंत्र शिकणार कशावर? आणि प्र.4 वर मालकाला तो
टोचतही नाही. **नवखा नेमका हाच निवडतो, कारण तो
"हुशार" दिसतो.** चाळणी त्यासाठीच आहे.

## दोन धोक्याचे नमुने (चाळणीबाहेरचे)

**नमुना 1: "सगळं करून देतो."** मालक म्हणतो "हे पण
होईल का? ते पण?" उत्साहात "हो हो, सगळं!" म्हटलं की
project फुगतो, भाव मात्र एकाचाच राहतो, delivery बुडते
(4.4 च्या gallery तला मृत्यू #4). उत्तर तयार ठेवा:
**"होईल: पण आधी हे एक चालू करू. हे चाललं की पुढचं
पुढच्या महिन्यात."** मालकालाही हेच हवं असतं: त्याचा
विश्वासही एका पायरीचाच आहे.

**नमुना 2: "दुखणं खरं, मालक खोटा."** काही मालक audit
मध्ये भरभरून बोलतात आणि द्यायच्या वेळी गायब. खुणा
आधीच दिसतात: प्रत्येक गोष्टीत "फुकट करून द्या मग बघू",

## 35,000 भेटींचा अभ्यास

1970-80 च्या दशकात Neil Rackham च्या टीमने विक्रीच्या
इतिहासातला सर्वात मोठा अभ्यास केला: 20+ देशांत,
**35,000 खऱ्या विक्री-भेटींचं** निरीक्षण: कोण जिंकतं आणि
का. [पक्कं: अभ्यास खरा, याच आकाराचा]

मोठा निष्कर्ष अपेक्षेच्या उलटा होता: मोठ्या विक्रीत जिंकणारे
**कमी सांगतात आणि जास्त विचारतात.** आणि त्यांच्या
प्रश्नांचा क्रम ठरलेला असतो. त्या क्रमाचं नाव SPIN:

```
S: परिस्थिती-प्रश्न (Situation)
   "उधारीची नोंद कशी ठेवता? किती दुकानं?"
   (माहिती: पण कमी: बहुतेक तुम्ही audit-निरीक्षणातून
   आधीच जाणता: जास्त S-प्रश्न = कंटाळा)
P: दुखणं-प्रश्न (Problem)
   "आठवण करायला संकोच वाटतो का? विसरायला होतं का?"
   (दुखणं त्याच्या तोंडून बाहेर काढणं)
I: परिणाम-प्रश्न (Implication) <- शिडीची जान
   "हे दीड लाख 3 महिने बाहेर राहतात, तेव्हा माल
   भरायला काय करता? कधी उसने घ्यावे लागले?"
   "त्या 2 गेलेल्या दुकानांचा वर्षाचा माल किती होता?"
   (दुखण्याची किंमत त्यालाच मोजायला लावणं)
N: फायदा-प्रश्न (Need-payoff)
   "समजा आठवणी आपोआप, विनम्रपणे जात राहिल्या आणि
   तुम्हाला फक्त 'कोण देतोय-कोण टाळतोय' ची यादी
   मिळाली: तर काय फरक पडेल?"
   (solution चं वर्णन त्याच्या तोंडून!)
```

जिंकणाऱ्यांचं गुपित I आणि N मध्ये होतं: सामान्य विक्रेता
S-P नंतर थेट भाषणावर उडी मारतो ("आमच्याकडे असं
software आहे..."); जिंकणारा **I-प्रश्नांनी दुखण्याची किंमत
फुगू देतो** आणि N-प्रश्नाने **मालकालाच solution मागायला
लावतो.**

## हे का चालतं (तुम्हाला हे आधीच माहितीये)

Book 12 उघडा: **generation effect.** स्वतः बनवलेलं टिकतं,
ऐकलेलं उडतं. मालकाने स्वतः केलेला हिशेब ("अरे हो, दोन
दुकानं म्हणजे वर्षाला लाखभर माल गेला की...") हा त्याचा
निष्कर्ष आहे: तुमचा दावा नाही. **दावा नाकारता येतो;
स्वतःचा निष्कर्ष नाकारता येत नाही.** SPIN म्हणजे विक्रीला
लावलेला generation effect: तुम्ही प्रश्न पेरता, निष्कर्ष
त्याच्या शेतात उगवतो.

म्हणूनच 1.4 चा नियम-1 ("आकडे त्याच्या तोंडून") आणि
2.1 चा जादूची-कांडी प्रश्न: सगळं एकाच तत्त्वाची रूपं.

आणि म्हणूनच **कच्चं बोलणं इथे अडथळा नाही.** शिडीला
लागतात 8-10 तयार प्रश्न (वर आहेत) + ऐकण्याची चिकाटी.
भाषण-कला लागते ती जुन्या, feature-सांगणाऱ्या विक्रीला.
प्रश्न विचारणारा अडखळला तरी चालतो: **ऐकणारा माणूस
अडखळणारा असला तरी आवडतो.**

## सराव-मैदान: Claude = शिंदे

खऱ्या दारावर जाण्याआधी शिडी 2-3 वेळा Claude वर
चालवा. नियम-पत्र (जसंच्या तसं द्या):

```
तू "शिंदे" आहेस: किराणा-मालाचा distributor. स्वभाव:
कामात बुडालेला, थोडा संशयी (आधी एकाने website विकून
फसवलंय), पण बोलका. तुझी परिस्थिती: 60-70 दुकानं,
महिन्याला ~18 लाखांचा माल, दीड-दोन लाख उधारी कायम
बाहेर, गर्दीत फोन सुटतात, 2 दुकानं नुकतीच दुसऱ्या
distributor कडे गेली.
नियम:
1. मराठीत, दुकानदारासारखं बोल: छोटी वाक्यं, मध्ये मध्ये
   गिऱ्हाईक आल्याने तुटक.
2. माहिती आपणहून देऊ नकोस: विचारलं तरच, तेवढंच.
3. मी भाषण द्यायला लागलो, jargon वापरला, किंवा
   विचारण्याआधी solution सांगितलं तर संशयी हो:
   "बघू, नंतर बोलू" कडे सरक.
4. मी चांगले I-प्रश्न विचारले तरच तुझी काळजी उघड कर.
5. 15 मिनिटांनी भेट संपव आणि मला परीक्षण दे:
   माझे S/P/I/N प्रश्न किती-किती, भाषण किती %,
   कुठे घाई केली, पुढच्या वेळी काय बदलू: गुण /10.
```

तीन फेऱ्या करा: पहिलीत बहुधा 4-5/10 येतील (सगळ्यांचेच
येतात: भाषणाची खोड जुनी आहे). तिसरीत शिडी अंगात
बसते. **हा सराव फुकट, अमर्याद, आणि लाज न वाटणारा
आहे: न वापरणं हा वेडेपणा आहे.** (Book 12, 4.1 चा
Harvard-धडा: सराव-जोडीदार म्हणून AI उत्तम: दिशा योग्य
ठेवली की.)

## इथे लोक चुकतात

**"I-प्रश्न म्हणजे मालकाला घाबरवणं."**

I-प्रश्नांची शिडी चढताना नवख्याला वाटतं आपण मालकाला
कोपऱ्यात ढकलतोय: म्हणून तो मध्येच "पण काळजी करू
नका, माझ्याकडे उपाय आहे!" म्हणून हवा सोडून टाकतो.
थांबा. **दुखणं त्याचं आहे; तुम्ही फक्त दिवा धरलाय.**
किंमत पूर्ण मोजून होण्याआधी उपाय दिला की उपायाची
किंमतही छोटी होते (भाव-गणित 2.6 इथेच बांधलेलं आहे).
शिस्त: N-प्रश्नाआधी उपायाचा शब्दही नाही. अवघडलेली
शांतता ही विक्रीतली सर्वात किमती जागा आहे: ती मोडू नका.

## भावाची तीन दिशा-यंत्रं

भाव काढताना तीन होकायंत्रं एकत्र वापरायची:

```
यंत्र 1: दुखण्याचा अपूर्णांक (मुख्य)
   भाव = मोजलेल्या गळतीच्या 10-20%
   शिंदे: गळती ~₹24,000/महिना -> retainer ₹3-5,000
   योग्य. मालकाचा हिशेब सोपा: "5 देऊन 20 वाचतात."
यंत्र 2: पगार-पट्टी (मालकाच्या डोक्यातली फूटपट्टी)
   तो प्रत्येक खर्च पगाराशी ताडतो (1.5). counter-माणूस
   ₹10-15K/महिना. तुमचा retainer त्याच्या अर्ध्याखाली
   असला की "स्वस्त माणूस" वाटतो: ₹3-8K हा भारतीय
   micro-धंद्याचा सुखाचा पट्टा.
यंत्र 3: बाजार-पट्टी (तुम्ही एकटे नाही)
   भारतात या कामांचे चालू भाव [थोडं: विक्रेते-यादीतून,
   पण सुसंगत]: साधा WhatsApp-bot ₹15-50K setup;
   जोडण्यांसकट ₹50K-1.5L; चालू खर्च+retainer
   ₹3-15K/महिना. या पट्टीच्या तळाशी शिरा (नवखे
   आहात), मध्यावर वाढा (4.2).
```

**Setup + retainer ही रचना का:** setup तुमच्या बांधणीचे
पैसे देतो (आणि "फुकटात करून बघू" वाल्यांना चाळतो:
पैसे दिलेला मालकच यंत्र वापरतो: गुंतवणूक = लक्ष);
retainer तुमचं खरं इंजिन आहे: Book 11 चं MRR-गणित:
10 गिऱ्हाईकं x ₹5K = ₹50K/महिना **आपोआप येणारे,**
आणि तुमचा चालू खर्च (API-tokens, platform-भाडं)
गिऱ्हाईकागणिक काही शेकड्यांत: margin जाड.

## शिंदे-सौद्याचं पूर्ण गणित (तुमच्या बाजूने)

```
setup ₹12,000 (घासाघिशीनंतर)
   बांधणी: master-recipe तयार होती -> re-skin + वही
   भरणं + चाचणी = ~10 तास काम -> ₹1,200/तास
retainer ₹4,000/महिना
   चालू खर्च: API + platform ~₹500-800/महिना
   पहिला महिना देखरेख: ~4 तास; नंतर: ~1-2 तास/महिना
   -> दुसऱ्या महिन्यापासून ₹3,200+ नफा = 80% margin
आणि खरी गोम: शिंदे 12 महिने टिकले तर एक सौदा =
   ₹12K + 48K = ₹60,000. म्हणून 4.2 (टिकवणं) हा
   chapter भावाइतकाच महत्त्वाचा आहे.
```

## स्वस्त-विकण्याचा सापळा (नीट, एकदाच)

नवख्याचा मोह: "₹1,000 त करून देतो, फक्त हो म्हणा."
काय बिघडतं:

```
1. भाव = तुमची किंमत-पाटी. ₹1,000 वाला "पोरगं"
   असतो; ₹12,000 वाला "व्यावसायिक". स्वस्त भावाला
   मालक कमी गंभीरपणे घेतो: यंत्र वापरत नाही: चाललं
   नाही: churn: आणि वस्तीत खबर "त्याचं चाललं नाही."
   स्वस्त विकून वाईट-खबर विकत घेतली!
2. गणित बुडतं: ₹1,000 x 10 गिऱ्हाईकं = ₹10K साठी
   10 धंद्यांची देखरेख: वेळ संपतो, वाढ थांबते.
3. भाव वर काढणं जवळजवळ अशक्य: पहिला भाव नांगर
   (anchor) होतो. खाली सुरुवात = कायम खाली.
उतारा: भाव कमी करायचाच झाला तर पैसे नको, आकार
   कापा: "₹12K जड? मग आधी फक्त वसुली-यंत्र, उत्तर-
   bot नंतर: ₹8K." काम कापा, दर नाही.
```

आणि उलटा सापळा एक ओळ: फार महागही नको: पहिल्या
5 गिऱ्हाईकांत तुम्ही भाव नाही, **case-गोष्टी** कमावताय
(4.3): बाजार-पट्टीच्या तळाशी या, पण **तळाच्या खाली
कधीच नाही.**

## Follow-up यंत्र (भेटी-मधलं)

दिवस 4: न ठरल्यास: त्याच्या आकड्याची आठवण:
   "काका, आपण काढलेला हिशेब परत बघत होतो:
   महिन्याला ~₹24 हजार. विचार झाला का?"
दिवस 8: नवं मूल्य: त्याच्या धंद्याशी संबंधित एखादी
   उपयोगी गोष्ट पाठवा (GST-तारखेची आठवण, त्याच्या

   माझ्याकडे (खरं तेच सांगा): नंतर पुढच्या महिन्यात."
मग: यादीत 'थंड' खूण; महिन्याने recipe-2 च्या मऊ
   फेरीत. (नकार चिरंतन नसतो; वेळ चुकलेली असते.)
